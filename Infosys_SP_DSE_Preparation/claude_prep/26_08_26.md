# GROUP A — Knapsack Family (10 problems)

## 1. Coin Change — Minimum Coins (LeetCode 322)
**Problem:** Given coin denominations and a target amount, find the fewest coins needed to make that amount (unlimited supply of each coin). Return -1 if impossible.
**Idea:** Classic unbounded knapsack, minimizing count. `dp[a]` = min coins to make amount `a`.
```python
def coinChange(coins, amount):
    INF = float('inf')
    dp = [0] + [INF] * amount
    for a in range(1, amount + 1):
        for c in coins:
            if c <= a:
                dp[a] = min(dp[a], dp[a - c] + 1)
    return dp[amount] if dp[amount] != INF else -1

print(coinChange([1, 2, 5], 11))  # 3  (5+5+1)
```
**Complexity:** O(amount × len(coins))

## 2. Coin Change II — Count Combinations (LeetCode 518)
**Problem:** Count the number of ways to make `amount` using unlimited coins, where **order doesn't matter**.
**Idea:** Golden rule from Part 2.6(b): loop **coin outer, amount inner** so each combination is only counted once.
```python
def change(amount, coins):
    dp = [0] * (amount + 1)
    dp[0] = 1
    for c in coins:
        for a in range(c, amount + 1):
            dp[a] += dp[a - c]
    return dp[amount]

print(change(5, [1, 2, 5]))  # 4
```
**Complexity:** O(amount × len(coins))

## 3. Combination Sum IV — Count Ordered Sequences (LeetCode 377)
**Problem:** Count ordered sequences (permutations) from `nums` summing to `target`.
**Idea:** Golden rule from Part 2.6(c): loop **amount outer, item inner** — this lets the same items appear in different orders as distinct answers.
```python
def combinationSum4(nums, target):
    dp = [0] * (target + 1)
    dp[0] = 1
    for s in range(1, target + 1):
        for n in nums:
            if n <= s:
                dp[s] += dp[s - n]
    return dp[target]

print(combinationSum4([1, 2, 3], 4))  # 7
```
**Complexity:** O(target × len(nums))

## 4. Partition Equal Subset Sum (LeetCode 416)
**Problem:** Can the array be split into two subsets with equal sum?
**Idea:** 0/1 knapsack (each number used at most once) — check if `sum/2` is reachable. Loop the amount **backwards** so each item is only used once.
```python
def canPartition(nums):
    total = sum(nums)
    if total % 2 != 0:
        return False
    target = total // 2
    dp = [False] * (target + 1)
    dp[0] = True
    for x in nums:
        for s in range(target, x - 1, -1):
            if dp[s - x]:
                dp[s] = True
    return dp[target]

print(canPartition([1, 5, 11, 5]))  # True
```
**Complexity:** O(N × target)

## 5. Target Sum (LeetCode 494)
**Problem:** Assign `+` or `-` in front of each number so the expression evaluates to `target`. Count the number of ways.
**Idea:** If `P` = sum of positive-signed numbers and `N` = sum of negative-signed numbers, then `P - N = target` and `P + N = total`. So `P = (total + target) / 2`. Now it's "count subsets summing to P" — 0/1 knapsack counting.
```python
def findTargetSumWays(nums, target):
    total = sum(nums)
    if abs(target) > total or (total + target) % 2 != 0:
        return 0
    P = (total + target) // 2
    dp = [0] * (P + 1)
    dp[0] = 1
    for x in nums:
        for s in range(P, x - 1, -1):
            dp[s] += dp[s - x]
    return dp[P]

print(findTargetSumWays([1, 1, 1, 1, 1], 3))  # 5
```
**Complexity:** O(N × P)

## 6. Perfect Squares (LeetCode 279)
**Problem:** Find the minimum number of perfect square numbers (1, 4, 9, 16, ...) that sum to N.
**Idea:** Unbounded knapsack, minimizing count, where the "coins" are perfect squares generated on the fly.
```python
def numSquares(n):
    dp = [0] + [float('inf')] * n
    for i in range(1, n + 1):
        j = 1
        while j * j <= i:
            dp[i] = min(dp[i], dp[i - j * j] + 1)
            j += 1
    return dp[n]

print(numSquares(12))  # 3  (4+4+4)
```
**Complexity:** O(N × sqrt(N))

## 7. Coin Change II with Minimum Gap D (Custom — same as Question 6 from the mock test)
**Problem:** Count combinations summing to `amount`, but any two DIFFERENT denominations used must differ by ≥ D.
**Idea:** Sort coins. `dp[i][a]` = ways to form `a` where `coins[i]` is the LARGEST denomination used. Maintain a running `pref_sum` (two-pointer) of all `dp[j]` rows where `coins[i] - coins[j] >= D`.
```python
def coinChangeWithGap(amount, D, coins):
    MOD = 10**9 + 7
    if amount == 0:
        return 1
    coins = sorted(set(coins))
    n = len(coins)
    dp = [[0] * (amount + 1) for _ in range(n)]
    pref_sum = [0] * (amount + 1)
    ptr = 0
    total = 0
    for i in range(n):
        coin = coins[i]
        while ptr < i and coin - coins[ptr] >= D:
            for a in range(amount + 1):
                pref_sum[a] = (pref_sum[a] + dp[ptr][a]) % MOD
            ptr += 1
        for a in range(coin, amount + 1):
            ways = pref_sum[a - coin]
            if (a - coin) % coin == 0:
                ways = (ways + 1) % MOD
            ways = (ways + dp[i][a - coin]) % MOD
            dp[i][a] = ways
        total = (total + dp[i][amount]) % MOD
    return total

print(coinChangeWithGap(10, 3, [1, 4, 7]))
```
**Complexity:** O(len(coins) × amount)

## 8. Combination Sum IV with Alternating Parity (Custom — same as Question 5 from the mock test)
**Problem:** Count ordered sequences from `nums` summing to `target` where adjacent elements alternate even/odd.
**Idea:** Extra state dimension: `dp[s][0]` ends even, `dp[s][1]` ends odd.
```python
def combinationSum4Parity(nums, target):
    MOD = 10**9 + 7
    dp = [[0, 0] for _ in range(target + 1)]
    for x in nums:
        if x <= target:
            if x % 2 == 0:
                dp[x][0] = (dp[x][0] + 1) % MOD
            else:
                dp[x][1] = (dp[x][1] + 1) % MOD
    for s in range(1, target + 1):
        for x in nums:
            if x < s:
                if x % 2 == 0:
                    dp[s][0] = (dp[s][0] + dp[s - x][1]) % MOD
                else:
                    dp[s][1] = (dp[s][1] + dp[s - x][0]) % MOD
    return (dp[target][0] + dp[target][1]) % MOD

print(combinationSum4Parity([1, 2, 3, 4], 5))
```
**Complexity:** O(target × len(nums))

## 9. 0/1 Knapsack — Exactly K Items
**Problem:** Choose exactly K items (each usable once) with total weight ≤ capacity, maximizing value.
**Idea:** Add a third dimension `k` (items used so far) to the classic 0/1 knapsack.
```python
def knapsackExactlyK(weights, values, capacity, K):
    n = len(weights)
    NEG = float('-inf')
    dp = [[NEG] * (K + 1) for _ in range(capacity + 1)]
    dp[0][0] = 0
    for i in range(n):
        w, v = weights[i], values[i]
        for cap in range(capacity, w - 1, -1):
            for k in range(K, 0, -1):
                if dp[cap - w][k - 1] != NEG:
                    dp[cap][k] = max(dp[cap][k], dp[cap - w][k - 1] + v)
    best = max(dp[cap][K] for cap in range(capacity + 1))
    return best if best != NEG else -1

print(knapsackExactlyK([1, 2, 3], [10, 15, 40], 6, 2))
```
**Complexity:** O(N × capacity × K)

## 10. Number of Ways to Tile a 2×N Board
**Problem:** Count ways to fully tile a 2×N board using 2×1 dominoes.
**Idea:** Simple linear recurrence — same shape as Fibonacci. `dp[i] = dp[i-1] + dp[i-2]` (place one vertical domino, or two horizontal ones).
```python
def tilingWays(n):
    MOD = 10**9 + 7
    if n <= 1:
        return 1
    dp = [0] * (n + 1)
    dp[0], dp[1] = 1, 1
    for i in range(2, n + 1):
        dp[i] = (dp[i - 1] + dp[i - 2]) % MOD
    return dp[n]

print(tilingWays(4))  # 5
```
**Complexity:** O(N)

# GROUP B — String DP: LCS / Edit Distance (8 problems)

## 11. Edit Distance (LeetCode 72)
**Problem:** Minimum operations (insert, delete, replace) to convert word1 into word2.
**Idea:** Classic 2D DP. `dp[i][j]` = edit distance between first `i` chars of word1 and first `j` chars of word2.
```python
def minDistance(word1, word2):
    n, m = len(word1), len(word2)
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        dp[i][0] = i
    for j in range(m + 1):
        dp[0][j] = j
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if word1[i - 1] == word2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = 1 + min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1])
    return dp[n][m]

print(minDistance("horse", "ros"))  # 3
```
**Complexity:** O(N×M)

## 12. Delete Operation for Two Strings (LeetCode 583)
**Problem:** Minimum deletions (from either string) to make two strings equal — **this is exactly the "insert/delete only" base case used in Question 3**.
**Idea:** Find LCS length, then `answer = n + m - 2*LCS`.
```python
def minDistanceDeleteOnly(word1, word2):
    n, m = len(word1), len(word2)
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if word1[i - 1] == word2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    lcs = dp[n][m]
    return n + m - 2 * lcs

print(minDistanceDeleteOnly("sea", "eat"))  # 2
```
**Complexity:** O(N×M)

## 13. Longest Common Subsequence (LeetCode 1143)
**Problem:** Length of the longest subsequence common to both strings.
```python
def longestCommonSubsequence(text1, text2):
```

## 14. Shortest Common Supersequence (LeetCode 1092)
**Problem:** Find the shortest string that has both str1 and str2 as subsequences.
**Idea:** Build the LCS table, then walk back through it: wherever characters match, keep one copy; wherever they don't, take whichever string still has characters left (following the higher `dp` value), building the result in reverse.
```python
def shortestCommonSupersequence(str1, str2):
    n, m = len(str1), len(str2)
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if str1[i - 1] == str2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    i, j = n, m
    res = []
    while i > 0 and j > 0:
        if str1[i - 1] == str2[j - 1]:
            res.append(str1[i - 1]); i -= 1; j -= 1
        elif dp[i - 1][j] >= dp[i][j - 1]:
            res.append(str1[i - 1]); i -= 1
        else:
            res.append(str2[j - 1]); j -= 1
    while i > 0:
        res.append(str1[i - 1]); i -= 1
    while j > 0:
        res.append(str2[j - 1]); j -= 1
    return ''.join(reversed(res))

print(shortestCommonSupersequence("abac", "cab"))
```
**Complexity:** O(N×M)

## 15. Edit Distance with One Free Block Swap (Custom — same as Question 3 from the mock test)
**Problem:** Insert/delete cost 1 each; at most once, swap a K-length block of A for a K-length block of B at flat cost W.
**Idea:** Precompute prefix-LCS and suffix-LCS tables. Try every wildcard placement `(i, p)`; total cost = left-part cost + right-part cost + W. Take the min over all placements and the no-wildcard baseline.
```python
def editDistanceWithWildcard(A, B, K, W):
    n, m = len(A), len(B)

    def lcs_table(a, b):
        na, nb = len(a), len(b)
        dp = [[0] * (nb + 1) for _ in range(na + 1)]
        for i in range(1, na + 1):
            for j in range(1, nb + 1):
                if a[i - 1] == b[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        return dp

    lcs_prefix = lcs_table(A, B)
    lcs_suffix = lcs_table(A[::-1], B[::-1])

    best = n + m - 2 * lcs_prefix[n][m]  # no wildcard used

    if K <= n and K <= m:
        for i in range(0, n - K + 1):
            for p in range(0, m - K + 1):
                left_cost = i + p - 2 * lcs_prefix[i][p]
                ai, bp = n - (i + K), m - (p + K)
                right_cost = ai + bp - 2 * lcs_suffix[ai][bp]
                best = min(best, left_cost + right_cost + W)
    return best

print(editDistanceWithWildcard("abcde", "vwxyz", 3, 2))  # 6
```
**Complexity:** O(N×M)

## 16. Minimum ASCII Delete Sum for Two Strings (LeetCode 712)
**Problem:** Like #12, but minimize the SUM OF ASCII VALUES deleted instead of the count of deletions.
**Idea:** Same DP shape as edit distance, but base cases and transitions add `ord(char)` instead of `1`.
```python
def minimumDeleteSum(s1, s2):
    n, m = len(s1), len(s2)
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        dp[i][0] = dp[i - 1][0] + ord(s1[i - 1])
    for j in range(1, m + 1):
        dp[0][j] = dp[0][j - 1] + ord(s2[j - 1])
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if s1[i - 1] == s2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = min(dp[i - 1][j] + ord(s1[i - 1]), dp[i][j - 1] + ord(s2[j - 1]))
    return dp[n][m]

print(minimumDeleteSum("sea", "eat"))  # 231
```
**Complexity:** O(N×M)

## 17. Distinct Subsequences (LeetCode 115)
**Problem:** Count how many distinct subsequences of `s` equal `t`.
**Idea:** `dp[i][j]` = ways to form `t[0:j]` using `s[0:i]`. Either skip `s[i-1]` (`dp[i-1][j]`) or, if characters match, also use it (`+ dp[i-1][j-1]`).
```python
def numDistinct(s, t):
    n, m = len(s), len(t)
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        dp[i][0] = 1
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            dp[i][j] = dp[i - 1][j]
            if s[i - 1] == t[j - 1]:
                dp[i][j] += dp[i - 1][j - 1]
    return dp[n][m]

print(numDistinct("rabbbit", "rabbit"))  # 3
```
**Complexity:** O(N×M)

## 18. Interleaving String (LeetCode 97)
**Problem:** Check whether s3 can be formed by interleaving s1 and s2 (preserving each string's internal order).
**Idea:** `dp[i][j]` = True if `s3[0:i+j]` can be formed from `s1[0:i]` and `s2[0:j]`.
```python
def isInterleave(s1, s2, s3):
    n, m = len(s1), len(s2)
    if n + m != len(s3):
        return False
    dp = [[False] * (m + 1) for _ in range(n + 1)]
    dp[0][0] = True
    for i in range(1, n + 1):
        dp[i][0] = dp[i - 1][0] and s1[i - 1] == s3[i - 1]
    for j in range(1, m + 1):
        dp[0][j] = dp[0][j - 1] and s2[j - 1] == s3[j - 1]
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            dp[i][j] = (dp[i - 1][j] and s1[i - 1] == s3[i + j - 1]) or \
                       (dp[i][j - 1] and s2[j - 1] == s3[i + j - 1])
    return dp[n][m]

print(isInterleave("aabcc", "dbbca", "aadbbcbcac"))  # True
```
**Complexity:** O(N×M)

# GROUP C — Palindrome DP (6 problems)

## 19. Longest Palindromic Substring (LeetCode 5)
**Problem:** Find the longest substring that is a palindrome.
**Idea:** Build the `is_pal[i][j]` table (Part 2.5), track the best `(start, length)` seen.
```python
def longestPalindrome(s):
    n = len(s)
    if n == 0:
        return ""
    is_pal = [[False] * n for _ in range(n)]
    start, maxlen = 0, 1
    for i in range(n):
        is_pal[i][i] = True
    for i in range(n - 1):
        if s[i] == s[i + 1]:
            is_pal[i][i + 1] = True
            start, maxlen = i, 2
    for length in range(3, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            if s[i] == s[j] and is_pal[i + 1][j - 1]:
                is_pal[i][j] = True
                if length > maxlen:
                    start, maxlen = i, length
    return s[start:start + maxlen]

print(longestPalindrome("babad"))  # "bab" or "aba"
```
**Complexity:** O(N²)

## 20. Palindrome Partitioning II — Minimum Cuts (LeetCode 132)
**Problem:** Minimum cuts needed so every resulting piece of `s` is a palindrome.
**Idea:** `dp[i]` = min cuts for `s[0:i+1]`. If the whole prefix is already a palindrome, 0 cuts. Otherwise try every split point `j` where `s[j+1:i]` is a palindrome.
```python
def minCut(s):
    n = len(s)
    is_pal = [[False] * n for _ in range(n)]
    for i in range(n):
        is_pal[i][i] = True
    for i in range(n - 1):
        is_pal[i][i + 1] = s[i] == s[i + 1]
    for length in range(3, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            is_pal[i][j] = s[i] == s[j] and is_pal[i + 1][j - 1]
    dp = [0] * n
    for i in range(n):
        if is_pal[0][i]:
            dp[i] = 0
        else:
            dp[i] = min(dp[j] + 1 for j in range(i) if is_pal[j + 1][i])
    return dp[n - 1]

print(minCut("aab"))  # 1
```
**Complexity:** O(N²)

## 21. Palindrome Partitioning — All Ways (LeetCode 131)
**Problem:** Return every way to partition `s` so all pieces are palindromes.
**Idea:** Backtracking guided by the same `is_pal` table.
```python
def partition(s):
    n = len(s)
    is_pal = [[False] * n for _ in range(n)]
    for i in range(n):
        is_pal[i][i] = True
    for i in range(n - 1):
        is_pal[i][i + 1] = s[i] == s[i + 1]
    for length in range(3, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            is_pal[i][j] = s[i] == s[j] and is_pal[i + 1][j - 1]

    res, path = [], []
    def backtrack(start):
        if start == n:
            res.append(path[:])
            return
        for end in range(start, n):
            if is_pal[start][end]:
                path.append(s[start:end + 1])
                backtrack(end + 1)
                path.pop()
    backtrack(0)
    return res

print(partition("aab"))  # [['a','a','b'], ['aa','b']]
```
**Complexity:** O(N² ) for table + exponential for enumerating all partitions (unavoidable, since the output itself can be exponential)

## 22. Count Different Palindromic Subsequences (LeetCode 730)
**Problem:** Count the number of *distinct* palindromic subsequences of `s` (mod 1e9+7).
**Idea:** Interval DP on `dp[i][j]` = count of distinct palindromic subsequences in `s[i:j+1]`. When `s[i] != s[j]`, use inclusion-exclusion; when equal, find the next/previous occurrence of that same character inside the interval to avoid double counting.
```python
def countPalindromicSubsequences(s):
    MOD = 10**9 + 7
    n = len(s)
    dp = [[0] * n for _ in range(n)]
    for i in range(n):
        dp[i][i] = 1
    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            if s[i] != s[j]:
                dp[i][j] = (dp[i + 1][j] + dp[i][j - 1] - dp[i + 1][j - 1]) % MOD
            else:
                lo, hi = i + 1, j - 1
                while lo <= hi and s[lo] != s[i]:
                    lo += 1
                while lo <= hi and s[hi] != s[i]:
                    hi -= 1
                if lo > hi:
                    dp[i][j] = (2 * dp[i + 1][j - 1] + 2) % MOD
                elif lo == hi:
                    dp[i][j] = (2 * dp[i + 1][j - 1] + 1) % MOD
                else:
                    dp[i][j] = (2 * dp[i + 1][j - 1] - dp[lo + 1][hi - 1]) % MOD
    return dp[0][n - 1] % MOD

print(countPalindromicSubsequences("bccb"))  # 6
```
**Complexity:** O(N²)

## 23. Maximum Product of the Length of Two Palindromic Subsequences (LeetCode 2002)
**Problem:** Split characters (by index) into two disjoint palindromic subsequences, maximize product of their lengths. (N ≤ 12, so brute force over bitmasks is fine.)
**Idea:** Enumerate all subsets (bitmasks), keep the ones that are palindromes, then check every pair of DISJOINT palindrome-masks.
```python
def maxProduct(s):
    n = len(s)
    def is_pal(mask):
        chars = [s[i] for i in range(n) if mask & (1 << i)]
        return chars == chars[::-1]

    pal_len = {}
    for mask in range(1, 1 << n):
        if is_pal(mask):
            pal_len[mask] = bin(mask).count('1')

    best = 0
    masks = list(pal_len.keys())
    for m1 in masks:
        for m2 in masks:
            if m1 & m2 == 0:
                best = max(best, pal_len[m1] * pal_len[m2])
    return best

print(maxProduct("leetcodecom"))  # 9
```
**Complexity:** O(2^N × N) to build + O(K²) to compare, fine since N ≤ 12

## 24. Choose Exactly B Non-Overlapping Palindromes, Maximize Length Sum (Custom — same as Question 4 from the mock test)
**Problem:** Select exactly B non-overlapping palindromic substrings of `s` to maximize the sum of their lengths.
**Idea:** Interval-selection DP layered on top of the palindrome table: `dp[i][k]` = best total length using prefix `s[0:i]` with exactly `k` picks made.
```python
def maxLengthKPalindromes(s, B):
    n = len(s)
    is_pal = [[False] * n for _ in range(n)]
    for i in range(n):
        is_pal[i][i] = True
    for i in range(n - 1):
        is_pal[i][i + 1] = s[i] == s[i + 1]
    for length in range(3, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            is_pal[i][j] = s[i] == s[j] and is_pal[i + 1][j - 1]

    NEG = -1
    dp = [[NEG] * (B + 1) for _ in range(n + 1)]
    dp[0][0] = 0
    for i in range(1, n + 1):
        for k in range(B + 1):
            dp[i][k] = dp[i - 1][k]
        for j in range(i):
            if is_pal[j][i - 1]:
                length = i - j
                for k in range(1, B + 1):
                    if dp[j][k - 1] != NEG:
                        dp[i][k] = max(dp[i][k], dp[j][k - 1] + length)
    return max(dp[n][B], 0)

print(maxLengthKPalindromes("abaaba", 2))
```
**Complexity:** O(N² × B)

## 33. Maximum Sum of 3 Non-Overlapping Subarrays (LeetCode 689)
**Problem:** Pick 3 non-overlapping subarrays of fixed length `k` maximizing total sum; return their starting indices.
**Idea:** Precompute window sums, then precompute "best single window index up to i" (left-to-right) and "best single window index from i to end" (right-to-left), then try every middle window position.
```python
def maxSumOfThreeSubarrays(nums, k):
    n = len(nums)
    w = [0] * (n - k + 1)
    s = sum(nums[:k])
    w[0] = s
    for i in range(1, n - k + 1):
        s += nums[i + k - 1] - nums[i - 1]
        w[i] = s

    left = [0] * len(w)
    best = 0
    for i in range(len(w)):
        if w[i] > w[best]:
            best = i
        left[i] = best

    right = [0] * len(w)
    best = len(w) - 1
    for i in range(len(w) - 1, -1, -1):
        if w[i] >= w[best]:
            best = i
        right[i] = best

    result, max_sum = None, -1
    for j in range(k, len(w) - k):
        l, r = left[j - k], right[j + k]
        total = w[l] + w[j] + w[r]
        if total > max_sum:
            max_sum, result = total, (l, j, r)
    return result

```

## 35. Video Stitching (LeetCode 1024)

```python

    max_reach = [0] * (time + 1)
    for s, e in clips:
        if s <= time:
            max_reach[s] = max(max_reach[s], e)

    next_end = 0

        curr_end = next_end
```

## 37. Maximum Number of Non-Overlapping Substrings (LeetCode 1520)
**Problem:** Select the max number of non-overlapping substrings such that each distinct character appears in at most one selected substring.
**Idea:** For each character, compute the minimal valid interval containing all its occurrences (expanding until stable). Then greedily pick shortest-ending-first non-overlapping intervals (classic interval scheduling greedy).
```python
def maxNumOfSubstrings(s):
    first, last = {}, {}
    for i, c in enumerate(s):
        if c not in first:
            first[c] = i
        last[c] = i

    intervals = []
    for c in first:
        start, end = first[c], last[c]
        i = start
        valid = True
        while i <= end:
            if first[s[i]] < start:
                valid = False
                break
            start = min(start, first[s[i]])
            end = max(end, last[s[i]])
            i += 1
        if valid and start == first[c]:
            intervals.append((start, end))

    intervals.sort(key=lambda x: x[1])
    res, prev_end = [], -1
    for start, end in intervals:
        if start > prev_end:
            res.append(s[start:end + 1])
            prev_end = end
    return res
```

## 45. Sliding Window Maximum (LeetCode 239)
**Problem:** Return the max of every sliding window of size k.
**Idea:** Monotonic decreasing deque of indices; pop smaller elements from the back before pushing, and pop expired indices from the front.
```python
from collections import deque

def maxSlidingWindow(nums, k):
    dq = deque()
    res = []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] < x:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            res.append(nums[dq[0]])
    return res
```

```python
            dq.popleft()
```

**Problem:** Count the number of subarrays whose sum falls within `[lower, upper]`.
**Idea:** Build prefix sums, then count pairs `(i, j)` with `lower <= prefix[j] - prefix[i] <= upper` using a merge-sort-based counting technique (similar to counting inversions).
```python
def countRangeSum(nums, lower, upper):
    prefix = [0]
    for x in nums:
        prefix.append(prefix[-1] + x)

    def merge_sort(lo, hi):
        if hi - lo <= 1:
            return 0
        mid = (lo + hi) // 2
        count = merge_sort(lo, mid) + merge_sort(mid, hi)
        j = k = mid
        for i in range(lo, mid):
            while j < hi and prefix[j] - prefix[i] < lower:
                j += 1
            while k < hi and prefix[k] - prefix[i] <= upper:
                k += 1
            count += k - j
        prefix[lo:hi] = sorted(prefix[lo:hi])
        return count

    return merge_sort(0, len(prefix))

print(countRangeSum([-2,5,-1], -2, 2))  # 3
```
**Complexity:** O(N log N)
