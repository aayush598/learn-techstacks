# SUPREMACY 1 — NORM HIERARCHY (WHICH RULE WINS)

**Folder:** `00-CONSTITUTION/06-Supremacy-and-Conflict/`

---

## 1. THE PRIORITY LADDER

When rules conflict, the higher norm wins:

| Priority | Norm | Source |
|----------|------|--------|
| **1 (Highest)** | The Basic Structure (Section 4 of Master Constitution) | `00-MASTER-CONSTITUTION.md` |
| **2** | Fundamental Rights | `02-Fundamental-Rights/` |
| **3** | The Master Constitution and this resource's constitutional rules | `00-CONSTITUTION/` |
| **4** | Assembled resolutions and ratified amendments | Assembly records |
| **5** | Committee decisions and operating procedures | `02-GOVERNANCE/02-Committees/` |
| **6** | Interim/emergency ordinances | `03-Interim-Rules-During-Gaps.md` |
| **7 (Lowest)** | Customs, habits, local practice | N/A |

## 2. APPLICATION RULES

1. A lower norm can never override a higher norm.
2. A resolution that contradicts the constitution is void.
3. An amendment that contradicts the basic structure is void.
4. A committee decision that contradicts a resolution is void.
5. Custom yields to any written norm.

## 3. LEX SPECIALIS (SPECIAL RULE WINS)

- Where a general rule and a special rule both apply to the same situation, the
  **special rule** wins (e.g., the drought rationing rules override the normal
  schedule during a declared drought).

## 4. LEX POSTERIOR (LATER RULE WINS — WITHIN THE SAME LEVEL)

- Between two rules of the **same level**, the later one wins if it was validly
  adopted. (An amendment that amends an earlier rule replaces it.)

## 5. HOW TO CONFIRM THE WINNER

1. Identify the conflict.
2. Check the level of each norm (table above).
3. Check for a special-rule override.
4. Check for a later-in-time rule at the same level.
5. If still ambiguous, the interpretation **most favourable to the affected
   member's rights** wins (the "benefit of the doubt goes to the weaker party").
