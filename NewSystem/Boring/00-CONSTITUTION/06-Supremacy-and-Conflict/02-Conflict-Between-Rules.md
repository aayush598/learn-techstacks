# SUPREMACY 2 — CONFLICT BETWEEN RULES

**Folder:** `00-CONSTITUTION/06-Supremacy-and-Conflict/`

---

## 1. WHAT THIS DOCUMENT DOES

Provides step-by-step handling when two documents/rules in this resource seem to
contradict each other, so that **no one can exploit confusion**.

## 2. PROCEDURE FOR RESOLVING A CONTRADICTION

| Step | Action |
|------|--------|
| 1 | Note both citations exactly (file, section, line). |
| 2 | Determine the level of each rule (norm hierarchy — see `01-Norm-Hierarchy.md`). |
| 3 | If levels differ → the higher level wins automatically. |
| 4 | If same level → check if one is a special rule (special wins). |
| 5 | If same level and neither is special → the later-adopted wins. |
| 6 | If still ambiguous → interpretation most favourable to the weaker/affected member wins. |
| 7 | Record the interpretation in the register; if the contradiction is in this resource itself, file a **clarification amendment** to fix the text permanently. |

## 3. INTERPRETATION CANONS

1. **Purpose canon** — read a rule in line with its stated purpose (see the
   folder overview at the top of each document).
2. **Rights canon** — when two readings are possible, choose the one that
   protects rights more.
3. **Practicality canon** — choose the reading that the colony can actually
   implement and verify.
4. **Anti-abuse canon** — choose the reading that makes it harder to dominate
   others.

## 4. WHO RESOLVES A CONTRADICTION

- First: any member may point out the contradiction and propose the resolution.
- If disputed: the CRB resolves it with a written note.
- The resolution is temporary until a clarification amendment formally fixes the
  resource text (or the dispute is taken to arbitration, `11-LEGAL-AND-COMPLIANCE/04-Dispute-Adjudication/`).

## 5. RECORD KEEPING

- Every contradiction resolution is logged: date, rules involved, decision,
  rationale, and whether an amendment was filed.
- This log is public, so the resource improves over time without anyone "just
  deciding" what the rules mean.
