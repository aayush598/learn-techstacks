# SUPREMACY 3 — INTERIM RULES DURING GAPS

**Folder:** `00-CONSTITUTION/06-Supremacy-and-Conflict/`

---

## 1. THE PROBLEM

No constitution can literally cover everything. When a genuinely new situation
arises that no document covers, this protocol provides a **safe, temporary**
way to act — without letting anyone exploit the gap.

## 2. THE INTERIM RULE PROCESS

| Step | Action |
|------|--------|
| 1 | Any member identifies the gap and states it in writing to the CRB. |
| 2 | The CRB (or emergency assembly) proposes a temporary **interim rule** that: respects P1–P10, harms nobody irreversibly, and is reversible. |
| 3 | The interim rule is published to all members. |
| 4 | It takes effect only for a **maximum of 30 days** (or 48 hours in emergency). |
| 5 | Before expiry, the assembly must either: (a) adopt a permanent rule via the amendment process, or (b) extend the interim rule by one vote (max one extension), or (c) let it lapse. |

## 3. CONSTRAINTS ON INTERIM RULES

An interim rule may **never**:
- Touch the basic structure.
- Suspend a Fundamental Right.
- Cut water from any member without due process.
- Create a permanent role or permanent payment.
- Retroactively punish anyone.

## 4. THE FILL-IN PRINCIPLE

Until the gap is filled, the **nearest analogous rule** in this resource applies
by analogy. For example, if a new type of event-water request appears, apply the
closest existing event-water rule.

## 5. RECORD

Every interim rule is numbered (IR-2026-001) and logged with its text, reason,
duration, and final disposition (adopted / lapsed / replaced). The log is public.

## 6. REVERSIBILITY BUDGET

- Interim actions should be **reversible** (e.g., "reduce slot by 10 minutes for
  3 days" is reversible; "sell the pump" is not).
- Any irreversible interim action requires a full assembly resolution, not just
  an interim rule.

## 7. AFTER THE GAP

- If the situation recurs, a permanent amendment should be proposed so the
  resource becomes complete over time — but the resource is designed to be
  near-complete from the start, so gaps should be rare.
