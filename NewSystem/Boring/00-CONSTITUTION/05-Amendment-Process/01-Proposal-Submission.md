# AMENDMENT PROCESS 1 — PROPOSAL SUBMISSION

**Folder:** `00-CONSTITUTION/05-Amendment-Process/`

---

## 1. WHO CAN PROPOSE

- **Any single member** can propose an amendment. No seconding, no committee,
  no permission required. This keeps the system responsive to any individual's
  legitimate concern.

## 2. HOW TO PROPOSE

1. Use the **Amendment Proposal Form** (`12-TEMPLATES/13-Amendment-Proposal-Form.md`).
2. State clearly:
   - The exact rule/clause being changed (quote it).
   - The proposed new text.
   - The **reason** (problem it solves).
   - The **impact** (who is affected, how, cost if any).
   - Supporting facts/evidence if relevant.
3. Submit to the notice board + members group + CRB (who records it in the
   amendment register).

## 3. STANDING (ADMISSIBILITY) CHECK

The CRB checks only **admissibility**, not merits:

| Admissible | Inadmissible |
|------------|--------------|
| Clear, written proposal | Attempts to amend the basic structure (Section 4 of Master Constitution) |
| Relates to the system | Vague/unreadable proposals (returned for rewording once) |
| Any subject at all (schedule, money, duty, rules) | Proposals targeting a specific person by name as punishment |

If a proposal is found inadmissible because it attacks the basic structure, the
CRB records that finding. That finding is itself appealable to the assembly.

## 4. THE AMENDMENT REGISTER

- Every proposal gets a number (AM-2026-001, etc.) and an entry:
  proposer, date, subject, status, and history.
- The register is public.

## 5. TIMELINE

- Submission closes nothing — proposals can arrive anytime.
- A proposal is **scheduled for discussion** at the next assembly, or earlier
  if an emergency assembly is called per `02-GOVERNANCE/01-General-Assembly/01-Assembly-Schedule.md`.
