# 02 - EMERGENCY CONTACTS

**Folder:** `10-RISK-AND-EMERGENCY/05-Communication-Emergency/`

---

## 1. PURPOSE

In the old system, the only useful number was the one inside the operator's
phone — and he decided when to call it. The emergency contacts list makes
every essential number a **public, printed, current, and multiply-copied**
resource of the whole colony (P3, P6).

## 2. WHAT THE LIST CONTAINS

| Category | Entries |
|----------|---------|
| **Colony** | ERT (month), Repair Committee, municipal liaison, all members' numbers |
| **Electrician / pump shop** | All vendors from the Approved Vendor List with trade and rating (`05-MAINTENANCE-REPAIR/04-Vendor-Management/`) |
| **Plumber** | Approved plumbers |
| **Rental pump supplier** | Approved rental supplier |
| **Tanker suppliers** | Approved tanker suppliers |
| **Medical** | Nearest clinic/hospital, ambulance (108/112 as applicable), pharmacy that stays open late |
| **Fire** | Fire service number |
| **Police** | Local police station / control room |
| **Water board / municipality** | Water board complaint line, municipal office, executive engineer |
| **Health department** | District health office, PHC/CHC contact |
| **Electricity board** | Power failure complaint line |
| **Testing lab** | Approved water lab |

## 3. HOW THE LIST IS KEPT CURRENT

1. The list is **updated quarterly** by the Repair Committee:
   - vendor numbers are re-verified against the vendor list;
   - ERT numbers change monthly with the team;
   - emergency services numbers are spot-checked by one test call each
     quarter (or confirmed against official sources).
2. Changes are published immediately; a stale list is a process failure.
3. The quarterly refresh is logged and dated.

## 4. WHERE THE LIST LIVES — MULTIPLE COPIES

| Copy | Location |
|------|----------|
| Printed master | Notice board |
| Laminated sheet | Inside the motor room |
| Print copy | With the ERT team member |
| Print copy | With a second member (non-ERT, different household) |
| Digital | Colony group (with the printed copies as the fallback) |

Rule: **if only one copy exists, the list does not exist.** In a phone-down
scenario, the printed copies are the working tool
(`01-Offline-Notice-Protocol.md`).

## 5. USE OF THE LIST

1. Any member may use the list at any time for a genuine need — calling the
   electrician, the ambulance, the water board. It is a public resource.
2. The ERT uses it as its working tool; vendors are called through the
   committee, but the numbers themselves are never a secret.
3. The list is not for harassment: repeated misuse of a member's or vendor's
   number is an offence under the Enforcement Ladder
   (`07-CONFLICT-RESOLUTION/05-Enforcement/01-Enforcement-Ladder.md`).

## 6. SCENARIO — THE LOCKED-OUT NUMBER

A midnight breakdown; the network is down. In the old system, nobody but the
operator had the electrician's number, and he "could not reach" him. Under
this rule, the ERT member walks to the notice board, reads the laminated
electrician's number, and walks to the nearest working phone or uses the
loudspeaker arrangement — the repair is called the same night. The colony's
ability to act did not depend on one person's address book.
