# 02 - DUPLICATE KEYS

**Folder:** `03-ROTATION-DUTY/05-Key-and-Control/`  
**Cross-reference:** `01-Key-Holder-Rotation.md`, `04-No-Single-Point-of-Failure.md`, `04-Duty-Failure/02-Immediate-Replacement-System.md`

---

## 1. THE MINIMUM: THREE KEY SETS

The colony maintains **at least three sets of keys** to the motor room:

| Set | Location | Who accesses | Purpose |
|-----|----------|--------------|---------|
| (a) Duty box key | Duty box at the motor room with a **combination lock** | Current operator and backups, using the published combination | Daily operation |
| (b) Backup key | A backup holder from a **different household** than the duty box key's custodian | That household, as named backup | Covering a missed duty or handover |
| (c) Emergency key | **Sealed emergency box** kept with a trusted member | Opened only on a documented emergency | Lockout, disaster, or key loss |

## 2. WHY THREE, AND WHY DIFFERENT HOUSEHOLDS

1. If one set is lost, stolen, or with a person who has left the colony, the
   other two still open the room. **No single loss locks the colony out.**
2. The backup holder (b) must be a **different household** from whoever is the
   current operating-key custodian, so no one household can ever control access
   alone.
3. The emergency key (c) is sealed, so it cannot be quietly used for personal
   runs; breaking the seal is a recorded event.

## 3. KEY CREATION AND LOGGING

1. Duplicates are made only by assembly resolution or by the record keeper with
   assembly approval; every duplicate is recorded in the key register.
2. Each key set is logged with: unique number, holder, date issued, date
   returned, and reason.
3. When a holder changes (rotation, exit, loss), the key is re-logged the same
   day.
4. Unauthorised duplication is a serious violation under
   `07-CONFLICT-RESOLUTION/`: a secret key is a hidden door into the system.

## 4. THE DUTY BOX COMBINATION

1. The combination to the duty box is known to **all trained members** — it is
   not a secret from the community, because the community is the owner.
2. The combination is changed whenever a member leaves the colony or when any
   member requests it for security, at the next assembly or earlier if the CRB
   approves urgency.
3. A member who uses the duty box outside their duty or without a logged reason
   is reported; the box is audited against the key register monthly.

## 5. LOST KEYS

| Event | Action |
|-------|--------|
| Operating key lost | Reported same day; backups cover; the lost key number is recorded and the lock re-keyed if the assembly decides the risk is real. |
| Backup key lost | Same procedure; the holder is responsible for the recorded loss. |
| Emergency box opened | A documented incident: who, when, why, what was used. The seal is renewed. |
| Key believed stolen | Immediate assembly notice; re-keying decision within 48 hours. |

## 6. SCENARIO

The backup holder's family shifts to another city and takes the backup key
with them. At the monthly reconciliation, the key register shows set (b) is no
longer on site. The colony creates a new duplicate, re-logs it to a different
household, and notes the departure. The system did not skip a day: the duty box
key and the sealed emergency key were never affected.
