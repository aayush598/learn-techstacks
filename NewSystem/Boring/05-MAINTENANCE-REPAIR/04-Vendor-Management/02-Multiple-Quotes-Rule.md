# 02 - MULTIPLE QUOTES RULE

**Folder:** `05-MAINTENANCE-REPAIR/04-Vendor-Management/`

---

## 1. PURPOSE

Competition is the colony's price protector. In the old system one vendor's
word was the price, and nobody could compare it. This rule guarantees that for
any meaningful spend, **at least two independent written quotes** compete, and
that the comparison is public — so an inflated quote dies in the light (P6).

## 2. MINIMUM QUOTES BY SIZE

| Repair value | Minimum written quotes | Additional rule |
|--------------|------------------------|-----------------|
| Below ₹1,000 | 1 written quote | Committee keeps a single quote with the fault record |
| **₹1,000 – ₹10,000** | **2 independent quotes** | Comparison published before approval |
| Above ₹10,000 | **3 independent quotes** | Comparison published; assembly decides |
| Motor rewinding (any amount) | 2 quotes minimum | Summer rule: quotes mandatory even below thresholds if any member asks |

## 3. RULES OF THE QUOTE PROCESS

1. **Written only.** Quotes are on paper, letterhead, or the standard form
   `12-TEMPLATES/06-Repair-Quote-Comparison.md`. Verbal offers are notes, not
   quotes.
2. **Sealed.** Where 3 or more vendors compete, the quotes are collected in
   sealed envelopes or closed digital forms opened together in front of the
   Repair Committee and a witness member. Sealing prevents the second vendor
   from "matching" the first.
3. **Identical scope.** Every vendor quotes on the **same written diagnosis and
   parts list** (`02-Breakdown-Repair/02-Diagnosis-and-Quoting.md`), so the
   comparison is apples to apples. A vendor who refuses to quote on the given
   scope is noted, not accommodated.
4. **Same closing time.** All vendors get the same deadline. Extending one
   vendor's deadline to help them is an offence.
5. **No relatives-in-the-middle.** If a vendor is related to a member, the
   relationship is disclosed (`04-No-Personal-Vendor-Kickbacks.md`) and that
   member takes no part in collecting or opening the quotes for that job.

## 4. THE COMPARISON TABLE

The comparison is filled into `12-TEMPLATES/06-Repair-Quote-Comparison.md` and
published with the fault record:

| Vendor | Parts cost | Labor | Total | Warranty | Time | Notes |
|--------|-----------|-------|-------|----------|------|-------|
| A | | | | | | |
| B | | | | | | |
| C (if applicable) | | | | | | |

The table is published **before** approval, on the notice board and in the
group. Members may add a quote of their own sourcing within the quoting
window.

## 5. LOWEST IS NOT AUTOMATIC

The cheapest quote is not automatically chosen. The approval decision weighs:

| Factor | How weighed |
|--------|-------------|
| **Total price** | Compared, but not decisive alone |
| **Quality** | Brand/spec of parts, vendor's past rating (`03-Vendor-Performance-Rating.md`) |
| **Warranty** | Longer warranty can justify a higher price |
| **Time** | Speed matters for critical faults |
| **Past performance** | Rated history from the rating log |

The committee records **why** a vendor was chosen when it is not the lowest
quote. The reason is public and can be challenged at the assembly.

## 6. NO VERBAL-ONLY DEALS

1. No repair above ₹1,000 is ever agreed on a handshake and a verbal price.
2. If the final amount differs from the approved quote, the difference is
   explained in writing under the fault number before any payment, and follows
   the verification rule (`02-Breakdown-Repair/05-After-Repair-Verification.md`).
3. A vendor who "discovers" extra unquoted work after approval must stop and
   get a fresh approval; work done without approval is not paid.

## 7. SCENARIO — SUMMER WINDING INFLATION

In peak summer, a burned winding is a seller's market: every owner is in a
hurry and vendors know it. The colony's response is mechanical: the diagnosis
is written, the winding quote goes to two approved pump shops **on the same
spec**, both sealed, opened together, compared publicly, and the choice is
recorded. The vendor who quoted ₹18,000 against a ₹12,500 competitor fails in
public — and learns that summer does not let him exploit this colony.
