# NEW MOTOR INSTALLATION — WARRANTY MANAGEMENT

**Folder:** `09-PROJECTS-AND-EXPANSION/02-New-Motor-Installation/`

---

## 1. WHY THIS FILE EXISTS

The motor installed last month fails today. Who pays? If the answer comes from
memory and arguments, someone pays twice — the common fund repairs it, and the
warranty is quietly forgotten. If the answer comes from a register, the dealer
repairs it once, free.

## 2. THE WARRANTY REGISTER

A warranty register is kept for every warranted asset (motor, pump, panel,
meter, tank lining). It records:

| Field | Entry |
|-------|-------|
| Asset | Motor — 1.5 HP, make X |
| Serial number | (from the invoice) |
| Purchase date | |
| Warranty start date | |
| Warranty end date | |
| Terms | Parts / labour / conditions |
| Dealer and service contact | |
| Status | In warranty / expired / claimed |

The register lives with the Asset Register
(`09-PROJECTS-AND-EXPANSION/05-Infrastructure-Asset-Register/01-Asset-List.md`)
and is checked when any asset fails.

## 3. CLAIMS MADE WITHIN WARRANTY — NO ONE PAYS TWICE

1. A failure inside the warranty period is reported to the dealer **in writing
   on the day it is discovered** (with a photo and the fault description).
2. The system does not pay for a repair out of the common fund while a
   warranty covers it. The claim is the first route; a paid repair is the
   second.
3. If the dealer delays, a written reminder is sent after 7 days; if the dealer
   still does not act, the matter is escalated per the vendor rules
   (`05-MAINTENANCE-REPAIR/04-Vendor-Management/`) and, if needed, through the
   contract path in `11-LEGAL-AND-COMPLIANCE/`.
4. Evidence of the claim — dates, copies of the claim and reminders — is kept
   in the claim file. "We called the shop" is not a claim; the paper is.

## 4. AFTER-SALES SERVICE LOG

Every service visit is logged:

| Date | Fault reported | Work done | By whom | Cost | Warranty used? |
|------|----------------|-----------|---------|------|----------------|
| | | | | | |

The log is evidence for a later extension, replacement, or dealer-rating
decision. It also shows whether a recurring fault is a design problem rather
than an incident.

## 5. DEALER PERFORMANCE RATING

Each dealer/installer is given a simple rating after every interaction:

| Criterion | Rating (1-5) |
|-----------|-------------|
| Response time | |
| Honoured warranty terms | |
| Quality of work | |
| Fairness of billing | |

Ratings feed the vendor list used by the multiple-quotes rule
(`05-MAINTENANCE-REPAIR/04-Vendor-Management/02-Multiple-Quotes-Rule.md`). A
dealer who fails members' warranty claims is marked and rarely chosen again.

## 6. EXAMPLE FROM COLONY LIFE

The new motor fails in month two. The register shows the warranty runs to month
thirty-six. The system files a written claim the same day; the dealer replaces
the motor under warranty; the service log records it; the rating is updated.
The common fund pays nothing, and no member is asked for a single rupee.

## 7. RENEWALS AND EXTENSIONS

- Extended warranties are considered like any purchase: compared on paper,
   decided by the assembly, recorded in the register.
- A warranty renewal due date is in the records calendar so it is never missed
   silently (`11-LEGAL-AND-COMPLIANCE/03-Records-Retention/03-Digital-and-Physical-Backup.md`).

---

*The warranty register is the system's memory of what someone else owes it. A
warranty that is not registered is a warranty that is thrown away.*
