# NEW BORING INSTALLATION — CONTRACTOR SELECTION

**Folder:** `09-PROJECTS-AND-EXPANSION/01-New-Boring-Installation/`

---

## 1. WHY THIS FILE EXISTS

Two classic failures define the old system: the contractor who quotes low and
then raises costs mid-job, and the member who "knows a driller" and steers the
work to a relative for a cut. This file makes selection open, comparative, and
written.

## 2. THREE OR MORE QUOTES — SEALED AND COMPARED

1. **Three or more written quotations** must be obtained for any boring project.
   The multiple-quotes rule in
   `05-MAINTENANCE-REPAIR/04-Vendor-Management/02-Multiple-Quotes-Rule.md`
   applies in full.
2. All bidders receive the **same scope document**: depth, casing and screen
   specification, expected yield, timeline, and warranty terms.
3. Quotations are **sealed** and opened together at a scheduled meeting in the
   presence of the oversight members and any members who wish to attend (P6).
   A quote opened privately is void.

## 3. THE COMPARISON TABLE

| Criterion | Bidder A | Bidder B | Bidder C |
|-----------|----------|----------|----------|
| Total price | | | |
| Depth quoted / guarantee | | | |
| Casing and screen specs | | | |
| Yield commitment | | | |
| Timeline | | | |
| Warranty (workmanship, months) | | | |
| References verified | | | |
| Registration / GST / licence | | | |

The completed comparison table is filed in the project file and published. The
lowest price wins nothing by itself; the best combination of price, commitment,
and verified references wins.

## 4. REFERENCES AND PAST WORK — VERIFIED, NOT ASSUMED

1. Each bidder must supply at least **two past boring jobs** with contacts.
2. The oversight members call the references and record the conversation;
   visiting a completed site is preferred when distance permits.
3. Registration, GST number, and any licence or permission required for
   drilling are checked and copied into the file.
4. A bidder who cannot name past work, or whose references are unverifiable, is
   marked and weighed accordingly.

## 5. THE WRITTEN CONTRACT — NO VERBAL DEALS

The contract must be in writing and must state:

| Clause | Content |
|--------|---------|
| Scope | Depth, casing, screens, expected yield |
| Price | Fixed price or itemised; what happens to escalation |
| Timeline | Start, expected completion, daily penalty for delay |
| Payment milestones | Linked to verified progress, not to calendar dates alone |
| Warranty | Period (min. 12 months on workmanship) and remedy |
| Labour and material | Who supplies what |
| Insurance | Driller's liability for damage during work |
| Dispute resolution | Simple written path before any legal action |

A verbal deal with a driller is unenforceable in practice and is forbidden. No
money is paid against a verbal promise.

## 6. CONFLICT OF INTEREST

- A member related to a bidder, or who will gain from the choice, must disclose
  the relationship and take no part in the evaluation.
- A member who fails to disclose and steers the work anyway commits a conflict
  of interest offence under the enforcement rules
  (`07-CONFLICT-RESOLUTION/05-Enforcement/`).

## 7. EXAMPLE FROM COLONY LIFE

Ravi's uncle quotes ₹60,000; two other bidders quote ₹85,000 and ₹92,000. The
uncle has no references, refuses a written contract, and wants half payment
upfront. The system takes the ₹85,000 bidder, whose past work is verified and
whose contract carries a 12-month workmanship warranty and milestone payments.
Ravi's feelings about his uncle do not move the rupees of every member.

## 8. PAYMENT MILESTONES — NO UPFRONT LUMPS

| Milestone | Payment share (example) |
|-----------|--------------------------|
| On mobilisation | 10% |
| Depth reached and logged | 30% |
| Casing and screens installed | 25% |
| Pumping test passed | 25% |
| Handover, records delivered | 10% |

Milestones are verified in writing by the oversight members before payment;
every payment is by bank/cheque with a voucher
(`06-FINANCE/03-Bookkeeping/02-Expense-Voucher-Rule.md`).

---

*Selection is a public comparison of written facts. The moment a contract
becomes verbal, or the quotes become one uncle's quote, the members' money is
at risk — so neither is ever allowed.*
