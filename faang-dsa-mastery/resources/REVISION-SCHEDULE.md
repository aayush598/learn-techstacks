# Spaced Revision Schedule (Non-Negotiable)

## Rule
Revise by **recall first, code second**. If you need to peek -> mark FUZZY and revise again earlier.

## Intervals
| Interval | Purpose |
| :-- | :-- |
| **D+1 (Next Day)** | Lock fresh learning (10-15 min) |
| **D+3** | Fix early forgetfulness (15-20 min) |
| **D+7** | Strengthen retention (20-30 min) |
| **D+14** | Fight mid-term decay (25-35 min) |
| **D+30** | Long-term consolidation (30-40 min) |

## Weekly Plan
| Day | Focus |
| :-- | :-- |
| **Mon-Fri** | New Day (1H+2M+3E) + D+1/D+3 of older |
| **Sat** | Pure Revision (Only REVISIT list) - Redo unaided |
| **Sun** | Weekly Audit + Timed Mock + Fix weakest pattern + Update tracker |

## How To Do Revision
1. Open `DAILY-PROGRESS-TRACKER.md` -> filter `REVISIT/FUZZY`
2. Pick 5-8 questions max (quality)
3. Cover problem statement only. Don't read solution.
4. Derive approach in mind + code.
5. If correct in <time -> OK. Else FUZZY and put in next slot.
6. Update dates/status.

## 90-Day Retention Goal
After 90 days of this exact cycle, your pattern recognition should be automatic.
