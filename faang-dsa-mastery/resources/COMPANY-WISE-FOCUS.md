# Company-Wise Focus For FAANG/MAANG/Tesla/NVIDIA/Samsung

| Company | Priority Patterns | Notes |
| :-- | :-- | :-- |
| **Google** | Graphs, Trees, Recursion, DP, Strings, Hard Problems | Focus on clarity, edge cases, optimality |
| **Meta (Facebook)** | Arrays, Strings, Hashing, Trees, Graphs, Behavioral+LC style | Clean code, fast thinking |
| **Amazon** | Arrays, Stacks/Queues, Trees, Greedy, System Design basics | Leadership principles + DSA |
| **Apple** | Arrays, Strings, Trees, OOP/Design, Practical | Practical, readable solutions |
| **Netflix** | System Design heavy + strong problem solving | Less quantity, more depth |
| **Microsoft** | Arrays, Strings, Linked List, Trees, DP, Graphs | Balanced, very solvable with pattern prep |
| **Tesla** | Arrays, Strings, Stacks, Queues, Math, Bit, Practical coding | Speed + clean implementation |
| **NVIDIA** | Arrays, Graphs, Bit Manipulation, DP, Math, C++/Java | Strong on fundamentals + optimization |
| **Samsung** | Arrays, Strings, Matrix, Simulation, Recursion, Backtracking | Often matrix/simulation heavy |
