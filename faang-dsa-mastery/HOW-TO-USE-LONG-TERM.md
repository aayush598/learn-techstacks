# HOW TO USE THIS LONG-TERM PLAN

## Philosophy
This is built for **depth + breadth**. Cover all patterns with maximum variety.

## Daily Routine (Strict)
1. **Warm up (10 min)** - Revise yesterday's weak
2. **New Day (2.5-3.5 hrs)** - Complete all 6 (E1,E2,E3,M1,M2,H1)
3. **Revision (20-40 min)** - Do D+1/D+3/D+7 items
4. **Log (5-10 min)** - Update tracker

## Rules
- **Unaided first:** Try >=25 min on Medium, >=35-40 min on Hard before peeking
- **Pattern first:** Before code, write "Pattern: ..."
- **Brute -> Optimal:** Always think both
- **Java only:** Implement in Java as planned
- **Explain:** Speak approach aloud
- **Similar list:** Do >=1 similar on revisit
- **Track honestly:** PARTIAL/REVISIT if helped

## Weekly Cycle
- Mon-Fri: New day
- Sat: Full revision of REVISIT
- Sun: Audit + timed mock (mix) + fix weakest

## Tips For Cracking Any Question
- Spot pattern in <60s
- Constraints give hint
- Handle all edge cases
- Clean code > clever one-liners
- Give TC/SC confidently
- Think follow-ups

## Progress Tracking
Use `resources/DAILY-PROGRESS-TRACKER.md`. Update after every day.

## When Stuck
1. Re-read problem
2. Find similar pattern
3. Try small example
4. Code partial
5. Only peek hints, derive rest
6. Redo unaided later

**Timeframe:** 16 weeks minimum if consistent. Go at your pace but don't skip days.
