# Arrays & Hashing - Complete Pattern Guide

## Core Patterns
1. **Frequency Count** - Use int array or HashMap
2. **Two Sum Family** - Complement lookup
3. **Prefix Sums** - Range sums/subarrays
4. **Sliding Window** - Contiguous subarrays/strings
5. **Two Pointers** - Pairs/triplets in sorted arrays

## Must Know Problems

| Group Anagrams (49) | Medium | HashMap + key | Sort or count key |
