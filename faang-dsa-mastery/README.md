# FAANG/MAANG/Tesla/NVIDIA/Samsung DSA Mastery Plan

> *"You don't need to solve 1000 random questions. You need to master patterns and solve them with intent until they become muscle memory."*

This is a no-fluff, interview-oriented DSA roadmap built specifically for cracking top-tier product companies (FAANG, MAANG, Tesla, NVIDIA, Samsung, Google, Meta, Amazon, Apple, Netflix, Microsoft etc.)

## Goal
By the end of this plan, you should be able to identify any DSA pattern within 60 seconds, derive an optimal approach, code it bug-free in Java within the interview time limit and handle follow-ups confidently.

## Golden Rule (Must Follow)
**Every single day you MUST complete exactly these 6 questions without skipping:**
- `EASY 1` 
- `EASY 2`
- `EASY 3`
- `MEDIUM 1`
- `MEDIUM 2`
- `HARD 1`

*Quality > Quantity. Solve with pen+paper, dry-run, write Java code, test edge cases and do the "similar questions" list.*

## How To Use This Repo
1. **Start from Foundation** - Go to `00-FOUNDATION/` and read all files in order before starting Day 1.
2. **Follow Chronologically** - Do `01-WEEK-01/` -> `16-WEEK-16/` in order. DO NOT jump randomly.
3. **One File Per Day** - Open `DAY-XXX.md`, read the objective, solve all 6 questions strictly as per the instructions.
4. **Master The Pattern** - For every question, fill mentally: `Pattern -> Constraints -> Approach -> Dry Run -> Code -> TC/SC -> Edge Cases`.
5. **Revise Religiously** - Use `resources/REVISION-SCHEDULE.md` (Spaced Repetition: D+1, D+3, D+7, D+14, D+30).
6. **Track Honestly** - Use the checklist in each day file. Mark only when you can solve it unaided.
7. **Time Yourself** - Easy (10-15m), Medium (25-40m), Hard (40-60m) under timer.

## Time Commitment
- **Minimum (Job/College)**: 2.5 - 3.5 hours/day (Strictly non-negotiable for results)
- **Ideal (Full Focus)**: 4 - 5 hours/day
- **Weekend**: Revision + Weak Patterns + Company-Wise Drill + Mock
