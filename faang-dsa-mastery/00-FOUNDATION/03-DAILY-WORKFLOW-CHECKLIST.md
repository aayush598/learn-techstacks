# Daily Workflow & Self Checklist

## Pre-Session (5-10 min)
- [ ] Hydrated, focused, phone on DND
- [ ] Review yesterday's weak questions (5 min)
- [ ] Set timer per question

## During Session (2.5 - 4 hours)
For EACH of the 6 questions (3E + 2M + 1H) follow strictly:

- [ ] **Read**: Understand problem, constraints, examples
- [ ] **Clarify**: Mentally note edge cases
- [ ] **Approach**: Brute force -> Optimal. Write in words
- [ ] **Dry Run**: Trace with sample + custom edge case
- [ ] **Code**: Write clean Java, compile-logic
- [ ] **Test**: Run mentally for all examples
- [ ] **Analyze**: Time & Space Complexity
- [ ] **Similar**: Solve at least 1 similar if time allows (or next revision)
- [ ] **Explain**: Can I explain this to someone without code?

## Post-Session (10-15 min)
- [ ] Update `DAILY-PROGRESS-TRACKER.md` with status (DONE/PARTIAL/REVISIT)
- [ ] Mark weak topics
- [ ] Do 5-10 min flash revision of patterns used today
- [ ] Plan weak list for next revision slot

## Weekly Review (Sunday - Mandatory)
- [ ] Revise ALL questions marked REVISIT
- [ ] Redo top 3 weakest from the week unaided
- [ ] Attempt a timed mix (2H + 3M + 3E) from mixed set
- [ ] Analyze mistakes and fix approach
- [ ] Update revision calendar

## Honesty Rule
**"If I saw this question again after 7 days, would I still solve it from scratch?"**
If NO -> REVISE HARDER.
