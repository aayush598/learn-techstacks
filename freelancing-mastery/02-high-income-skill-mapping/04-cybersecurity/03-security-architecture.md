## Service Offerings

### Service 1: Zero Trust Architecture Design

**What you do**: Design and implement Zero Trust architectures for organizations moving away from perimeter-based security.

**Zero Trust principles** (NIST SP 800-207):
1. All resources are accessed regardless of network location
2. Access is granted per-session (not persistent)
3. Access is dynamic and based on multiple attributes (user, device, location, behavior)
4. All traffic is monitored and logged
5. No implicit trust — verify every request

**Deliverables**:
- Zero Trust maturity assessment
- Architecture design (network segmentation, identity, device trust)
- Implementation roadmap
- Policy framework (who can access what, under what conditions)

**Common components**:
- Identity-aware proxy (Google IAP, Cloudflare Access, Zscaler)
- Micro-segmentation (network-level, Kubernetes network policies)
- Device trust / endpoint compliance
- Just-in-time (JIT) access
- Session recording and auditing

**Pricing**:
- Assessment and design: $20-50K
- Full implementation (with team): $50-200K
- Zero Trust maturity retainer: $10-20K/month

**ROI pitch**: "A Zero Trust architecture reduces your breach impact by 80%+ and is required for cyber insurance compliance."
