**Market demand:** High | **Rate range:** $60-200/hr | **Top earners:** $200k+/year

## Skill Stack by Tier

### Tier 1: Foundation ($50-80/hr) — Junior Mobile Developer

**Core Skills:**

**React Native Path:**
- JavaScript/TypeScript fundamentals
- React basics (components, hooks, state)
- React Native (navigation, layouts, styling)
- REST API integration
- App deployment (App Store + Play Store basics)
- Firebase (Auth, Firestore, push notifications)

**Flutter Path:**
- Dart language
- Flutter widgets and layouts
- State management (Riverpod, Bloc, Provider)
- REST API integration
- App deployment
- Firebase integration

**Both Paths:**
- Git version control
- Basic testing
- App Store screenshots and metadata

**Can do:** Simple apps (todo, note-taking, basic e-commerce), API-connected apps
**Target rate:** $50-80/hr | **Max monthly:** $8k-$12k

### Tier 2: Professional ($80-150/hr) — Senior Mobile Developer

**Advanced Skills:**
- Deep platform knowledge (SwiftUI or Jetpack Compose)
- Offline-first architecture (SQLite, Realm, WatermelonDB)
- State management mastery
- Performance optimization (memory, rendering, startup)
- Custom animations and transitions
- Push notifications (FCM, APNs)
- In-app purchases / subscriptions (StoreKit, Google Billing)
- CI/CD for mobile (Fastlane, Bitrise, GitHub Actions)
- Code push / over-the-air updates
- App Store optimization (ASO)

**Specialization options:**
- React Native expert with native modules
- Flutter expert with platform channels
- Native iOS specialist (SwiftUI, Combine, async/await)
- Native Android specialist (Jetpack Compose, Room, Hilt)

**Can do:** Production-grade apps, subscription/paid apps, complex UIs, real-time features
**Target rate:** $80-150/hr | **Max monthly:** $15k-$25k

### Tier 3: Expert ($150-200+/hr) — Mobile Architect

**Architecture & Strategy:**
- Mobile app architecture (Clean Architecture, MVVM, MVI)
- Cross-platform strategy (when to use what)
- Mobile security (runtime protection, SSL pinning, encryption)
- CI/CD and testing infrastructure
- App modularization and monorepo management
- Performance at scale (100k+ users)
- Migration projects (legacy → modern)
- Accessibility (VoiceOver, TalkBack)

**Services:**
- Architecture design: $5-15k
- Code audit and optimization: $5-20k
- Full app development: $30-200k
- Mobile strategy consulting: $10-30k
- Fractional mobile lead: $10-20k/month

**Can do:** Enterprise mobile apps, apps with complex architectures, platform migrations
**Target rate:** $150-200+/hr | **Max monthly:** $30k+

## Freelancing Roadmap: Mobile Development

### Month 1-2: Foundation & First Clients

**Skill building (if needed):**
- [ ] Master React Native or Flutter
- [ ] Build and ship 1 app to App Store + Play Store
- [ ] Implement auth, payments, push notifications
- [ ] Learn Fastlane for CI/CD
- [ ] Understand App Store Connect + Google Play Console

**First offerings:**
| Package | Price | Scope | Timeline |
|---------|-------|-------|----------|
| MVP mobile app | $5-15k | Core features, auth, API integration | 3-6 weeks |
| App redesign | $3-10k | UI overhaul, navigation restructure | 2-4 weeks |
| Bug fix / performance sprint | $2-5k | Diagnose + fix issues | 1-2 weeks |
| App Store submission | $1-3k | Prepare assets, submit, manage review | 1 week |

**Client acquisition:**
- [ ] Target startups with web products that need mobile
- [ ] Target local businesses that need a basic app
- [ ] Partner with web dev freelancers (they build backend, you build mobile)
- [ ] Offer: "I'll build your MVP in 4 weeks for $X"
- [ ] Showcase shipped apps in portfolio

### Month 3-6: Specialize & Raise Rates

**Pick a platform focus:**
- [ ] React Native (TypeScript + Expo + native modules)
- [ ] Flutter (Dart + Riverpod + platform channels)
- [ ] Native iOS (Swift + SwiftUI)
- [ ] Native Android (Kotlin + Jetpack Compose)

**Build portfolio:**
- [ ] 3+ shipped apps with screenshots and metrics
- [ ] Case studies showing App Store ratings, download numbers, revenue
- [ ] Open-source a useful mobile component or library
- [ ] Write technical blog posts about mobile dev challenges

**Rate milestones:**
| Month | Target Rate | Revenue Target |
|-------|-----------|---------------|
| 1-2 | $50-80/hr | $3-8k |
| 3-4 | $80-120/hr | $8-15k |
| 5-6 | $120-150/hr | $15-25k |

### Month 7-12: Premium Positioning

**Move upmarket:**
- [ ] Minimum project: $15k
- [ ] Target funded startups and established companies
- [ ] Offer ongoing maintenance retainer ($2-5k/month)
- [ ] Build referral system with design agencies and web dev shops

**Premium services:**
- Full production app: $30-150k
- Mobile architecture consulting: $10-25k
- App store optimization + growth: $5-15k
- Performance audit + optimization: $5-15k

## Top-Paying Mobile Niches

### 1. React Native Cross-Platform — $75-175/hr
Build once, deploy to both iOS and Android. Most clients want this.
**Best clients:** Startups, SMBs, any company needing both platforms
**Avg project:** $15-60k

### 2. Native iOS (Swift) — $100-200/hr
Premium clients, better rates, Apple ecosystem focus.
**Best clients:** Companies with iOS-only strategy, Mac apps too
**Avg project:** $20-100k

### 3. Fintech / Health Mobile — $125-200/hr
Apps requiring compliance (HIPAA, PCI-DSS, SOC 2).
**Best clients:** Fintech startups, health/medtech companies
**Avg project:** $30-200k

### 4. Mobile CI/CD & DevOps — $125-200/hr
Automating build, test, and deployment pipelines for mobile teams.
**Best clients:** Companies with 5+ mobile developers
**Avg project:** $10-40k

### 5. App Rescue / Legacy Migration — $100-175/hr
Fixing broken apps, migrating from old frameworks to modern.
**Best clients:** Companies with existing apps that are failing
**Avg project:** $20-80k

## App Store & Monetization

**Revenue models you can build for clients:**
- Paid app: $2.99-$9.99
- Freemium: Basic free, premium subscription
- Subscriptions: $9.99-$49.99/month
- In-app purchases: consumables, unlockables
- Advertising: AdMob / AdColony
- Enterprise: Custom pricing, private distribution

**App Store requirements:**
- Apple Developer Program: $99/year
- Google Play Console: $25 one-time
- App Review Guidelines (Apple is strict)
- Privacy policy (required by both stores)
- App Store screenshots (various device sizes)
- App Store Optimization (ASO) keywords
