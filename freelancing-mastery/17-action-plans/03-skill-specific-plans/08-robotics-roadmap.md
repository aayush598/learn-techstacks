## Skill Stack by Tier

### Tier 1: Foundation ($60-100/hr) — Robotics Developer

**Core Skills:**
- Python (NumPy, OpenCV, Matplotlib)
- C++ (pointers, STL, classes, threading)
- ROS (Robot Operating System) basics:
  - Nodes, topics, services, actions
  - ROS message types
  - Launch files, parameter server
  - RViz visualization
- Linux (Ubuntu, command line, bash scripting)
- Git version control
- Basic sensor integration (LiDAR, camera, IMU, encoder)
- Basic motor control (PWM, PID)

**Hardware platforms:**
- TurtleBot3 / Husarion
- Raspberry Pi + Arduino for robot control
- ROS-compatible platforms (Clearpath, Unitree, etc.)

**Can do:** Basic ROS nodes, sensor data publishing, simple robot control, simulation in Gazebo
**Target rate:** $60-100/hr | **Max monthly:** $10k-$15k

### Tier 2: Professional ($100-200/hr) — Robotics Engineer

**Advanced Skills:**

**ROS/ROS2 Software:**
- ROS2 (rclcpp, rclpy, composition, lifecycle nodes)
- Multi-robot systems (ROS2 multi-machine)
- Real-time control (RT kernel, real-time executors)
- ROS2 security (SROS2)
- Custom message/service/action definitions

**Perception:**
- OpenCV (calibration, feature detection, tracking)
- PCL (Point Cloud Library) — segmentation, registration
- Deep learning for vision (YOLO, segmentation, depth estimation)
- Sensor fusion (Kalman filters, EKF, factor graphs)

**Navigation & Planning:**
- ROS Navigation Stack / Nav2
- SLAM (Cartographer, GMapping, ORB-SLAM)
- Path planning (A*, RRT, Dijkstra)
- MoveIt for manipulation
- OMPL (Open Motion Planning Library)

**Control:**
- PID control tuning
- Model Predictive Control (MPC)
- LQR, Kalman filters
- Robot kinematics (forward/inverse)
- Dynamics modeling

**Simulation:**
- Gazebo (SDF/URDF models, plugins)
- Isaac Sim (Nvidia)
- Webots / CoppeliaSim

**Can do:** Full robot software stack, autonomous navigation, manipulation, vision systems
**Target rate:** $100-200/hr | **Max monthly:** $30k-$40k

### Tier 3: Expert ($200-300+/hr) — Robotics Architect / Consultant

**Architecture & Strategy:**
- Full robot system design (hardware + software + controls)
- Robot product development from concept to deployment
- Safety-critical robotics (ISO 10218, ISO 13482)
- Robot cell design and integration
- Robot fleet management systems
- AI/ML for robotics (reinforcement learning, imitation learning)

**Services:**
- Robot software architecture: $20-60k
- Perception system design: $20-80k
- Full robot development: $50-500k
- Robot integration consulting: $15-50k
- Technical due diligence (robotics startup): $15-40k

**Can do:** End-to-end robot systems, research to production, autonomous systems
**Target rate:** $200-300+/hr | **Max monthly:** $50k+

## Freelancing Roadmap: Robotics

### Month 1-3: Foundation & First Projects

**Skill building:**
- [ ] ROS/ROS2 tutorials (beginner to intermediate)
- [ ] Build a simulated robot in Gazebo with navigation
- [ ] Implement a mobile robot with SLAM and autonomous navigation
- [ ] Set up computer vision pipeline with OpenCV + ROS
- [ ] Learn PID control and implement on a real/simulated robot
- [ ] Get familiar with MoveIt for arm manipulation

**First offerings:**
| Package | Price | Scope | Timeline |
|---------|-------|-------|----------|
| ROS driver development | $5-15k | Driver for sensor/actuator | 2-4 weeks |
| Robot simulation setup | $5-15k | URDF + Gazebo + sensor simulation | 2-4 weeks |
| Navigation stack setup | $8-20k | SLAM + path planning + Nav2 | 3-6 weeks |
| Vision pipeline integration | $5-20k | Camera + detection + tracking | 2-6 weeks |
| Industrial robot program | $3-10k | Program for specific task | 1-3 weeks |

**Client acquisition:**
- [ ] Target robotics startups (hundreds of funded startups globally)
- [ ] Target research labs (universities, government) needing ROS expertise
- [ ] Target manufacturing companies automating processes
- [ ] Offer: "I can build your robot software stack in ROS/ROS2"
- [ ] Contribute to ROS ecosystem (answer questions, submit PRs)
- [ ] Partner with hardware-focused robotics companies

### Month 4-9: Specialize & Build Reputation

**Pick a specialization:**
- [ ] Mobile robotics (navigation, SLAM, multi-robot)
- [ ] Manipulation (arm control, grasping, MoveIt)
- [ ] Perception (computer vision, deep learning, sensor fusion)
- [ ] Industrial robotics (robot programming, PLC integration)
- [ ] Agricultural robotics (field robots, crop sensing)
- [ ] Underwater/aerial robotics (drones, ROVs)

**Build authority:**
- [ ] Open-source a ROS package that solves a common problem
- [ ] Write detailed ROS tutorials and blog posts
- [ ] Publish a robot build guide (open-source hardware + software)
- [ ] Speak at ROSCon or ICRA/IROS
- [ ] Create video demos of your robot projects on YouTube
- [ ] Build a portfolio of 3+ robot projects with video evidence

- ROS / ROS2 (Humble, Iron, Rolling)

- MoveIt / MoveIt2
- Navigation2 (Nav2)
- OpenCV
- PCL (Point Cloud Library)

**Simulation:**

- Webots
- CoppeliaSim (formerly V-REP)
- MuJoCo

**Hardware:**
- Sensors: LiDAR (Velodyne, Ouster, Hesai), cameras (Intel RealSense, FLIR), IMUs (VectorNav, Xsens)
- Actuators: Dynamixel, RoboMaster, custom motor controllers
- Compute: NVIDIA Jetson (Orin, Xavier), Intel NUC, Raspberry Pi
- Platforms: TurtleBot, Clearpath, Unitree (quadrupeds), Boston Dynamics (API)

**Control Libraries:**
- ROS Control
- OMPL (motion planning)
- Pinocchio (dynamics)
- Drake (Model-based design)
- CasADi (optimization)

**Perception:**
- YOLO / Ultralytics
- DeepLabCut
- Open3D
- SuperGlue / SuperPoint
- Depth Anything / ZoeDepth
