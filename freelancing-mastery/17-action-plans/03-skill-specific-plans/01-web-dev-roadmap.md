## Skill Stack by Tier

### Tier 1: Foundation ($40-75/hr) — Junior Freelancer

**Frontend:**
- HTML5, CSS3, JavaScript (ES6+)
- React or Vue basics (components, state, routing)
- Responsive design (Tailwind, Bootstrap)
- Version control (Git/GitHub)

**Backend:**
- Node.js basics (Express or Next.js API routes)
- REST API fundamentals
- Database basics (PostgreSQL or MongoDB basics)
- Authentication (JWT, session-based)

**Tooling:**
- VS Code, terminal
- npm/yarn/pnpm
- Basic deployment (Vercel, Netlify)
- Chrome DevTools

**Can do:** Simple landing pages, basic CRUD apps, WordPress sites, small business websites
**Target rate:** $40-75/hr | **Max monthly:** $6k-$12k (full-time)

### Tier 2: Professional ($75-125/hr) — Experienced Freelancer

**Full-Stack Mastery:**
- Next.js 14+ (App Router, Server Components, SSR/SSG/ISR)
- TypeScript (advanced types, generics, utilities)
- Tailwind CSS, Shadcn UI, Radix UI
- tRPC or GraphQL (Apollo, Relay)
- Prisma or Drizzle ORM
- PostgreSQL, Redis basics
- Authentication (NextAuth/Auth.js, Clerk)
- Stripe integration

**DevOps Basics:**
- Docker basics (Dockerfile, docker-compose)
- CI/CD (GitHub Actions)
- Vercel/Railway/Fly.io deployment
- Environment management

**Testing:**
- Vitest/Jest, React Testing Library
- Playwright or Cypress (E2E)

**Can do:** Complex SaaS platforms, e-commerce stores, API-first applications, real-time apps
**Target rate:** $75-125/hr | **Max monthly:** $15k-$20k

### Tier 3: Expert ($125-200+/hr) — Premium Consultant

**Architecture & Scale:**
- Microservices architecture
- Event-driven systems (Kafka, RabbitMQ)
- Edge computing (Cloudflare Workers, Vercel Edge)
- Monorepo management (Turborepo, Nx)
- Web performance (Core Web Vitals, Lighthouse 100)
- Accessibility (WCAG 2.1/2.2)
- Security (OWASP Top 10, auth patterns)

**Specialization:**
- Deep expertise in 1-2 frameworks (e.g., Next.js + tRPC expert)
- Vertical expertise (e-commerce, fintech, healthcare, SaaS)
- Migration projects (legacy → modern stack)
- Technical architecture consulting

**Business skills:**
- Technical due diligence (for investors/acquiring companies)
- Code review and audit services
- Fractional CTO / technical advisor

**Can do:** Enterprise-grade systems, architecture consulting, platform migrations, technical leadership
**Target rate:** $125-200+/hr | **Max monthly:** $30k+

## Freelancing Roadmap: Web Dev

### Month 1-2: Foundation & First Clients

**Skill building (if needed):**
- [ ] Master Next.js App Router and Server Components
- [ ] Build 2-3 full-stack projects with auth + payments
- [ ] Deploy to Vercel/Railway
- [ ] Learn Stripe integration

**Client acquisition:**
- [ ] Find 10 local businesses with outdated websites → pitch rebuilds
- [ ] Join Shopify/Webflow partner programs for referrals
- [ ] Offer "free audit" of landing page performance → upsell

**Package offerings:**
| Package | Price | Scope | Timeline |
|---------|-------|-------|----------|
| Landing page | $1,500-3k | 1 page, responsive, basic SEO | 1 week |
| MVP build | $5k-15k | 3-5 page app, auth, payments | 3-6 weeks |
| Site rebuild | $3k-10k | Legacy → modern, same features | 2-4 weeks |
| Performance audit | $500-1k | Lighthouse audit + recommendations | 2-3 days |

**Pick a vertical:**
- [ ] SaaS (subscription apps, dashboards)
- [ ] E-commerce (Shopify custom apps, headless)
- [ ] Content platforms (blogs, media, education)
- [ ] Internal tools (admin dashboards, CRMs)

**Build portfolio in chosen vertical:**
- [ ] 3 case studies with metrics (conversion, speed, revenue)
- [ ] Open-source a component library or starter template
- [ ] Write 5 articles about problems in your niche

**Rate milestones:**
- [ ] Month 1-2: $50-75/hr

## Top-Paying Web Dev Niches

### 1. SaaS Development — $100-200/hr
- Building MVP to production for funded startups
- Subscription management, team features, billing
- Multi-tenant architecture
- **Best clients:** VC-backed seed/Series A startups

### 2. E-Commerce / Shopify — $100-200/hr
- Headless Shopify with Next.js/Hydrogen
- Custom checkout flows and payment integrations
- Migration from Magento/WooCommerce to Shopify
- **Best clients:** DTC brands doing $1M+/year

### 3. Performance Optimization — $150-250/hr
- Core Web Vitals optimization (Lighthouse 90+ → 100)
- Reduce page load from 5s → 1s
- Fix render-blocking resources, CLS issues
- **Best clients:** Enterprise e-commerce, media, SaaS

### 4. Migration Projects — $100-175/hr
- jQuery/legacy → React/Vue/Next.js
- Monolith → microservices (carefully)
- Database migrations (MySQL → PostgreSQL)
- **Best clients:** Mid-market companies with technical debt

### 5. Enterprise React — $100-175/hr
- Large-scale React applications with complex state
- Internal tooling, admin panels, dashboards
- Component libraries and design systems
- **Best clients:** 100+ employee tech companies
