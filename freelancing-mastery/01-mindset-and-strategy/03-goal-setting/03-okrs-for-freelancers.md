# OKRs for Freelancers: The Goal-Setting System Used by Top Performers

## What Are OKRs?

**Objective:** What you want to achieve (inspirational, qualitative)
**Key Results:** How you measure success (specific, quantitative, 3-5 per objective)

## OKR Framework for Freelancers

### Quarterly OKR Template

#### Objective: Build a sustainable $10k/month freelancing business

**KR1:** Acquire 3 retainer clients at $3k+/month each
**KR2:** Achieve 40% response rate on outreach
**KR3:** Close 5 projects at $5k+ average value
**KR4:** Reach 90% client satisfaction score (measured by repeat/ referral rate)

## Weekly OKR Check-in

Every Monday, review:
- What's on track?
- What's at risk?
- What's one thing I can do this week to move the needle?

## Common OKR Mistakes

- **Too many objectives** → Max 2-3 per quarter
- **KRs that aren't measurable** → "Get better at proposals" isn't a KR
- **Setting and forgetting** → Review weekly
- **Risk-averse KRs** → 70% confidence is ideal (stretch goals)
- **Mixing tasks with results** → "Send 50 proposals" is a task; "Get 5 responses" is a result

## OKR vs. To-Do List

| OKR | To-Do List |
|-----|-----------|
| Strategic | Tactical |
| Quarterly | Daily/weekly |
| Outcome-focused | Task-focused |
| 2-3 objectives | 5-10 items/day |

Both are needed. OKRs set direction. To-do lists execute.

## Your First OKR Set

**Objective: Start freelancing and get first paying client within 30 days**

- **KR1:** Set up profiles on Upwork, LinkedIn, and portfolio website by Day 3
- **KR2:** Send 50+ tailored proposals by Day 14
- **KR3:** Get on 5 discovery calls by Day 21  
- **KR4:** Close first project at minimum $2k by Day 30

Write these down. Review every Sunday. Adjust as needed.
