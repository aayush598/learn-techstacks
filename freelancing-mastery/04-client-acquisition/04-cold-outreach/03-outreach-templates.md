# Outreach Templates — Ready to Use

## How to Use These Templates

These templates are battle-tested across thousands of outreach attempts. They work.

**Modify them by:**
1. Replacing bracketed text `[like this]` with your specifics
2. Adding personalization for each prospect
3. Adjusting tone to match your voice
4. A/B testing variations

**Never send them as-is.** Even the best template needs personalization to avoid feeling generic.

## 8. Follow-Up Templates

### No Response Follow-Up (Day 3)

```
Subject: Re: [Original Subject]

Hi [Name],

Just bumping this in case it got buried. I'd still love to connect if you're open to it.

Brief reminder: I help [client type] with [service], and I think [Company] could benefit from [specific approach].

Either way, wishing you a great week!
```

### No Response Follow-Up (Day 7)

```
Subject: Re: [Original Subject]

Hi [Name],

I know you're busy, so I'll keep this brief.

I have [availability] this week if you'd like to chat about [topic]. If not, no worries — I won't follow up again.

Best,
[Your Name]
```

### No Response Breakup (Day 14)

```
Subject: Re: [Original Subject]

Hi [Name],

I understand this isn't a priority right now. I'll stop following up.

If things change, feel free to reach out. I'm always happy to help [client type] with [service].

Wishing you and [Company] all the best.

Best,
[Your Name]
```

### Positive Response Follow-Up

```
Great to hear from you, [Name]!

[Answer their question or address their concern]

Are you available [specific day/time] for a 15-minute call?

Alternatively, here's my calendar link: [link]
```

### "Not Interested" Response

```
Totally understand, [Name]. Thanks for letting me know.

If anything changes, feel free to reach out. I'll keep sharing content that might be useful.

Best of luck with [Company]!
```

### "Send Me Info" Response

```
Happy to share more, [Name]! What would be most helpful?

1. Case study from [similar client]
2. Pricing overview
3. Quick 10-minute call to discuss your specific needs

Let me know and I'll send it right over.
```

## 9. Price Negotiation Templates

### Initial Price Discussion

```
For [project scope], my rate is $[rate]/hr or $[fixed price] fixed price.

This includes [specific deliverables] and [specific value-adds].

Based on similar projects, you can expect [specific outcome] within [timeframe].
```

### Handling "Too Expensive"

```
I understand $[price] is an investment. Here's what that investment gets you:

[Value point 1]: Worth $[X]
[Value point 2]: Worth $[X]
[Value point 3]: Worth $[X]

The total value is $[X], and the ROI is typically [X]x within [timeframe].

I also offer a [cheaper option] at $[lower price] if that fits better.
```

### Offering Alternatives

```
I totally understand budget constraints. Here are options:

Option 1 (Full scope): $[price] — includes everything we discussed
Option 2 (Core only): $[price] — includes [core features], delivers [core outcome]
Option 3 (Phased): Start with $[price] for phase 1, then $[price] for phase 2

Which approach works best for you?
```

## 11. Objection Handling Templates

### "We Don't Have Budget"

```
Totally understand. Budget is always a consideration.

A few thoughts:
1. The cost of NOT solving this is [specific cost/month]
2. My solution typically pays for itself within [timeframe]
3. We could start with a smaller scope to fit your budget

What would make this feasible for you?
```

### "We Already Work With Someone"

```
That's great! Glad you have a good relationship.

If anything changes or you need additional capacity, I'd love to be a backup option.

No hard feelings either way.
```

### "Send Me Your Brochure/Website"

```
I actually don't have a brochure — I work closely with each client and customize my approach.

But here's what I can share:
1. [Case study link]
2. [Relevant portfolio item]
3. [Testimonial]

The best way to see if we're a fit is a 15-minute call. Want to schedule one?
```

### "I'm Not the Right Person"

```
Thanks for being honest! Who would be the right person to talk to about [topic]?

If you can point me in the right direction, I'd really appreciate it.
```

### "We'll Circle Back"

```
Totally understand. When would be a good time to check back?

I don't want to be a pest, so if you give me a specific month, I'll make a note and follow up then.
```

## Final Truth

Templates are starting points, not crutches. The best outreach feels personal, not templated.

Use these templates to save time on structure, but invest time on personalization. A template that's 80% stock + 20% personalized beats a template that's 100% stock.

The difference between a template that converts and one that doesn't: specificity. Generic templates die. Specific templates fly.
