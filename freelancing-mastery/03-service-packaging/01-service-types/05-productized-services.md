# Productized Services

## Overview

Productized services are fixed-price, fixed-scope offerings with a clear deliverable and a known price. Instead of "I build websites" you sell "Website Audit $500" or "AI Chatbot Setup $3,000." Productization is the single fastest way to scale a service business because it removes the #1 bottleneck in freelancing: custom proposals for every lead.

## Why Productized Services Are the Key to Scaling

| Metric | Custom Service | Productized Service |
|--------|---------------|-------------------|
| Time to proposal | Days | Minutes |
| Time to close | Weeks | Days |
| Delivery consistency | Varies | Predictable |
| Pricing negotiation | Always | Rarely |
| Client education | Significant | Minimal |
| Upsell potential | Low | High (tiered) |
| Subcontractor onboarding | Hard | Easy |
| Scalability | Limited | Unlimited |

## Characteristics of Great Productized Services

### 1. Well-Defined Scope
"Website Audit" not "Website Help." Every client gets exactly the same thing.
- What's included (explicit list)
- What's NOT included (explicit list)
- What they receive (deliverables)
- Timeline (fixed, e.g., 5 business days)

### 2. Fixed Price
No variation. $500 for the audit. Every time. Price is listed on your website.
- No customization
- No negotiation
- No "it depends"

### 3. Clear Outcome
Client knows exactly what they're getting before they pay.
- "You'll receive a 15-page PDF with 30+ action items"
- "Your chatbot will be live within 48 hours"
- "You'll get a prioritized list of 20 security vulnerabilities"

### 4. Quick Delivery
Days or weeks, not months. Under 2 weeks ideal.
- Faster delivery = faster cash flow
- Lower cognitive load for you
- Easier to guarantee satisfaction

### 5. Low Client Involvement
You don't need their time beyond initial information gathering.
- No ongoing meetings
- No feedback loops
- No back-and-forth

## How to Productize a Service

### Step 1: Identify What You Already Do
Look at your last 5-10 projects. What patterns emerge?
- What do 80% of clients ask for?
- What can you deliver with minimal customization?
- What provides high value with low effort?

**Example:**
If 8/10 web dev clients ask for a "website speed optimization," create a "Website Speed Optimization Package — $1,000 — 1 week."

### Step 2: Define the Scope Rigidly

| What's Included | What's NOT Included |
|----------------|-------------------|
| Performance audit | Content creation |
| 10 optimization recommendations | Design changes |
| Implementation of top 3 fixes | Third-party tool subscriptions |
| Before/after comparison report | Ongoing monitoring |
| 30-minute walkthrough call | Additional revisions |

### Step 3: Set a Fixed Price
Base it on your experience:
- Time to deliver: 20 hours
- Desired hourly: $150/hr
- Price: $3,000

Or base it on value:
- Client outcome: "Improve conversion rate by 15%"
- Value to them: $30k/year
- Your fee: $3,000 (10x ROI for them)

### Step 4: Package It Attractively

**Naming matters:**
- "Website Audit" → "Conversion Growth Audit"
- "Code Review" → "Production Readiness Review"
- "Security Scan" → "Security Shield Assessment"

**Use comparisons:**
- Before/after metrics
- "Your website is slow" → "Your website loads in 1.2 seconds"
- "You have vulnerabilities" → "Your system is PCI compliant"

### Step 5: Build a Sales Page
```
Product: [Name]
Price: $[Price]
Timeline: [X days/weeks]

What You Get:
- Deliverable 1
- Deliverable 2
- Deliverable 3

Who This Is For:
- [Client type 1]
- [Client type 2]

Who This Is NOT For:
- [Client type to avoid]

How It Works:
1. You buy
2. You fill out intake form (5 min)
3. I deliver in X days
4. Optional: 30-min review call

Guarantee: [Your guarantee]

Buy Now
```

## Creating a Productized Service Funnel

### The Tripwire ($200-$500)
A low-cost entry that's profitable on its own.
**Example:** Website Audit $500
- Low commitment for client
- Low effort for you (5-10 hours)
- Easy to sell (it's $500, not $5,000)
- High conversion rate

### The Core Offer ($1,000-$5,000)
The productized service you actually want to sell.
**Example:** Website Redesign $3,500
- Substantial value
- Good margins ($100-$200/hr effective)
- Clear outcome
- 1-3 week delivery

### The Premium Offer ($5,000-$15,000)
High-ticket version with expanded scope.
**Example:** Full Marketing Site Build $12,000
- 4-6 week delivery
- Includes everything from core + more
- Tiered upsell from core

### The Upsell Path
Tripwire → Core → Premium → Retainer

```
$500 Audit → $3,500 Redesign → $12,000 Full Build → $2,000/mo Maintenance
```

## Sales Process for Productized Services

### The No-Call Close
Best part of productized services: you can sell without calls.
- Client visits website
- Sees price and deliverables
- Buys with credit card
- You deliver

### The Low-Friction Call
If calls are needed:
1. Schedule via Calendly (15 min)
2. Qualify: "This is for [specific service], right?"
3. Answer questions
4. Send payment link
5. Done

### Handling Price Objections
Objection: "That seems expensive for 5 days of work"
Response: "The price reflects the outcome, not the hours. [Client X] got [Y result] from this service. That's worth more than $500."

Objection: "Can you do it cheaper?"
Response: "This is a fixed-price service. What I can do is adjust the scope — let me show you what changes if we reduce scope."

## Managing Delivery at Scale

### The Productization Mindset
Every service delivery should make the NEXT delivery faster.
- Build SOPs
- Create templates
- Automate repetitive tasks
- Track time to improve estimates

### Batch Processing
If you sell the same service multiple times:
- Audit all websites on the same day
- Generate reports in batch
- Send all deliverables same day

### Subcontractor Enablement
Productized services are easy to delegate because scope is fixed.
- Write the SOP
- Train once
- Quality check template
- Let them deliver

## Pricing Productized Services

### Cost-Plus Pricing
```
Hours: 20 hours
Desired hourly: $150/hr
Cost: $3,000
Overhead (20%): $600
Price: $3,600
```

### Value-Based Pricing
```
Client: E-commerce store doing $100k/mo
Problem: 3% conversion rate
Potential: 4% conversion rate = $33k/mo more
Your value: $33k/mo or $400k/year
Your price: $5,000 (1.25% of annual value)
```

### Market-Based Pricing
- Research what competitors charge for similar
- Price at 80-120% of market
- Adjust based on your positioning

### Price Raising Strategy
| Version | Price | What's Included |
|---------|-------|----------------|
| V1 (beta) | $250 | Reduced scope, longer delivery |
| V2 (launch) | $500 | Full scope |
| V3 (established) | $750 | Full scope + priority |
| V4 (premium) | $1,000 | Full scope + priority + video walkthrough |

Raise prices when:
- You're consistently booked 3+ weeks out
- You're turning away work
- You've delivered 10+ successfully
- You've improved delivery efficiency

## Case Study: Productized Service in Action

### The $500 Website Audit
**Pre-work (30 min):**
- Run automated tools (Lighthouse, GTmetrix, WAVE)
- Manual review of homepage + top 3 pages
- Screenshot key issues

**Analysis (3 hours):**
- Performance bottlenecks
- SEO issues
- Security concerns
- UX improvements
- Accessibility problems

**Report (2 hours):**
- Executive summary (1 page)
- 15-page detailed report
- 20-30 prioritized action items
- Before/after metrics comparison
- Priority matrix (impact vs effort)

**Walkthrough (30 min):**
- Screen recording or live call
- Highlight top 5 actions
- Answer questions

**Total time: 6 hours**
**Effective rate: $500 / 6 = $83/hr** (for the first few)
**After optimization: $500 / 3 hours = $167/hr** (with templates)

## Scaling Productized Services

### Phase 1: Founder-Only
- 3-5 productized services
- You deliver everything
- $5k-$15k/month

### Phase 2: With SOPs
- Document everything
- Build templates
- Use automation
- $10k-$25k/month

### Phase 3: First Hire
- Hire for delivery (cheaper location or junior)
- You focus on sales + quality
- $20k-$40k/month

### Phase 4: Agency Model
- 5+ services
- 3-5 delivery people
- $50k-$100k+/month

## Summary Rules

1. Every service can be productized — find the pattern
2. Fixed scope, fixed price, fixed timeline
3. Never customize (that's consulting, not productized)
4. List price on your website (no "contact for pricing")
5. Low-ticket entry = high-volume lead gen
6. Automate everything (booking, onboarding, delivery)
7. Batch deliver similar services together
8. Raise prices every 10 deliveries
9. Build SOPs from day one
10. Use for inbound marketing (published case studies)
11. Referral fees for partners (20%)
12. Always have an upsell path
