# Quick-Start Packages — Copy and Use

## How to Use These Packages

Each package below is ready to copy-paste into a proposal, sales page, or client email. Fill in `[bracketed]` values with your specific details. Each package includes:

1. **Package name** — compelling offer title
2. **Target client** — who this is for
3. **The promise** — one-line outcome
4. **What's included** — bullet list of deliverables
5. **Timeline** — delivery timeframe
6. **Investment** — price and payment options
7. **Guarantee** — risk reversal statement

## How to Customize These Packages

### The "Find and Replace" Customization

For each package you use:

1. **Replace the price** — adjust based on your experience, market, and the client
2. **Add your personal guarantee** — make it stronger if you have the confidence
3. **Include specific examples** — "Similar to what we did for [past client]"
4. **Add relevant case studies** — link to past work that demonstrates capability

### The "Package Builder" Template

If you need to create custom packages for a specific client:

```
## PACKAGE NAME

**For:** [Who this is for]
**The Promise:** [Single outcome in one sentence]

**What's Included:**
- [Deliverable 1]
- [Deliverable 2]
- [Deliverable 3]
- [Deliverable 4]
- [Deliverable 5]

**Not Included:**
- [Out of scope 1]
- [Out of scope 2]

**Timeline:** [X weeks/days]
**Investment:** $[Price]
**Payment:** [Payment terms]
**Guarantee:** [Risk reversal statement]
```

## Sales Tips for Each Package

- Lead with the guarantee, not the price
- Show the value first: "This [package] typically saves clients $X/year"
- Use the package name consistently in all communications
- Present 3 packages in a proposal (Good/Better/Best) using these as components
- Always have a next step after delivering a package (upsell to retainer)
- Collect testimonials after every package delivery for social proof

## Summary Rules

1. Copy, paste, customize — these are templates, not final versions
2. Every package needs a clear, specific outcome
3. Every package needs a strong guarantee
4. Every package needs explicit "not included" items
5. Link packages together (audit → fix → retainer)
6. Collect testimonials for every completed package
7. Raise prices after every 5 package sales
8. Use package names consistently across website, proposals, and invoices
9. Always have 3 tiers available (these are the "Pro" tier)
10. Customize the "For" section to match your exact target client
