# Retainer Scope

## Why Scope Is the Difference Between Profit and Pain

Scope defines your retainer's profit margin. Vague scope = scope creep = you work more hours than you're paid for. Every hour you spend outside scope is an hour you're working for free.

The rule: **If it's not in scope, it doesn't get done without a change order.** Period. No exceptions.

This guide gives you the exact language, boundaries, and processes to define and enforce retainer scope.

---

## Defining What's Included

### The Included Services Framework

Every scope document must answer: "What exactly does the client get each month?"

**Category 1: Maintenance Services (Routine)**

- Plugin/library/package updates (minor and security)
- CMS core updates (WordPress, Drupal, etc.)
- Server OS and security patches
- SSL certificate renewal monitoring
- DNS record verification
- Database optimization and cleanup
- Log rotation and disk space monitoring
- Backup verification and restoration testing
- Broken link checks
- Forms and integrations testing

**Category 2: Support Services (Reactive)**

- Bug triage and prioritization
- Critical issue response (defined by SLA)
- Non-critical issue resolution
- User access management
- Error log analysis
- Performance degradation investigation
- "How do I?" questions (up to 30 min/day)

**Category 3: Monitoring Services (Proactive)**

- Uptime monitoring (5-minute intervals)
- Performance monitoring (response time, load time)
- Security monitoring (login attempts, file changes)
- Error rate monitoring
- Resource utilization (CPU, RAM, disk, bandwidth)
- Traffic analysis and anomaly detection
- Third-party service status checks

**Category 4: Reporting Services (Ongoing)**

- Monthly uptime report
- Monthly change log
- Monthly performance summary
- Incident report (if applicable)
- Recommendations for next month
- Hours worked vs. retainer allocation

**Category 5: Strategy Services (Advisory)**

- Monthly strategy call (30-60 min)
- Quarterly technical audit
- Roadmap planning assistance
- Architecture recommendations
- Tool and vendor evaluation

### Sample Scope Document (Professional Tier - $3k/month)

```
INCLUDED SERVICES (Monthly)

TECHNICAL MAINTENANCE
- Weekly WordPress/package updates for all plugins and themes
- Monthly core updates with staging environment testing
- Daily automated backups with weekly verification
- SSL certificate monitoring and renewal assistance

SUPPORT
- Priority email support with 4-hour response during business hours

- Content updates: text changes, image replacements, minor layout tweaks

MONITORING
- 24/7 uptime monitoring with SMS/email alerts
- Weekly security scan and malware check
- Monthly performance audit (PageSpeed, Core Web Vitals)

REPORTING
- Weekly status update (email summary)
- Monthly detailed report with metrics and recommendations
- Quarterly strategic review meeting

- 10 hours of work per month included
- Hours tracked through Toggl with shared access
- Monthly reports show time allocation
```

## The Exclusions Document (Critical)

### What MUST Be Excluded

Every scope document needs an explicit "Not Included" section. This is your contract armor. Be specific:

**EXCLUDED SERVICES**

```
The following services are NOT included in the monthly retainer:

1. New feature development (beyond 2 hours/month)
2. Third-party API integrations
3. Database migration or schema changes
4. Major version upgrades (e.g., WordPress 5.x → 6.x)
5. Redesign or rebranding work
6. Content creation or copywriting
7. SEO strategy and implementation
8. Paid advertising management (Google Ads, Facebook Ads)
9. Migration to new hosting provider
10. Security incident recovery (beyond initial triage)
11. Code review of third-party contributions
12. Performance optimization requiring architecture changes
13. Training sessions for new team members
14. Documentation creation beyond basic runbooks
15. Integration with new tools/platforms
16. Custom development exceeding [2] hours per item
17. Data entry or manual content population
18. Social media management
19. Email marketing management
20. Any service not explicitly listed as included

Work in these areas will be scoped separately under a Statement of Work
at standard project rates ($150/hour or fixed price per deliverable).
```

### The "Gray Area" Rule

For items that could go either way:

```
Gray Area Services. The following services may occasionally fall within
scope at Consultant's discretion, but are not guaranteed:

- Minor CSS adjustments (under 30 minutes)
- Plugin configuration changes
- User permission audits

If a gray area service exceeds 30 minutes, it will be treated as
out-of-scope and requires a change order.
```

## Overage Billing: Where the Real Money Is

### The Overage Model

Overage billing is your profit center. It's where you make your highest margins because:

1. The client has already agreed to premium rates for overages
2. Overage work is usually urgent (client can't wait)
3. There's no negotiation on price (it's in the contract)

### Overage Rate Structure

| Retainer Tier | Monthly Hours | Overage Rate (Standard) | Overage Rate (Emergency) |
|--------------|---------------|----------------------|------------------------|
| Essential ($1k) | 5 | $200/hr | $300/hr |
| Professional ($3k) | 15 | $200/hr | $300/hr |
| Premium ($5k) | 25 | $225/hr | $350/hr |
| Elite ($10k) | 40 | $250/hr | $400/hr |

**Contract language:**
```
Hours exceeding the monthly retainer allocation will be billed at
$200/hour in 15-minute increments, invoiced monthly. Emergency
requests (requiring response within 2 hours outside business hours)
will be billed at $300/hour. All overage work must be pre-approved
by Client via email.
```

### The 15-Minute Increment Rule

Always bill in 15-minute increments. Never round down. Track everything:

```
Work completed: 3 minutes fixing a CSS issue
Billable: 15 minutes (minimum increment)
Revenue: $50 (at $200/hr)

10 small fixes per month at 15 min each: 2.5 hours = $500 in overage
```

### How to Create Overage Opportunities

**Strategy 1: Scope conservatively**
Deliberately exclude tasks that often come up. Let them become overage.

**Example:** "Small feature requests" are defined as "under 2 hours." Anything more is overage. A 3-hour feature = $600 overage.

**Strategy 2: Offer "same-day" as premium**
Standard SLA is 24-48 hours. Same-day response costs extra. Clients who need things fast pay more.

**Strategy 3: Quarterly "health checks"**
These aren't included in standard retainer. They're $1,000-$3,000 additional. Clients with retainers almost always buy them.

**Strategy 4: Holiday/coverage periods**
You're available during holidays, but at 2x overage rates. Clients with critical systems will pay.

### Overage Billing Process

1. **Track everything** — Use time tracking that's visible to client
2. **Pre-approval required** — "This will take ~3 hours, putting us over the 15-hour retainer. OK to proceed at $200/hr?"
3. **Same-month billing** — Overage is billed with the current month's invoice
4. **Monthly cap** — Optional: "Overage won't exceed 50% of retainer fee without written approval"

### Why Reporting Matters

Clients need to SEE the value. If you don't report, they don't remember what you did. If they don't remember, they question the retainer. If they question it, they cancel.

A good report:
- Shows exactly what you did (quantified)
- Shows what problems you prevented
- Makes the client feel smart for hiring you
- Justifies next month's retainer payment
- Documents scope changes for potential price increases

### Quarterly Business Review (QBR)

Every 3 months, do a deeper review meeting. This is your upsell opportunity.

**QBR agenda (60 min):**
1. Last quarter recap (10 min) — wins, metrics, incidents
2. Value quantification (10 min) — "Here's what you would have spent without us"
3. Upcoming needs (15 min) — What's changing in their business
4. Recommendations (15 min) — New services, upgrades, projects
5. Contract review (10 min) — Adjust scope, pricing, or tier

**QBR value quantification formula:**
```
Cost of incidents prevented: $X (estimated)
Development hours saved: Y hours × $Z/hr internal cost = $X
Performance improvements: X% conversion improvement × $Y avg order = $X
Total value delivered: $X
Retainer cost: $Y
ROI: ($X - $Y) / $Y = Z%
```

**Example:**
```
Incidents prevented (3 critical bugs found before deployment): $15,000
Dev hours saved (team didn't need to context-switch): 40 hrs × $100 = $4,000
Performance improvement (2% conversion lift on $500k/month): $10,000
Total value: $29,000
Retainer cost: $6,000
ROI: 383%
```

## Scope Creep: Detection and Prevention

### The 5 Signs of Scope Creep

1. **Increasing communication volume** — More emails, more Slack messages, more "quick questions"
2. **The "while you're in there" requests** — "Oh, could you also fix this small thing?"
3. **Expanding definition of "bug"** — What was a feature request is now a "bug fix"
4. **Blurring of SLA lines** — Non-urgent requests getting labeled "urgent"
5. **Your hours creeping up** — You're consistently exceeding retainer hours by 20%+

### Monthly Scope Audit

Each month, ask yourself:

```
1. Did I work more hours than the retainer covers? Yes / No
   If yes, by how much? ___ hours
   Value of unpaid work: ___ hours × $___/hr = $___

2. Did I do work that's explicitly excluded? Yes / No
   If yes, list: ___

3. Did I receive "quick questions" that turned into work? Yes / No
   If yes, how many? ___

4. Did the client request the same thing multiple times? Yes / No
   If yes, it's probably a feature, not a bug fix.

5. Am I dreading this client's messages? Yes / No
   If yes, the retainer isn't profitable enough for the headache.
```

### The Scope Boundary Scripts

**When client asks for out-of-scope work:**
"I'd be happy to help with that. Just a heads up, this isn't included in the retainer scope. I can either scope this as a separate project, or we can add it to the retainer when we review next month. For now, I'll estimate it at about 4 hours — would you like me to proceed at the overage rate of $200/hour?"

**When client says "it'll just take 5 minutes":**
"I understand it seems quick, and it might be. But I've learned that these small requests add up across all my clients. To keep things fair and predictable, I track everything. If it truly takes 5 minutes, I'll only bill 15 minutes (minimum increment)."

**When client tries to redefine scope:**
"I want to make sure I deliver what you need. The original retainer scope covers [X, Y, Z]. This request seems more like [category]. Let me put together a quick scope document so we're aligned on what this entails and whether it fits within the retainer or should be scoped separately."

**When you need to push back:**
"I value our partnership and want to make sure I'm delivering the best possible service within our agreement. Over the past few months, I've noticed an increase in [type of request], which falls outside the retainer scope. Let's discuss how to handle this going forward — would you like to upgrade the retainer tier, or should I bill these as overage?"

## Retainer Scope Expansion (Upselling)

### The Upgrade Path

| Current Tier | Upgrade To | Triggers | New Monthly Revenue |
|-------------|-----------|----------|---------------------|
| $1k (Essential) | $3k (Professional) | Client needs more changes, faster response | +$2,000/month |
| $3k (Professional) | $5k (Premium) | Client growing, needs 24/7, more strategy | +$2,000/month |
| $5k (Premium) | $10k (Elite) | Client has full-time work for you | +$5,000/month |
| $10k (Elite) | +Add-ons | Additional services, team members | Variable |

### When to Propose an Upgrade

1. **After 3 consecutive months of overage billing** — "You're consistently using 20+ hours. The Premium tier would save you money."
2. **After a major win** — "Given the 300% ROI we delivered this quarter, I think it's time to expand our engagement."
3. **When their business grows** — "Congratulations on the funding round. Let's talk about how I can support you at the next level."
4. **During QBR** — Built into the natural review cycle.

### The Upgrade Pitch Script

```
"I've been tracking our engagement over the past few months, and I
noticed you're consistently using about 22 hours/month of my time.
With the $3k retainer covering 15 hours, that's about $1,400/month
in overage billing.

I'd suggest moving to the Premium tier at $5k/month for 25 hours.
You'd get:
- All your current work covered (no more overage tracking)
- 24/7 support (you're growing, and you'll need this)
- Weekly strategy calls instead of monthly

Your total cost goes from $4,400/month ($3k + $1.4k overage) to
$5,000/month. More service for $600 more. And you get the predictability
of a fixed price.

Does that make sense?"
```

## Multiple Retainer Client Management

### Time Allocation Across Clients

```
Weekly capacity: 30 hours of retainer work maximum
Maximum retainer clients (solo): 6-8
Ideal mix: 3-4 high-value clients + 2-3 lower-value (easy) clients

Sample week:
- Monday: Client A (deep work, 4 hrs) + Client B (maintenance, 2 hrs)
- Tuesday: Client C (deep work, 4 hrs) + Client A (support, 2 hrs)
- Wednesday: Client D (strategy, 2 hrs) + Client E (maintenance, 3 hrs)
- Thursday: Buffer day (catch-up, overage, emergencies, 4 hrs)
- Friday: Reporting, planning, education (4 hrs)
```

### Scope Conflicts Between Clients

Policy: First-come, first-served for urgent issues. Pre-scheduled work maintains its slot. No client gets priority over another unless they've paid for a higher tier.

```
Conflict resolution:
- Both have emergencies → Critical tier gets priority response
- Overlapping scheduled work → Negotiate reschedule, no penalty
- One client chronically interrupting → Move them to higher tier or fire them
```

## Firing Clients: When to Cut Scope

### Signs It's Time to Fire

1. Client exceeds retainer hours by 50%+ for 3+ months and refuses to upgrade
2. Client is consistently rude, disrespectful, or demanding
3. Client doesn't pay on time (2+ late payments)
4. Client asks you to do unethical or risky work
5. Client's project/company is failing and they're taking you with them
6. Client's requests are causing you burnout
7. Client doesn't respect scope boundaries despite repeated conversations

### The Firing Process

**Step 1: Attempt correction**
Have the scope conversation. Explain the issue. Give them 30 days to improve.

**Step 2: Send transition notice**
```
Subject: Transition of [Service] — 30-Day Notice

Hi [Name],

After careful consideration, I've decided to transition my retainer
services with [Company] to a new arrangement.

Per our agreement, this is my 30-day written notice. I'll continue
full support through [date]. During this period, I'll help ensure
a smooth transition to whoever takes over.

I've enjoyed working with you and want to make sure you're set up
for success. Let me know how I can help with the transition.

Best,
[Your Name]
```

**Step 3: Provide transition support**
- Document all systems, credentials, and processes
- Offer 10 hours of transition support (billed or free depending on circumstances)
- Recommend alternatives (other freelancers, agencies, tools)

**Step 4: Hold the line**
Don't let them guilt you into staying. A bad client at $3k/month costs you $10k/month in potential revenue from better clients. Every hour you spend on them is an hour you can't spend on your ideal clients.

## Scope Enforcement Tools

### Automated Scope Enforcement

- **Time tracking with client visibility:** Toggl, Harvest, Clockify
- **Ticketing system:** Linear, Trello, or GitHub Projects for request tracking
- **Automated reminders:** Zapier sends "You've used X% of your retainer hours" alerts
- **Scope gate:** Buddyboss or custom solution that blocks requests once hours are exhausted

### Ticketing Workflow

```
Client submits request → Ticket created in system
→ Ticket categorized (In Scope / Out of Scope / Gray Area)
→ In Scope → Added to queue, tracked against retainer hours
→ Out of Scope → Estimate generated, approval requested, overage billed
→ Gray Area → 30-min triage, then decision

When hours are exhausted:
- New tickets: Auto-response: "Retainer hours exhausted for this month.
  Proceed at $200/hr? Reply YES for estimate."
- Priority queue: Critical issues only (defined by SLA)
```

### The "Stop Work" Clause

For chronic overage abusers:

```
If Client's monthly hours exceed the retainer allocation by more than 50%
in any two months during the agreement term, Consultant reserves the right
to pause all non-critical work until an upgraded retainer tier is agreed
upon or overage payment is received.
```

## Annual Scope Review Process

### Month 11 of 12 (Before Renewal)

1. **Analyze 12 months of data:**
   - Average hours per month
   - Overage hours and revenue
   - Scope creep items that became "regular"
   - Value delivered (quantified)

2. **Determine new scope:**
   - What should be added to retainer? (services you deliver regularly anyway)
   - What should be removed? (services they never use)
   - What should be added at additional cost? (new services)

3. **Propose renewal:**
   - Option A: Same scope, X% price increase (inflation + value bump)
   - Option B: Expanded scope at higher tier (if they're using overage)
   - Option C: Reduced scope at current price (if they want to save)

4. **Renewal conversation:**
   "Based on our work together this year, I'd recommend we [keep scope / expand / restructure]. Here's what I'm proposing for Year 2..."
