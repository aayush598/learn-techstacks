## Choosing Your Course Topic

### The Topic Selection Framework

A profitable technical course needs three things:

1. **High demand** - People are actively searching for this knowledge
2. **Your expertise** - You know this topic deeply (from client work)
3. **Clear outcome** - Student achieves a specific result

### Topic Validation Questions

Before investing weeks into a course:

```
1. Are people paying for this knowledge? (check competitors)
   - If no one sells a course on this, demand might not exist
   - If 3-10 competitors exist, demand is validated

2. Can students achieve a clear, measurable outcome?
   - "Build a SaaS from scratch" = clear outcome
   - "Learn React" = too vague
   - "Deploy a production app" = clear outcome

3. Is there an audience I can reach?
   - Do they hang out on Twitter/YouTube/Reddit?
   - Do they read specific blogs or newsletters?
   - Can I reach 10,000+ potential students?

4. Can I teach this without deep-diving into prerequisites?
   - Target: Intermediate developers
   - Too beginner: "Learn to code" (millions of competitors)
   - Too advanced: "Advanced distributed systems" (too niche)
   - Sweet spot: "Build and deploy a production [X]"
```

## Course Structure: The Blueprint

### The 80/20 Outline

80% of the value comes from 20% of the content. Focus on that 20%.

**Bad outline:** 50+ videos covering every possible topic
**Good outline:** 20-30 videos covering the critical path to a specific outcome

### Course Structure Template

```
MODULE 1: Foundation (15% of course)
- Lesson 1.1: What you'll build and why
- Lesson 1.2: Environment setup
- Lesson 1.3: Core concepts
- Lesson 1.4: First code

MODULE 2: Core Build (40% of course)
- Lesson 2.1-2.10: Building the main features step by step
- Each lesson produces a working increment

MODULE 3: Polish & Production (25% of course)
- Lesson 3.1: Error handling
- Lesson 3.2: Testing
- Lesson 3.3: Performance optimization
- Lesson 3.4: Security best practices

MODULE 4: Deploy & Launch (20% of course)
- Lesson 4.1: Deployment setup
- Lesson 4.2: CI/CD pipeline
- Lesson 4.3: Monitoring and analytics
- Lesson 4.4: Launch checklist
- Lesson 4.5: What's next

BONUS: Pro tips from real-world experience
- "This is what I learned doing this for clients"
- "Don't make these mistakes I made"
- Advanced patterns
```

### Video Length Guidelines

- **Introduction:** 2-3 minutes (hook + what they'll learn)
- **Core lesson:** 8-15 minutes (deep work)
- **Review/wrap-up:** 3-5 minutes (recap + next steps)
- **Total per module:** 45-90 minutes
- **Total course:** 4-8 hours (sweet spot)

**Why short videos work:**
- Students can watch during breaks
- Easier to update individual lessons
- Lower abandonment rate
- Better for YouTube previews

## Creating the Course Content

### Screen Recording Setup

**Minimum viable setup:**
- Mac: QuickTime Player + CleanShot X ($29)
- PC: OBS Studio (free) + built-in audio
- Audio: Any USB microphone ($50-$150)

**Recommended setup:**
- Screen recording: ScreenFlow ($149) or Camtasia ($249)
- Microphone: Blue Yeti ($100) or Rode NT-USB ($150)
- Camera: Logitech C920 ($70) or phone camera
- Lighting: Ring light ($30)
- Editor: DaVinci Resolve (free) or Final Cut Pro ($300)

**Audio is non-negotiable:**
- Bad video quality is acceptable
- Bad audio quality is DEATH for courses
- Invest in a good microphone first

### Recording Best Practices

**Before recording:**
- Write a script or detailed outline
- Close all unnecessary apps
- Turn off notifications
- Clean your desktop
- Set zoom level to readable size
- Do a 1-minute test recording

**During recording:**
- Speak at conversational pace (not too fast)
- Pause between sentences (makes editing easier)
- Say what you're doing before you do it
- If you mess up, pause, clap (visual cue), restart the sentence
- Keep it natural, not robotic

**After recording:**
- Remove long pauses and mistakes
- Add zoom-ins on important areas
- Lower background music during speaking
- Add captions (great for SEO and accessibility)

### Course Code Repository

Every course needs companion code:

```
course-name/
  starter/             # Starting point for each module
  completed/           # Completed code after each module
  final/               # The complete finished project
  exercises/           # Practice exercises
  resources/           # Links, cheatsheets, references
  README.md            # Course overview and setup instructions
```

## Marketing Your Course

### Pre-Launch (4-6 Weeks Before)

**Phase 1: Build anticipation**

1. Announce you're creating the course (Twitter/LinkedIn)
2. Share your outline and ask for input
3. Offer a "pre-order at 50% off" discount
4. Start an email list specifically for the course

**Phase 2: Content marketing**

1. Write 3-5 blog posts related to the course topic
2. Record 3-5 YouTube tutorials (preview content)
3. Post daily tips on Twitter
4. Engage in relevant communities

**Phase 3: Launch week**

1. Email list (every 2-3 days with value + updates)
2. Launch day: Big announcement with limited-time discount
3. Day 2-3: Social proof (testimonials, early reviews)
4. Day 5: "Last chance" reminder
5. Day 7: Launch closes (creates urgency)

### Content Funnel for Courses

```
FREE CONTENT (Top of Funnel)
- YouTube tutorials
- Blog posts
- Twitter threads
- Free email course (5 days)
- Downloadable cheatsheet

-> Leads to:

PAID PREVIEW (Middle of Funnel)
- Free first module of your course
- Sample video from each section
- Full course outline
- Student testimonials

-> Leads to:

FULL COURSE (Bottom of Funnel)
- Complete access
- Community/Discord
- Code repository
- Certificate
```

### Social Proof Strategies

**Before launch (with beta testers):**
- "This course helped me build [X] in 2 weeks"
- "Finally a course that teaches production [topic]"
- "[Instructor] answered my questions within hours"

**Screenshot format:**
"I went from [before] to [after] after taking [course]."

**Video testimonial format:**
"I was stuck on [problem]. After this course, I built [result] in [timeframe]."

### Launch Pricing Strategy

| Timing | Price | Psychology |
|--------|-------|------------|
| Pre-order (4 weeks before) | $99 | Risk-free, biggest discount |
| Launch day | $149 | Limited-time launch price |
| Week 2 | $199 | Regular price |
| Evergreen | $299 | Full price |

**Create urgency with real deadlines.** "Pre-order ends Sunday at midnight." Then actually end it.

## Ebooks for Developers

### Why Write a Technical Ebook

- Quickest to create (40-80 hours)
- Lower barrier to purchase ($19-$49)
- Builds authority for higher-ticket offers
- Lead magnet for email list
- Can expand into a course later

### Ebook Types That Sell

**1. The "Complete Guide" ($29-$49)**
"Complete Guide to [Topic]" - Comprehensive, 100-200 pages

Best topics:
- "Complete Guide to Next.js 14"
- "Complete Guide to AWS Deployment"
- "Complete Guide to TypeScript"

**2. The "Playbook" ($19-$39)**
Actionable, step-by-step recipes. Less theory, more code.

Best topics:
- "React Performance Playbook"
- "Startup Deployment Playbook"
- "Freelance Pricing Playbook"

**3. The "Cookbook" ($29-$49)**
50-100 specific solutions to specific problems.

Best topics:
- "React Testing Cookbook"
- "Python Automation Cookbook"
- "Docker Cookbook"

**4. The "Case Study" ($19-$29)**
"How we built [X] at scale" - Real-world case study.

Best topics:
- "How we scaled to 1M users"
- "Migrating from [tech] to [tech]"
- "Building a SaaS from $0 to $10k MRR"

### Ebook Pricing

| Format | Length | Price | Typical Sales | Revenue |
|--------|--------|-------|---------------|---------|
| Short guide | 30-50 pages | $19 | 500-2,000 | $9,500-$38,000 |
| Complete guide | 100-200 pages | $39 | 300-1,000 | $11,700-$39,000 |
| Bundle (3 ebooks) | 300+ pages | $79 | 100-500 | $7,900-$39,500 |
| Premium (hardcover) | 200+ pages | $49-$79 | 200-500 | $9,800-$39,500 |

### Distribution for Ebooks

1. **Gumroad** - Best for direct sales, PDF + EPUB
2. **Amazon Kindle** - Largest audience, 35-70% royalty
3. **Leanpub** - Writing platform + sales
4. **Your own site** - Highest margin

### From Ebook to Course

After publishing your ebook, expand into a course:
- Ebook = text version
- Course = video version + code + community
- Price: Ebook $39, Course $149
- Cross-sell both: "Buy the course, get the ebook free"

## Student Success = More Sales

### The Student Success Loop

Good course -> Students succeed -> Students tell others -> More sales -> Money to improve course -> More student success

### How to Ensure Student Success

1. **Clear prerequisites** - "You need to know React basics. Here's a free refresher."
2. **Quick wins** - First lesson produces a visible result
3. **Working code** - Every lesson code must work (test each one!)
4. **Community support** - Discord where you answer questions within 24 hours
5. **Progress tracking** - Show students how far they've come
6. **Certificate** - Even unaccredited, it motivates completion

### Handling Student Questions

| Question Type | Response Time |
|--------------|---------------|
| Bug in my code | 12 hours (this is urgent) |
| "How do I..." from course | 24 hours |
| Feature request | 1 week |
| Refund | Immediate |

**Reality:** 80% of support questions are answered by good documentation and FAQ. Invest in these upfront.
