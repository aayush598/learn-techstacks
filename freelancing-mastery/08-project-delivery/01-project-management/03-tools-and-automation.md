# Tools and Automation

## The Freelancer's Tech Stack for Maximum Efficiency

Every hour you spend on admin is an hour you're not billing. The right tools and automation eliminate busywork, reduce errors, and make you look professional.

This guide covers the complete freelancer tech stack — project management, time tracking, invoicing, client portals, and automation.

## Project Management Tools

### Linear (Best for Software Projects)

**Why use it:** Built for software teams. Fast, keyboard-driven, sprint management.

**Setup for Freelancers:**
1. Create a project per client
2. Set up teams: "Client Projects" (for billable work) and "Business" (for admin)
3. Use labels: `bug`, `feature`, `improvement`, `admin`
4. Use cycles (sprints) for time-boxed work

**Linear Workflow:**
```
Triage → Backlog → In Progress → In Review → Done
```

**Tips for Freelancers:**
- Use keyboard shortcuts (cmd+k for everything)
- Link Linear to GitHub for automatic status updates
- Use the "Today" view for daily focus
- Archive completed cycles for future reference

### Notion (Best for All-in-One)

**Why use it:** Combines project management, documentation, wiki, database, and notes.

**Notion Setup for Freelancers:**

## Time Tracking

### Why Track Time (Even on Fixed-Price Projects)

1. **Know your profitability** — Are you making $150/hr or $50/hr?
2. **Improve estimates** — Data drives better future pricing
3. **Prove value to clients** — Show hours saved vs. manual processes
4. **Tax compliance** — Track billable vs. non-billable
5. **Productivity insights** — Where does your time actually go?

### Toggl Track Setup

**Workspace Structure:**
```
Workspace: My Freelance Business
├── Clients
│   ├── Client A
│   │   ├── Project 1
│   │   └── Project 2
│   └── Client B
├── Internal
│   ├── Business Development
│   ├── Admin
│   └── Learning
```

**Tags for Better Tracking:**
```
Billable: development, design, meetings, research, testing
Non-billable: admin, marketing, learning, sales
```

**Automation with Toggl:**
- Auto-start timer when you open certain apps
- Pomodoro timer integration
- Idle detection (prompts you if you stop moving)
- Calendar integration (block time automatically)

### Time Tracking Script for Clients

"I track my time for transparency. Here's what I spent on your project this week:
- Development: 12 hours
- Meetings: 2 hours
- Research: 1 hour
- Total: 15 hours

Current budget utilization: [$X of $X remaining]
Timeline status: On track"

## Invoicing and Payments

### The Invoicing System

**Invoice Structure:**

| Field | Content |
|-------|---------|
| Invoice # | INV-001 (sequential) |
| Date | Issue date |
| Due date | Net 15 (or 7 for retainer) |
| From | Your name, address, tax info |
| To | Client company name, address |
| Description | Clear line items |
| Amount | Per item and total |
| Payment terms | Bank details, payment links |
| Late fee policy | "1.5% monthly on overdue balances" |

### Automated Invoicing Workflow

**Using FreshBooks / Wave:**

1. **Create recurring invoices** for retainers
2. **Set up automatic reminders** for due dates
3. **Enable online payments** (credit card, ACH)
4. **Auto-sync** with time tracking (Toggl → FreshBooks)
5. **Auto-categorize** expenses for tax time

**Invoicing Automation Rules:**

| Trigger | Action |
|---------|--------|
| Project milestone reached | Auto-generate invoice |
| Time tracked reaches threshold | Auto-generate partial invoice |
| Recurring date | Auto-send retainer invoice |
| Invoice 7 days overdue | Auto-send reminder email |
| Invoice 14 days overdue | Auto-send second reminder + late fee notice |
| Invoice 30 days overdue | Auto-flag for manual follow-up |

### Invoicing Payment Terms

| Term | When to Use |
|------|-------------|
| 50% upfront, 50% on completion | Small projects (<$5K) |
| 25/25/25/25 (milestone-based) | Medium projects ($5-20K) |
| Net 15 | Retainer clients |
| Payment on delivery | If you have leverage |
| Escrow (Upwork-style) | Unknown clients |

**The Late Payment Policy:**
"I charge a 1.5% monthly late fee on balances over 30 days past due. I also pause all work on past-due accounts until payment is received."

### Payment Automation

**Stripe Integration:**
- Set up recurring payment links
- Auto-charge credit cards on invoice due dates
- Send payment receipts automatically

**PayPal / Wise for International:**
- Auto-generate payment requests
- Currency conversion built in

**Why clients love it:** Everything in one place. No "where's that file?" conversations.

**Basecamp Structure for a Project:**

## Automation Workflows

### Zapier/Make Automations

**Essential Zaps for Freelancers:**

**Zap 1: New Proposal → Create Project**
```
Trigger: Proposal signed in PandaDoc
Action 1: Create project in Linear/Notion
Action 2: Create invoice in FreshBooks
Action 3: Send welcome email
Action 4: Create Slack channel
Action 5: Add to client portal
```

**Zap 2: Time Tracked → Update Budget**
```
Trigger: Time entry added in Toggl
Action: Update budget tracking in Notion/Google Sheets
```

**Zap 3: Invoice Paid → Send Receipt**
```
Trigger: Payment received in Stripe/FreshBooks
Action 1: Send payment confirmation email
Action 2: Update project budget in Notion
Action 3: Log payment in accounting software
```

**Zap 4: Form Submission → Create Task**
```
Trigger: Client submits feedback form
Action 1: Create task in project management
Action 2: Send notification to Slack
Action 3: Add to feedback database
```

**Zap 5: New Email → Create Lead**
```
Trigger: Email from unknown sender with keyword
Action 1: Create lead in CRM
Action 2: Send to Gmail label "Prospects"
Action 3: Create task to follow up
```

## The Million-Dollar Tools Mindset

Tools are not the solution. Systems are.

The best tool that you don't use is useless. The simplest tool that you use daily is invaluable.

Start with the minimum viable stack. Add tools only when the pain of not having them exceeds the cost and setup time.

The goal is not to have the most tools. The goal is to have the fewest tools that eliminate the most friction.

Automate everything that can be automated. Systematize everything that can't. Focus your energy on billable work and skill development.
