## Key Questions and Topics (2023 Paper)

### Analog Circuits Topics
- Op-amp circuits (inverting/non-inverting configuration)
- Schmitt trigger threshold calculations
- Feedback topology identification
- Class B amplifier efficiency
- Active filter cutoff frequency

### Digital Circuits Topics
- K-map simplification (4-variable)
- Flip-flop excitation table
- MUX implementation of Boolean function
- VHDL process sensitivity list
- FSM state diagram for sequence detector
- Metastability and MTBF calculation
- ADC resolution calculation

### EM/Microwaves/Antennas Topics
- Transmission line impedance matching
- Waveguide cutoff frequency (TE10 mode)
- S-parameter properties (reciprocal network)
- Antenna directivity and gain calculation
- Friis transmission equation application
- Microwave device identification (Gunn, IMPATT)
- VSWR calculation from reflection coefficient

### Communication Systems Topics
- AM modulation index and power calculation
- PCM quantization noise (SQNR formula)
- Nyquist sampling rate determination
- Shannon channel capacity
- Huffman coding average code length
- FM bandwidth using Carson's rule
- Binary communication channel error probability
- Eye diagram interpretation

### Signals & Systems Topics
- Convolution integral evaluation
- Laplace transform ROC determination
- Z-transform stability analysis
- Fourier transform properties
- LTI system stability from pole locations
- FFT butterfly stage calculation
- Discrete convolution

### Network Theory Topics
- t=0+ initial condition analysis (switching circuits)
- RLC resonance Q-factor calculation
- Thevenin equivalent circuit
- Mason's gain formula application
- First-order transient response

### Electronic Devices Topics
- Built-in potential calculation (Vbi)
- MOSFET drain current in saturation
- BJT alpha-beta conversion
- Carrier concentration (mass action law)
- Bandgap and temperature coefficient
- Small-signal transconductance

### Control Systems Topics
- Routh-Hurwitz stability (find range of K)
- Bode plot transfer function identification
- State-space matrix identification
- Root locus construction
- Gain margin and phase margin
- PID controller characteristics

### Engineering Mathematics Topics
- Eigenvalue calculation (3x3 matrix)
- Singular matrix identification
- Probability distribution (Poisson)
- Differential equation solution
- Linear algebra (determinant properties)

### Power Electronics Topics
- SCR firing circuit operation
- DC-DC converter output voltage (buck/boost)
- Single-phase full converter average voltage
- Commutation class identification
- Inverter harmonic analysis

### Measurements Topics
- AC bridge balancing condition
- LVDT sensitivity calculation
- Strain gauge gauge factor
- Voltmeter loading effect

## Key Takeaways for Preparation

1. **Communication Systems** had highest weightage (10 questions)
2. **Non-GATE subjects** (Power Electronics + Measurements) together = 11 questions
3. **VHDL questions** were conceptual (syntax and semantics)
4. **Formula-based questions** dominated (~60% of Part A)
5. **Part B** had visual reasoning, syllogisms, and quantitative aptitude
