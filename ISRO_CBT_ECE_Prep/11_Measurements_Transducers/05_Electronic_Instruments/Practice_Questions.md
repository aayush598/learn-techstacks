# Electronic Instruments - Practice Questions

## Q1. (ISRO Pattern)
A 3½ digit DVM has a basic accuracy of ±(0.05% of reading + 0.02% of range + 1 digit). On 10V range, what is the maximum error when reading 5.000V?
- (A) ±4.5 mV
- (B) ±5.5 mV
- (C) ±6.5 mV
- (D) ±3.5 mV
**Answer: (B)** 0.05%×5000mV + 0.02%×10000mV + 1mV = 2.5+2+1 = 5.5 mV

## Q2.
In a dual slope ADC, the integration time T₁ is chosen as 20ms to:
- (A) Increase conversion speed
- (B) Reject 50 Hz power line interference
- (C) Reduce component count
- (D) Increase resolution
**Answer: (B)**

## Q3.
The successive approximation ADC converts a 10V input with 12-bit resolution. The output count is:
- (A) 4096
- (B) 2048
- (C) 1024
- (D) 4095
**Answer: (A)** Count = (10/10) × 4096 = 4096 (or 4095 for max)

## Q4.
A frequency counter uses a 1s gate time and counts 5000 cycles. The frequency is:
- (A) 5 kHz
- (B) 50 kHz
- (C) 500 Hz
- (D) 50 Hz
**Answer: (A)** f = 5000/1 = 5 kHz

## Q5.
Which ADC type has the fastest conversion?
- (A) Ramp type
- (B) Dual slope
- (C) Successive approximation
- (D) Flash
**Answer: (D)**

## Q6.
In a dual slope ADC, the conversion result is independent of:
- (A) Reference voltage
- (B) Integration capacitor value
- (C) Input voltage
- (D) Clock frequency (partially)
**Answer: (B)** R and C cancel out.

## Q7.
The resolution of a 4½ digit DVM on 2V range is:
- (A) 0.1 mV
- (B) 1 mV
- (C) 0.01 mV
- (D) 10 mV
**Answer: (A)** 2V/19999 ≈ 0.1 mV

## Q8.
A true RMS converter measures the:
- (A) Average value
- (B) Peak value
- (C) RMS value of any waveform
- (D) DC component only
**Answer: (C)**

## Q9.
The conversion time of an 8-bit successive approximation ADC with 1MHz clock is:
- (A) 8 μs
- (B) 8 ms
- (C) 128 μs
- (D) 256 μs
**Answer: (A)** t = 8/1MHz = 8 μs

## Q10.
The primary advantage of dual slope ADC over ramp type is:
- (A) Higher speed
- (B) Simpler circuit
- (C) Better noise rejection and accuracy
- (D) Lower cost
**Answer: (C)**

## Q11.
For a sinusoidal input, the form factor is:
- (A) 1.11
- (B) 1.414
- (C) 0.637
- (D) 1.0
**Answer: (A)** Form factor = V_rms/V_avg = (V_p/√2)/(2V_p/π) = π/(2√2) = 1.11

## Q12.
A frequency counter with 0.1s gate time can resolve frequencies up to:
- (A) 1 Hz
- (B) 10 Hz
- (C) 100 Hz
- (D) 0.1 Hz
**Answer: (B)** Resolution = 1/0.1 = 10 Hz

## Q13.
The crest factor of a square wave is:
- (A) √2
- (B) 1
- (C) √3
- (D) 2
**Answer: (B)** V_peak = V_rms for square wave

## Q14.
In successive approximation ADC, the MSB is tested:
- (A) Last
- (B) First
- (C) In the middle
- (D) Randomly
**Answer: (B)**
