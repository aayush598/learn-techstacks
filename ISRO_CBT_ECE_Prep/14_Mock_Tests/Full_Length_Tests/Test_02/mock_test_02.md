## Detailed Solutions

### Numerical and Non-obvious Items

- **Q1:** \(V_o=-(R_f/R_{in})(V_1+V_2)=-20(1.0+2.0)=-60\text{ V}\), so **A**.
- **Q2:** \(A_v=1+R_f/R_1=1+20/4=6\), so **C**.
- **Q3:** \(RC=10\text{ ms}\); \(V_o=-t/(RC)=-0.10/0.01=-10\text{ V}\), so **A**.
- **Q5:** \(A_v\approx-(2\times10^{-3})(4.7\times10^3)=-9.4\), so **B**.
- **Q7:** \(SR_{\min}=2\pi fV_{p}=2\pi(20{,}000)(4)=5.03\times10^5\text{ V/s}=0.503\text{ V/μs}\), so **C**.
- **Q8:** The current ratio is \(2\text{ mA}/100\text{ μA}=20\), so **C**.
- **Q9:** The desensitivity factor is \(1+A\beta=100\), so **C**.
- **Q10:** \(f_c=1/(2\pi RC)=1/[2\pi(2.2\text{ k})(47\text{ n})]=1.54\text{ kHz}\), so **A**.
- **Q11:** \(45+26=71=1000111_2\), so **C**.
- **Q13:** From 8 to the next rollover at 16 requires 8 clock pulses, so **C**.
- **Q17:** Four bit positions differ, so **C**.
- **Q19:** \(D=\epsilon_0\epsilon_rE=(8.854\times10^{-12})(9)(30)=2.39\ \mu\text{C/m}^2\), so **B**.
- **Q20:** \(\eta=\eta_0/\sqrt{\epsilon_r\mu_r}=377/2=188.5\ \Omega\), so **C**.
