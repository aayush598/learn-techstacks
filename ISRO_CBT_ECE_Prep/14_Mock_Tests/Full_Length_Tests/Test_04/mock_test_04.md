## Detailed Solutions

### Numerical and Non-obvious Items

- **Q1:** Av = 1 + Rf/R1 = 1 + 17.8/2.2 = 9.09, so **C**.
- **Q2:** fc = 1/(2πRC) = 1/[2π(6.8 kΩ)(22 nF)] = 1.06 kHz, so **B**.
- **Q3:** \(V_o=-RC(dV_i/dt)=-(15\text{ k}\Omega)(0.10\ \mu\text{F})(0.020\text{ V/s})=-30\ \mu\text{V}\), so **A**.
- **Q4:** The ideal comparator output is high because V+ = 0.80 V is greater than V− = 0.50 V, so **A**.
- **Q5:** \(I_E=(1+1/\beta)I_C=(50/49)(15\ \mu\text{A})=15.3\ \mu\text{A}\), so **A**.
- **Q6:** The desensitivity factor is 1 + Aβ = 1 + 200(0.025) = 6, so **D**.
- **Q7:** Av ≈ -gmRC = -(1.5 mS)(3.3 kΩ) = -4.95, so **C**.
- **Q8:** f = 1/(2πRC) = 1/[2π(15 kΩ)(6.8 nF)] = 1.56 kHz, so **A**.
- **Q9:** A slight forward bias places both devices in conduction near the crossover region, which is Class AB operation, so **B**.
- **Q10:** vo = -(12/2.5)(0.80 - 0.30) = -2.40 V, so **A**.
- **Q11:** 13 + 11 = 24 = 11000₂, so **A**.
- **Q12:** Four variables have 2⁴ = 16 possible input combinations, so **C**.
- **Q13:** The enabled counter holds its state while E = 0, so the state remains 101₂, **A**.
- **Q14:** Gray code is formed as \(1010_2\oplus0101_2=1111_2\), so **A**.
- **Q15:** For 4 data bits, r = 3 gives 2³ = 8 = 4 + 3 + 1, so **A**.
- **Q16:** S = 1 selects I1, so **B**.
- **Q18:** SystemVerilog uses the nonblocking assignment operator <= in sequential logic, so **B**.
- **Q19:** vp = c/√(εrμr) = 3 × 10⁸/1.5 = 2.00 × 10⁸ m/s, so **B**.
- **Q20:** η = η0/√(εrμr) = 377/1.5 = 251.3 Ω, so **C**.
- **Q21:** ΓE = (η2 - η1)/(η2 + η1) = (150 - 50)/(150 + 50) = 0.50, so **B**.
- **Q22:** VSWR = (1 + |Γ|)/(1 - |Γ|) = 1.2/0.8 = 1.5, so **B**.
- **Q23:** Zt = √(ZLZ0) = √(12.5 × 50) = 25 Ω, so **B**.
- **Q24:** fc = c/(2a) = 3 × 10⁸/(2 × 0.025) = 6 GHz, so **B**.
- **Q25:** λg/λ = 1/√[1 - (fc/f)²] = 1/√(1 - 0.8²) = 1.667, so **C**.
- **Q26:** 20 log10(0.25) = -12.04 dB, so **A**.
- **Q27:** Pr = 0.5(4)(3)[0.20/(4π × 20)]² = 3.80 μW, so **B**.
- **Q28:** Ae = Gλ²/(4π) = 20(0.5)²/(4π) = 0.398 m², so **C**.
- **Q29:** The sideband fraction is μ²/(2 + μ²) = 0.36/2.36 = 15.3%, so **A**.
- **Q30:** β = 18/3 = 6, so **B**.
- **Q31:** BT ≈ 2(18 + 3) = 42 kHz, so **C**.
- **Q32:** The Nyquist rate is 2(4) = 8 ksamples/s, so **C**.
- **Q33:** C = 20 log2(1 + 1023) = 20 log2(1024) = 200 Mbps, so **B**.
