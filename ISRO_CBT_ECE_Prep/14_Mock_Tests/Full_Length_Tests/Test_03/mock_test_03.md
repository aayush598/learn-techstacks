## Detailed Solutions

### Numerical and Non-obvious Items

- **Q1:** \(V_o=-R_fV_{in}/R_{in}=-33/3.3(0.6)=-6\text{ V}\), so **A**.
- **Q2:** \(V_o=(R_2/R_1)(V_2-V_1)=10(0.5-0.2)=3\text{ V}\), so **B**.
- **Q3:** \(\tau=4.7\text{ k}\Omega\times22\text{ nF}=103.4\ \mu\text{s}\); at \(2\tau\), \(V_C=5(1-e^{-2})=4.32\text{ V}\), so **A**.
- **Q5:** \(I_E=(1+1/\beta)I_C=(150/149)(1\text{ mA})=1.007\text{ mA}\), so **A**.
- **Q6:** \(V_{ov}=\sqrt{2I_D/k_n}=\sqrt{2(1)/2}=1\text{ V}\), so **B**.
- **Q8:** \(f=1/(2\pi RC)=1/[2\pi(8.2\text{ k})(10\text{ n})]=1.94\text{ kHz}\), so **B**.
- **Q9:** \(R_B=R_{in}\parallel R_f=(10\times90)/(10+90)\text{ k}\Omega=9\text{ k}\Omega\), so **B**.
- **Q10:** The desensitivity factor is \(1+A\beta=11\), so **A**.
- **Q11:** \(0x2A+0x1F=0x49\), so **B**.
- **Q13:** Since 45 is positive, its 8-bit two's-complement form is \(00101101\), so **A**.
- **Q16:** One left shift of 1000 gives 0001, so **B**.
- **Q17:** The data word has five 1s, so a parity bit of 1 makes the total number of 1s even; **A**.
- **Q19:** \(\Phi=DA=(8\text{ nC/m}^2)(0.02\text{ m}^2)=0.16\text{ nC}\), so **A**.
- **Q21:** \(v_p=1/\sqrt{\epsilon_r\mu_r}=3.0\times10^8/3=1.0\times10^8\text{ m/s}\), so **A**.
- **Q22:** \(\mathrm{RL}=-20\log_{10}(0.4)=7.96\text{ dB}\), so **C**.
- **Q23:** \(f_c=c/(2a)=3\times10^8/(2\times0.015)=10\text{ GHz}\), so **B**.
- **Q24:** \(20\log_{10}(0.5)=-6.02\text{ dB}\), so **A**.
- **Q26:** \(P_r=10(2)(2)[0.1/(4\pi\times10)]^2=2.53\times10^{-5}\text{ W}=0.0253\text{ mW}\), so **A**.
- **Q27:** \(A_e=G\lambda^2/(4\pi)=2(0.3)^2/(4\pi)=0.0143\text{ m}^2\), so **B**.
- **Q28:** Gain is proportional to \(D^2\) at fixed frequency, so doubling the diameter gives a factor of 4, **C**.
- **Q29:** The sideband fraction is \(\mu^2/(2+\mu^2)=0.25/2.25=0.1111\), so **A**.
- **Q30:** \(\beta=50/2.5=20\), so **B**.
- **Q32:** \(C=5\log_2(32)=5(5)=25\text{ Mbps}\), so **B**.
- **Q33:** For \(r=4\), \(2^4=16\geq8+4+1=13\); the code length is \(8+4=12\), so **B**.
