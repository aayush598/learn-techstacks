## Detailed Solutions

### Numerical and Non-obvious Items

- **Q1:** vo = -(Rf/Rin)Vin = -(36/12)(0.90) = -2.70 V, so **B**.
- **Q2:** Av = 1 + Rf/R1 = 1 + 24/6 = 5, so **B**.
- **Q3:** τ = RC = 0.10 s and the high-pass output is 5e^(-t/τ); at t = τ, vo = 5/e = 1.84 V, so **B**.
- **Q4:** SRmin = 2πfVp = 2π(25,000)(2.5) = 3.93 × 10⁵ V/s = 0.393 V/μs, so **C**.
- **Q5:** VOV = 4 - 1 = 3 V, while VDS = 2.5 V < VOV, so the MOSFET is in the triode region, **B**.
- **Q6:** Av ≈ -gmRD = -(1.2 mS)(6.8 kΩ) = -8.16, so **C**.
- **Q7:** The current ratio is 3.0 mA/250 μA = 12, so **B**.
- **Q8:** Af = A/(1 + Aβ) = 80/(1 + 20) = 3.81, so **A**.
- **Q9:** RC = 20 kΩ × 470 nF = 9.4 ms; vo = -2.0(0.050)/0.0094 = -10.6 V, so **A**.
- **Q10:** The maximum Class B efficiency is π/4 = 0.785 = 78.5%, so **C**.
- **Q11:** 91 = 64 + 16 + 8 + 2 + 1, giving 01011011₂, so **A**.
- **Q12:** 16 = 2⁴, so four select lines are required, so **A**.
- **Q13:** Binary 1101₂ maps to Gray 1011₂ through adjacent XORs, so **B**.
- **Q14:** The Johnson sequence is 000, 001, 011, 111, so after three edges the state is 111, **D**.
- **Q15:** (A + B)' + A'B = A'B' + A'B = A'(B' + B) = A', so **B**.
- **Q16:** The word contains four 1s, so appending 0 preserves even parity, so **A**.
- **Q18:** A four-variable Karnaugh map has 16 cells, and the largest power-of-two group is 8 cells, so **C**.
- **Q19:** \(D=\epsilon_0\epsilon_rE=(8.854\times10^{-12})(4)(25)=8.854\times10^{-10}\ \text{C/m}^2=0.885\ \text{nC/m}^2\), so **B**.
- **Q20:** η = 377/√(εrμr) = 377/3 = 125.7 Ω, so **A**.
- **Q21:** The tangential electric field at an ideal perfect-electric-conductor surface is zero, so **B**.
- **Q22:** Γ = (75 - 50)/(75 + 50) = 0.20; hence VSWR = 1.20/0.80 = 1.50, so **B**.
- **Q23:** Zt = √(Z0ZL) = √(30 × 120) = 60 Ω, so **B**.
- **Q24:** fc = c/(2a) = 3 × 10⁸/(2 × 0.040) = 3.75 GHz, so **B**.
- **Q25:** vp = c/√(1 - (fc/f)²) = c/√(1 - 1/4) = 3.46 × 10⁸ m/s, so **C**.
- **Q26:** RL = -20 log10(0.316) = 10 dB, so **B**.
- **Q27:** Pr = 2(5)(4)[0.10/(4π × 50)]² = 1.01 μW, so **B**.
- **Q28:** BW = 0.886(0.012/0.24) = 0.0443 rad = 2.54°, so **B**.
- **Q29:** Pt = Pc(1 + μ²/2) = 1.00(1 + 0.64/2) = 1.32 kW, so **C**.
- **Q30:** β = 45/3 = 15, so **C**.
- **Q31:** C = 10 log2(16) = 40 Mbps, so **B**.
- **Q32:** Rb = 6000 × 10 = 60 kbps, so **C**.
- **Q33:** BPSK uses two antipodal carrier phases, 0° and 180°, so the phase difference is 180°, **B**.
- **Q34:** QPSK carries 2 bits per symbol, so Rs = 24/2 = 12 Msymbol/s, so **B**.
- **Q35:** A single-error-correcting code requires minimum distance dmin ≥ 3, so **C**.
- **Q36:** SQNR ≈ 6.02(8) + 1.76 = 49.92 dB, so **B**.
- **Q38:** P = (1² + 1² + 2² + 2²)/4 = 10/4 = 2.5, so **B**.
- **Q39:** X(e^jω) = 1/(1 - 0.80e^(-jω)), so **A**.
