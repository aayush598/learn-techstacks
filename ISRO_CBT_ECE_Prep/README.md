## How to Use This Resource

### Step 1: Start with 00_Exam_Overview
Read the exam pattern, weightage analysis, and create your study plan from the 8-month plan.

### Step 2: Study Subjects in Priority Order
Start with the highest weightage subjects first:
1. Analog Circuits (01)
2. Digital Circuits (02)
3. EM/Microwaves/Antennas (03)
4. Communication Systems (04)
5. Signals/DSP (05)

Then medium priority:
6. Network Theory (06)
7. Electronic Devices (07)
8. Control Systems (08)

Then lower priority:
9. Power Electronics (10)
10. Engineering Math (09)
11. Measurements (11)

### Step 3: For Each Subject
1. Read the Concepts.md files (all subtopics)
2. Memorize the Formulas.md files
3. Solve ALL Practice_Questions.md questions
4. Review the ISRO_Specific_Shortcuts

### Step 4: Part B (Aptitude)
Practice 12_Part_B_Aptitude regularly - it's free marks (no negative marking)

### Step 5: Revision and Testing
1. Use 13_Formula_Handbook for rapid revision
2. Take 14_Mock_Tests to build exam temperament
3. Review 15_PYP_Analysis for question patterns
