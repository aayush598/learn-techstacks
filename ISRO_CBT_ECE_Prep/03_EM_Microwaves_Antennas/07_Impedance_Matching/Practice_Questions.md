# Impedance Matching - Practice Questions

---

### Q1. (Easy) A load is matched to a 50 ohm line when:
(A) ZL = 0  (B) ZL = 50 ohm  (C) ZL = 100 ohm  (D) ZL is purely reactive

**Answer: (B) ZL = 50 ohm**

---

### Q2. (Moderate) A quarter-wave transformer matches a 50 ohm line to a 200 ohm load. Its characteristic impedance is:
(A) 25 ohm  (B) 75 ohm  (C) 100 ohm  (D) 200 ohm

**Solution:** Zt = sqrt(Z0 ZL) = sqrt(50 x 200) = 100 ohm.
**Answer: (C) 100 ohm**

---

### Q3. (Moderate) The reflection coefficient at a 75 ohm load connected to a 50 ohm line is:
(A) 0.20  (B) 0.40  (C) -0.20  (D) 0.60

**Solution:** Gamma = (75 - 50)/(75 + 50) = 0.20.
**Answer: (A) 0.20**

---

### Q4. (Moderate) The VSWR corresponding to |Gamma| = 0.2 is:
(A) 1.2  (B) 1.5  (C) 2.0  (D) 0.8

**Solution:** VSWR = (1 + 0.2)/(1 - 0.2) = 1.5.
**Answer: (B) 1.5**

---

### Q5. (Moderate) A short-circuited lossless stub has a purely:
(A) Resistive input impedance  (B) Inductive input reactance  (C) Capacitive input reactance  (D) Zero input impedance at every length

**Answer: (B) Inductive input reactance**

---

### Q6. (Moderate) In a single-stub tuner, the stub is placed where the normalized conductance of the load is:
(A) Zero  (B) One  (C) Infinite  (D) Equal to normalized susceptance

**Answer: (B) One, so the stub can cancel the remaining susceptance.**

---

### Q7. (Moderate) The main disadvantage of a quarter-wave transformer is that it:
(A) Has poor voltage isolation  (B) Is narrowband and requires a precise length  (C) Cannot match a resistive load  (D) Always needs an active device

**Answer: (B) Is narrowband and requires a precise electrical length.**

---

### Q8. (Moderate) An L-network has Q = sqrt(RL/Rs - 1). For RL = 200 ohm and Rs = 50 ohm, Q is:
(A) 0.5  (B) 1  (C) 1.73  (D) 3.46

**Solution:** Q = sqrt(200/50 - 1) = sqrt(3) = 1.73.
**Answer: (C) 1.73**

---

### Q9. (Moderate) Return loss for |Gamma| = 0.1 is approximately:
(A) -20 dB  (B) -10 dB  (C) 20 dB  (D) 1 dB

**Solution:** Return loss = -20 log10(0.1) = 20 dB.
**Answer: (C) 20 dB**

---

### Q10. (Moderate) A tapered transmission line is preferred when:
(A) Very high Q is desired  (B) A broadband match is required  (C) A single frequency only is available  (D) The load must be an open circuit

**Answer: (B) A broadband match is required.**
