# Business Judgment - Concepts & Strategies

## ISRO Exam Context
- Part B Aptitude: 15 questions, 20 marks, NO negative marking
- Business judgment: 1-2 questions per exam
- Tests workplace decision-making and professional judgment
- Time: ~1 minute per question (fastest section)

---

## 1. Situational Judgment

### What It Tests
Ability to choose the best course of action in workplace scenarios.

### Common Scenario Types
1. **Conflict between team members** → Choose collaborative resolution
2. **Deadline pressure** → Prioritize tasks, communicate proactively
3. **Ethical dilemma** → Follow organizational policy, report violations
4. **Resource constraints** → Optimize allocation, seek alternatives
5. **Quality vs speed** → Maintain quality standards, escalate if needed

### Decision Framework
1. **Identify the problem** clearly
2. **Consider stakeholders** affected
3. **Evaluate options** for feasibility and impact
4. **Choose the most ethical and practical** solution
5. **Communicate the decision** effectively

### Speed Tip
- In ISRO context: safety and quality always take priority
- When in doubt, choose the option that involves communication and documentation

## 2. Conflict Resolution

### Conflict Resolution Styles
| Style | When to Use | Description |
|-------|-------------|-------------|
| Collaborating | Both parties important | Win-win solution |
| Compromising | Time pressure | Both give up something |
| Accommodating | Relationship important | One party yields |
| Competing | Emergency/safety | One party dominates |
| Avoiding | Issue trivial | Postpone or ignore |

### ISRO-Preferred Approach
1. **Address the issue directly** but professionally
2. **Listen to all perspectives** before deciding
3. **Focus on the problem**, not the person
4. **Document the resolution** for future reference
5. **Follow up** to ensure implementation

### Red Flags in Conflict
- Personal attacks instead of issue-focused discussion
- Withholding information from team members
- Refusing to compromise on non-critical issues
- Escalating too quickly without attempting resolution

## 3. Workplace Ethics

### Core Ethical Principles
1. **Integrity**: Honesty and transparency in all actions
2. **Accountability**: Taking responsibility for outcomes
3. **Confidentiality**: Protecting sensitive information
4. **Fairness**: Equal treatment of all stakeholders
5. **Compliance**: Following rules, regulations, and policies

### Common Ethical Dilemmas
| Dilemma | Correct Response |
|---------|-----------------|
| Discovering a colleague's error | Report through proper channels |
| Asked to hide project delays | Report truthfully to management |
| Receiving gifts from vendors | Decline or report per policy |
| Witnessing safety violations | Report immediately |
| Accessing unauthorized data | Refuse and report |

### ISRO Code of Conduct Emphasis
- National security and public safety come first
- Scientific integrity in reporting results
- Confidentiality of mission-critical information
- No tolerance for fraud or misrepresentation

## 4. Project Management Scenarios

### Key Concepts
| Concept | Description |
|---------|-------------|
| Critical Path | Longest path through project network |
| Float/Slack | Time an activity can be delayed |
| Scope Creep | Uncontrolled expansion of project scope |
| Risk Management | Identifying and mitigating project risks |

### Project Decision Framework
1. **Scope**: What needs to be delivered?
2. **Time**: What is the deadline?
3. **Cost**: What is the budget?
4. **Quality**: What are the standards?
5. **Risk**: What could go wrong?

### Common PM Scenarios
- **Behind schedule**: Crash critical path, add resources
- **Over budget**: Reduce scope, find cost efficiencies
- **Quality issues**: Stop production, investigate root cause
- **Stakeholder conflict**: Mediate, document, escalate
- **Scope creep**: Change control process, document requests

### ISRO Project Context
- Mission-critical projects have zero tolerance for quality issues
- Documentation and traceability are paramount
- Peer review and verification are mandatory
- Schedule adherence is critical (launch windows are fixed)

## 5. Decision-Making Under Constraints

### Types of Constraints
| Constraint | Example | Strategy |
|-----------|---------|----------|
| Time | Fixed deadline | Prioritize, parallel work |
| Budget | Limited funds | Cost-benefit analysis |
| Resources | Limited personnel | Cross-training, outsourcing |
| Technical | Tool limitations | Workarounds, alternatives |
| Regulatory | Compliance requirements | Legal review, documentation |

### Decision-Making Models
1. **Rational Model**: Identify → Analyze → Choose → Implement → Evaluate
2. **Bounded Rationality**: Satisficing (good enough) vs optimizing
3. **Intuitive Model**: Experience-based quick decisions
4. **Creative Model**: Generate novel solutions

### Speed Tip
- In ISRO context: safety and mission success override all other constraints
- Always document the rationale behind constrained decisions

## 6. Professional Communication

### Effective Communication Principles
1. **Clarity**: Be specific and unambiguous
2. **Conciseness**: Get to the point quickly
3. **Completeness**: Include all necessary information
4. **Courtesy**: Maintain professional tone
5. **Correctness**: Verify facts before communicating

### Communication Channels (by urgency)
| Urgency | Channel | Example |
|---------|---------|---------|
| Critical | Phone/In-person | Safety incidents |
| High | Email + Follow-up | Project delays |
| Medium | Email | Regular updates |
| Low | Report/Document | Status reports |

### Report Writing (ISRO Context)
- Technical reports follow structured format
- Executive summary first, details later
- Use data and evidence, not opinions
- Include recommendations with rationale

## Business Judgment Speed-Solving Framework

### Step 1: Read the Scenario (15 seconds)
- What is the core problem?
- Who are the stakeholders?

### Step 2: Identify the Priority (10 seconds)
- Safety? Quality? Timeline? Budget? Ethics?

### Step 3: Evaluate Options (20 seconds)
- Which option addresses the core problem?
- Which option has the least negative impact?
- Which option is most ethical?

### Step 4: Select Best Answer (5 seconds)
- Choose the option that is most professional, ethical, and practical

## Common ISRO Business Judgment Patterns

1. **Safety first**: Always choose safety over schedule/cost
2. **Report, don't hide**: Transparency about problems
3. **Follow process**: Documentation and proper channels
4. **Team collaboration**: Seek input before major decisions
5. **Quality standards**: Never compromise on mission-critical quality
