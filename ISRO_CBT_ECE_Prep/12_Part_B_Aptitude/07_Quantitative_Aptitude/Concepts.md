# Quantitative Aptitude - Concepts & Strategies

## ISRO Exam Context
- Part B Aptitude: 15 questions, 20 marks, NO negative marking
- Quantitative aptitude: 2-3 questions per exam
- Tests numerical and mathematical ability
- Time: ~1.5 minutes per question (faster than visual types)

---

## 1. Percentages

### Basic Formulas
| Formula | Description |
|---------|-------------|
| (Part/Whole) × 100 | Finding percentage |
| (New - Old)/Old × 100 | Percentage change |
| New = Old × (1 ± r/100) | Increase/decrease by r% |

### Important Percentages
| Fraction | % | Fraction | % |
|----------|-----|----------|-----|
| 1/2 | 50% | 1/5 | 20% |
| 1/3 | 33.33% | 1/6 | 16.67% |
| 1/4 | 25% | 1/7 | 14.28% |
| 1/8 | 12.5% | 1/9 | 11.11% |
| 3/4 | 75% | 1/10 | 10% |
| 2/3 | 66.67% | 1/11 | 9.09% |

### Successive Percentage Change
If x% and y% changes are applied successively:
Net change = x + y + xy/100

### Speed Tips
- Convert fractions to percentages instantly (memorize the table)
- For successive changes, use the net change formula
- Use 100 as base for mental calculations

## 2. Profit and Loss

### Basic Formulas
| Formula | Description |
|---------|-------------|
| Profit = SP - CP | When SP > CP |
| Loss = CP - SP | When CP > SP |
| Profit% = (Profit/CP) × 100 | Profit percentage |
| Loss% = (Loss/CP) × 100 | Loss percentage |
| SP = CP × (1 + Profit%/100) | Selling price with profit |
| SP = CP × (1 - Loss%/100) | Selling price with loss |

### Marked Price and Discount
| Formula | Description |
|---------|-------------|
| Discount = MP - SP | Marked price minus selling price |
| Discount% = (Discount/MP) × 100 | Discount percentage |
| SP = MP × (1 - Discount%/100) | After discount |

### Successive Discounts
Two successive discounts of d₁% and d₂%:
Net discount = d₁ + d₂ - d₁d₂/100

### Speed Tips
- CP is always the base (100%) for profit/loss
- MP is the base for discount calculations
- Use fractions: 25% profit = multiply CP by 5/4

## 3. Simple and Compound Interest

### Simple Interest (SI)
| Formula | Description |
|---------|-------------|
| SI = P × R × T / 100 | P=Principal, R=Rate%, T=Time(years) |
| Amount = P + SI | Total amount |
| P = SI × 100 / (R × T) | Finding principal |

### Compound Interest (CI)
| Formula | Description |
|---------|-------------|
| A = P(1 + R/100)^T | Amount after T years |
| CI = A - P | Compound interest |
| CI = P[(1 + R/100)^T - 1] | Direct CI formula |

### CI for Half-Yearly Compounding
A = P(1 + R/(2×100))^(2T)

### Difference: CI - SI (for 2 years)
CI - SI = P × (R/100)^2

### Speed Tips
- For 2 years: CI - SI = SI²/P (approximate)
- SI grows linearly, CI grows exponentially
- For small rates and short periods, CI ≈ SI

## 4. Time, Speed, and Distance

### Basic Formulas
| Formula | Description |
|---------|-------------|
| Speed = Distance / Time | Basic relationship |
| Distance = Speed × Time | Finding distance |
| Time = Distance / Speed | Finding time |

### Unit Conversions
| From | To | Multiply by |
|------|----|-------------|
| km/h | m/s | 5/18 |
| m/s | km/h | 18/5 |

### Average Speed
| Scenario | Formula |
|----------|---------|
| Equal distances at speeds v₁ and v₂ | 2v₁v₂/(v₁ + v₂) |
| Equal times at speeds v₁ and v₂ | (v₁ + v₂)/2 |

### Relative Speed
| Scenario | Formula |
|----------|---------|
| Same direction | v₁ - v₂ |
| Opposite direction | v₁ + v₂ |
| Trains crossing | (L₁ + L₂) / Relative speed |
| Objects crossing a pole | Length / Speed |

### Speed Tips
- Memorize 5/18 and 18/5 conversions
- For average speed with equal distances: harmonic mean formula
- For trains: add lengths of both trains

## 5. Ratios and Proportions

### Basic Concepts
| Concept | Description |
|---------|-------------|
| a:b = c:d | Proportion |
| a × d = b × c | Cross multiplication |
| a:b:c | Continued proportion |

### Ratio Operations
| Operation | Method |
|-----------|--------|
| Simplify | Divide by GCD |
| Add a+b | Combine ratios with same second term |
| Divide in ratio a:b | Parts = a/(a+b) and b/(a+b) of total |

### Speed Tips
- Convert ratios to actual numbers using a common multiplier
- Use cross multiplication for proportions
- For mixture problems, use alligation

## 6. Averages

### Basic Formulas
| Formula | Description |
|---------|-------------|
| Average = Sum / Count | Basic average |
| Sum = Average × Count | Finding sum |
| New average = (Old sum + New value) / (Old count + 1) | Adding a value |

### Weighted Average
Weighted Average = Σ(wᵢ × xᵢ) / Σwᵢ

### Average of Consecutive Numbers
| Sequence | Average |
|----------|---------|
| 1, 2, ..., n | (n+1)/2 |
| a, a+1, ..., b | (a+b)/2 |

### Speed Tips
- Average of consecutive integers = (first + last) / 2
- When adding a value: New avg = (Old sum + new) / (n+1)
- For equal groups: overall average = (avg₁ + avg₂ + ...) / number of groups

## 7. Mixtures and Alligation

### Alligation Rule
If two ingredients at prices P₁ and P₂ are mixed to get average price P:
Ratio = (P₂ - P) : (P - P₁)

### Mixture Replacement
If x liters are removed and replaced with water, repeated n times:
Pure remaining = P × (1 - x/P)^n

### Speed Tips
- Draw the alligation cross for quick ratio finding
- For replacement: use the formula directly
- For successive replacements: compound the reduction

## 8. Work and Time

### Basic Formulas
| Formula | Description |
|---------|-------------|
| Work = Rate × Time | Basic relationship |
| Rate = Work / Time | Efficiency |
| Time = Work / Rate | Finding time |

### Combined Work
| Scenario | Formula |
|----------|---------|
| A completes in a days, B in b days | Together: ab/(a+b) days |
| A's rate = 1/a, B's rate = 1/b | Combined rate = 1/a + 1/b |
| Multiple workers | Total rate = Σ(1/timeᵢ) |

### Efficiency Approach
| Worker | Days | Efficiency (per day) |
|--------|------|---------------------|
| A | a | 1/a |
| B | b | 1/b |
| Together | ab/(a+b) | 1/a + 1/b |

### Speed Tips
- Assume total work = LCM of individual times
- For pipes and cisterns: inlet = positive rate, outlet = negative rate
- For alternate days work: calculate work done in 2-day cycles

---

## 9. Number Systems and HCF/LCM

### HCF (Highest Common Factor)
- HCF of a and b divides both a and b
- HCF(a,b) × LCM(a,b) = a × b

### LCM (Least Common Multiple)
- LCM of a and b is the smallest number divisible by both

### Speed Tips
- HCF is found by prime factorization (take minimum powers)
- LCM is found by prime factorization (take maximum powers)
- For co-prime numbers: HCF = 1, LCM = product

---

## 10. Time and Work — Advanced

### Pipes and Cisterns
- Pipe A fills in a hours, Pipe B empties in b hours
- Together: rate = 1/a - 1/b (net filling rate)
- Time to fill = 1 / (1/a - 1/b) = ab/(b-a)

### Work Distribution
- Total work = sum of individual works
- If total work is W, and workers have different efficiencies:
  Time = W / (sum of efficiencies)

## Quantitative Aptitude Speed-Solving Framework

### Step 1: Identify the Topic (5 seconds)
- Is it percentages, profit/loss, time-speed-distance, etc.?

### Step 2: Write the Formula (5 seconds)
- Recall the relevant formula

### Step 3: Substitute and Calculate (30-45 seconds)
- Plug in values and compute

### Step 4: Sanity Check (5 seconds)
- Does the answer make sense? Is it in the right range?

---

## Common ISRO Quantitative Aptitude Patterns

1. **Percentage change**: Successive changes or reverse percentage
2. **Profit/loss with discount**: MP → discount → SP, and profit on CP
3. **Average speed**: Equal distances at different speeds
4. **Work together**: Multiple workers with different efficiencies
5. **Simple/compound interest difference**: For 2-3 year periods
