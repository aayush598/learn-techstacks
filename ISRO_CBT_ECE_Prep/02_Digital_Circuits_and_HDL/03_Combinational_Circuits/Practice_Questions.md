# Combinational Circuits - Practice Questions

---

### Q1. (Easy) Combinational circuit output depends:
(A) Only current inputs  (B) Previous state  (C) Clock  (D) Memory

**Answer: (A) Only current inputs (no memory, no clock required)**

---

### Q2. (Moderate) Combinational vs sequential - combinational has:
(A) No memory elements  (B) FFs  (C) Clock always  (D) State

**Answer: (A) No memory/flip-flops; output is pure function of inputs**

---

### Q3. (Moderate) NAND and NOR are:
(A) Universal gates  (B) Only AND  (C) Only basic  (D) Not useful

**Answer: (A) Universal - any Boolean function can be built from NAND alone or NOR alone**

---

### Q4. (Moderate) A 3-input majority function output:
(A) 1 if >=2 inputs 1  (B) 1 if all 1  (C) XOR  (D) 0 always

**Answer: (A) Majority - output 1 when at least 2 of 3 inputs are 1**

---

### Q5. (Moderate) A comparison: XNOR acts as:
(A) Equality (1 when equal)  (B) Difference  (C) OR  (D) Always 1

**Answer: (A) XNOR = compactor - 1 when inputs equal**

---

### Q6. (Moderate) Which can realize any function more efficiently as building block?
(A) NAND/NOR universality  (B) Only AND-OR  (C) Only NOT  (D) Only XOR

**Answer: (A) NAND (or NOR) single gate type is universal**

---

### Q7. (Moderate) A full-adder is:
(A) Combinational (3 in, 2 out)  (B) Sequential  (C) Memory  (D) Register

**Answer: (A) Combinational - Sum & Carry out from A,B,Cin**

---

### Q8. (Moderate) Number of rows in truth table for 4-variable function:
(A) 16  (B) 8  (C) 32  (D) 4

**Solution:** 2^4 = 16
**Answer: (A) 16**
