# Decoders and Encoders - Practice Questions

---

### Q1. (Easy) 3-to-8 decoder has:
(A) 3 outputs  (B) 8 outputs  (C) 8 inputs  (D) 4 outputs

**Answer: (B) 8 outputs (2^3)**

---

### Q2. (Easy) Decoder output Y3 of 2-to-4 (inputs A,B):
(A) AB  (B) A'B  (C) A+B  (D) A'B'

**Answer: (A) Y3 = AB (11)**

---

### Q3. (Moderate) Priority encoder resolves:
(A) No inputs  (B) Multiple active inputs (picks highest)  (C) Speed  (D) Power

**Answer: (B) Ambiguity when multiple inputs active - picks highest priority**

---

### Q4. (Moderate) Number of decoder outputs configured when realizing a function with 3 variables:
(A) 3  (B) 8  (C) 16  (D) 4

**Answer: (B) 8 minterms (3-to-8 decoder)**

---

### Q5. (Moderate) Decoder + OR gate can implement:
(A) Only AND  (B) Any Boolean function  (C) Only multiplexer  (D) Only memory

**Answer: (B) Any Boolean function (OR of minterms)**

---

### Q6. (Moderate) 4-to-2 encoder: A = D1 + D3, B = D2 + D3. If D3=1 gives:
(A) 00  (B) 11  (C) 10  (D) 01

**Answer: (B) 11 (both A,B =1 encoded as 3)**

---

### Q7. (Moderate) Priority encoder valid output V indicates:
(A) Error  (B) At least one input active  (C) Carry  (D) Clock

**Answer: (B) At least one input is active**

---

### Q8. (Moderate) Memory address decoding uses a decoder to:
(A) Amplify  (B) Select one memory chip  (C) Convert analog  (D) Divide clock

**Answer: (B) Select the memory chip (from address bits)**
