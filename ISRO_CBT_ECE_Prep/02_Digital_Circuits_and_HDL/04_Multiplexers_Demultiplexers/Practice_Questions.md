# Multiplexers and Demultiplexers - Practice Questions

---

### Q1. (Easy) 4-to-1 MUX has:
(A) 4 data inputs  (B) 4 outputs  (C) 2 data  (D) 8 select

**Answer: (A) 4 data inputs, 2 select lines, 1 output**

---

### Q2. (Moderate) Select lines for 2^n-input MUX:
(A) n  (B) 2n  (C) n^2  (D) 2^n

**Answer: (A) n select lines (2^n inputs)**

---

### Q3. (Moderate) 8-to-1 MUX select lines:
(A) 3  (B) 8  (C) 2  (D) 4

**Answer: (A) 3 select lines (2^3 = 8)**

---

### Q4. (Moderate) MUX can implement:
(A) Any Boolean function  (B) Only AND  (C) Only memory  (D) Only delay

**Answer: (A) Any combinational function (use inputs as minterm values, select=variables)**

---

### Q5. (Moderate) Demultiplexer:
(A) 1 input, many outputs (rout to select)  (B) Many inputs 1 output  (C) Memory  (D) Counter

**Answer: (A) DMUX - one input routed to one of many outputs via select**

---

### Q6. (Moderate) MUX parallel-to-serial:
(A) Selects one input at a time = serial out  (B) Only parallel  (C) Only memory  (D) None

**Answer: (A) MUX repeatedly selects inputs -> converts parallel to serial**

---

### Q7. (Moderate) 16-bit MUX built from 2x 8-to-1:
(A) Use select bit to choose which MUX via enable  (B) 2 data only  (C) Cannot  (D) Add XOR

**Answer: (A) Cascading with enable/select MSB to build larger MUX**

---

### Q8. (Moderate) Function of 16 inputs needs MUX:
(A) 16-to-1 MUX (4 select)  (B) 4-to-1  (C) 8-to-1  (D) 2-to-1

**Answer: (A) 16-to-1 MUX with 4 select lines**
