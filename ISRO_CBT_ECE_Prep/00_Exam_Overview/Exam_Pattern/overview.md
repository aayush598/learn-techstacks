## Exam Overview

The ISRO Scientist/Engineer (C) Computer Based Test (CBT) for Electronics and Communication Engineering (ECE) is a national-level examination conducted by the Indian Space Research Organisation. It serves as the primary gateway for engineering graduates to join ISRO as Scientist/Engineer 'C'.

### Key Exam Statistics

| Parameter | Details |
|-----------|---------|
| **Total Questions** | 95 |
| **Total Marks** | 100 |
| **Total Duration** | 120 minutes (2 hours) |
| **Question Type** | Multiple Choice Questions (MCQ) |
| **Mode** | Computer Based Test (CBT) |
| **Language** | English only |
| **Frequency** | Once a year (typically) |

## Part A: Objective Questions

### Structure

Part A consists of **80 Multiple Choice Questions (MCQs)** covering the core ECE syllabus. Each question has four options, and exactly one is correct.

### Characteristics

| Feature | Details |
|---------|---------|
| **Number of Questions** | 80 |
| **Marks per Question** | 1 mark |
| **Total Marks** | 80 |
| **Negative Marking** | Yes |
| **Penalty for Wrong Answer** | -1/3 mark (approximately 0.33) |
| **Penalty for Unattempted** | 0 |
| **Options per Question** | 4 (A, B, C, D) |
| **Correct Answer** | Only one option is correct |

### Subject Distribution in Part A

| Subject | Typical Questions | Marks |
|---------|-------------------|-------|
| Analog Electronics | 8-10 | 8-10 |
| Digital Electronics | 8-10 | 8-10 |
| Electromagnetic Theory | 8-10 | 8-10 |
| Communication Systems | 8-10 | 8-10 |
| Signals and Systems | 8-10 | 8-10 |
| Network Theory | 7-9 | 7-9 |
| Electronic Devices & Circuits | 7-9 | 7-9 |
| Control Systems | 7-9 | 7-9 |
| Engineering Mathematics | 5-7 | 5-7 |
| Power Electronics | 4-6 | 4-6 |
| Measurements & Instrumentation | 3-5 | 3-5 |

### Part A Difficulty Level

The questions in Part A generally fall into three difficulty categories:

1. **Easy (35%)**: Direct formula-based questions, basic concept applications
   - These are straightforward and should be answered quickly
   - Expected time: 30-40 seconds per question

2. **Moderate (45%)**: Conceptual questions requiring multi-step reasoning
   - These require understanding of underlying principles
   - Expected time: 60-90 seconds per question

3. **Hard (20%)**: Complex problems, application-based, or tricky conceptual questions
   - These may require longer calculation or deep analysis
   - Expected time: 120-180 seconds per question

### Part A Strategy

- **Target**: Answer 65-70 questions correctly out of 80
- **Accuracy Goal**: 85-90% on attempted questions
- **Skip Strategy**: Mark difficult questions and return if time permits
- **Time Budget**: 80-85 minutes for Part A (approximately 1 minute per question)

## Part B: Numerical Questions

### Structure

Part B consists of **15 Numerical Answer Type (NAT) questions** where the answer is a numerical value that must be entered manually.

### Characteristics

| Feature | Details |
|---------|---------|
| **Number of Questions** | 15 |
| **Marks per Question** | Variable (total 20 marks) |
| **Total Marks** | 20 |
| **Negative Marking** | **NO** negative marking |
| **Answer Format** | Numerical value (integer or decimal) |
| **Rounding** | Typically up to 2 decimal places |
| **Calculator** | Virtual calculator available on screen |

### Part B Marking Distribution

| Question Type | Marks | Count | Total Marks |
|---------------|-------|-------|-------------|
| 1-mark questions | 1 | 5-6 | 5-6 |
| 1.5-mark questions | 1.5 | 4-5 | 6-7.5 |
| 2-mark questions | 2 | 4-5 | 8-10 |
| **Total** | | **15** | **20** |

### Part B Difficulty Level

1. **Easy (20%)**: Direct calculation problems
   - Simple numerical substitution
   - Expected time: 60-90 seconds

2. **Moderate (50%)**: Multi-step numerical problems
   - Requires multiple formulas or iterations
   - Expected time: 90-150 seconds

3. **Hard (30%)**: Complex calculations, tricky concepts
   - May involve multiple concepts combined
   - Expected time: 150-240 seconds

### Part B Strategy

- **No negative marking** means you should attempt ALL questions
- **Even partial knowledge** helps - attempt every question
- **Calculator usage**: Practice with the virtual calculator before exam
- **Time Budget**: 35-40 minutes for Part B
- **Average time per question**: 2-2.5 minutes

## Marking Scheme

### Complete Marking Breakdown

```
Total Score Calculation:
═══════════════════════════════════════════════════════════

Part A (80 Questions):
  Correct Answer:    +1.00 mark each
  Wrong Answer:      -0.33 mark each (1/3 deduction)
  Unattempted:       0 marks

Part B (15 Questions):
  Correct Answer:    +1.00 to +2.00 marks each
  Wrong Answer:      0 marks (NO negative marking)
  Unattempted:       0 marks

═══════════════════════════════════════════════════════════
Maximum Possible Score: 100 marks
```

### Impact of Negative Marking

| Scenario | Part A Impact | Part B Impact |
|----------|---------------|---------------|
| Correct answer | +1.00 | +1.00 to +2.00 |
| Wrong answer | -0.33 | 0 |
| Unattempted | 0 | 0 |

### Break-Even Analysis for Part A

To understand when negative marking hurts you:

- If you answer 60 questions correctly and 10 incorrectly:
  - Score: 60 × 1 - 10 × 0.33 = 60 - 3.3 = **56.7 marks**
  
- If you answer 70 questions correctly and 10 incorrectly:
  - Score: 70 × 1 - 10 × 0.33 = 70 - 3.3 = **66.7 marks**
  
- If you answer 50 questions correctly and 20 incorrectly:
  - Score: 50 × 1 - 20 × 0.33 = 50 - 6.6 = **43.4 marks**

**Key Insight**: The penalty for wrong answers is relatively small (-0.33), so it's generally better to attempt questions you're reasonably confident about. However, blind guessing on 4-option MCQs has only 25% success rate, which would result in net loss.

### Optimal Attempt Strategy

| Confidence Level | Action | Expected Value |
|------------------|--------|----------------|
| Very High (90%+) | Attempt immediately | +0.90 to +1.00 |
| High (70-90%) | Attempt after quick review | +0.54 to +0.87 |
| Medium (50-70%) | Attempt if time permits | +0.17 to +0.51 |
| Low (25-50%) | Skip (don't guess) | -0.08 to +0.17 |
| Random guess | Never attempt | -0.08 (expected loss) |

## Exam Flow

### Recommended Exam Execution Flow

```
Phase 1: Quick Scan (2-3 minutes)
├── Read through all Part A questions
├── Identify easy questions (mark mentally)
└── Identify questions needing more time

Phase 2: Part A Easy Questions (20-25 minutes)
├── Answer all easy questions first
├── Build confidence and momentum
└── Secure guaranteed marks

Phase 3: Part A Moderate Questions (35-40 minutes)
├── Systematic approach to each question
├── Show work on rough sheet
└── Mark uncertain answers

Phase 4: Part B (35-40 minutes)
├── Attempt all questions (no negative marking)
├── Use virtual calculator
└── Double-check calculations

Phase 5: Part A Hard Questions (15-20 minutes)
├── Return to skipped questions
├── Use elimination technique
└── Make educated guesses if needed

Phase 6: Final Review (5 minutes)
├── Check for any unanswered questions
├── Verify Part B answers
└── Ensure no bubbling errors
```

| 3 | Part A - Moderate | 40 min | 68 min |

## Tips for Each Section

### Part A Tips

1. **Read the question completely** before looking at options
2. **Don't spend more than 2 minutes** on any single question
3. **Use elimination** to narrow down options
4. **Trust your first instinct** unless you're sure it's wrong
5. **Mark uncertain answers** for review if time permits
6. **Watch for "NOT" or "EXCEPT"** in question stems

### Part B Tips

1. **Attempt every question** - no negative marking
2. **Use virtual calculator** before exam to get familiar
3. **Round answers** appropriately (usually 2 decimal places)
4. **Check units** - some questions have unit traps
5. **Show all work** on rough sheet for verification
6. **Double-check calculations** before moving on

### General Exam Tips

1. **Stay hydrated** and carry water bottle
2. **Reach exam center 30 minutes early**
3. **Carry required documents** (admit card, ID)
4. **Don't discuss answers** before exam
5. **Stay calm and confident** throughout
6. **Trust your preparation**
