# Common Mistakes to Avoid in ISRO CBT ECE Exam

## Preparation Phase Mistakes

### Mistake 1: Ignoring Non-GATE Subjects
**Problem:** Many aspirants skip Power Electronics, Measurements, and Microwave Hardware because they are not in GATE.
**Impact:** Losing 12-15 marks (15-19% of Part A) from 20% of syllabus.
**Solution:** Allocate 20% of study time to Power Electronics, Measurements, and Microwave devices.

### Mistake 2: Over-focusing on Derivations
**Problem:** ISRO tests formula application, not derivation steps.
**Impact:** Wasting time on derivations that will never be asked.
**Solution:** Learn formulas directly with physical meaning. Know when to use each formula.

### Mistake 3: Not Practicing Under Time Pressure
**Problem:** Solving questions without timer gives false confidence.
**Impact:** Running out of time in actual exam, leaving 20+ questions unattempted.
**Solution:** Practice 80 questions in 90 minutes regularly. Build speed.

### Mistake 4: Ignoring Part B (Aptitude)
**Problem:** Thinking aptitude is easy and needs no preparation.
**Impact:** Losing 15-20 easy marks from spatial/abstract reasoning.
**Solution:** Practice visual reasoning, syllogisms, Venn diagrams weekly.

### Mistake 5: Studying Too Many Books
**Problem:** Reading 3-4 books per subject creates confusion.
**Impact:** Incomplete preparation across many sources.
**Solution:** Stick to 1 primary book + 1 supplement per subject. Use this resource as main guide.

## Exam-Day Mistakes

### Mistake 6: Attempting Questions Sequentially
**Problem:** Starting from Q1 and getting stuck on Q3 wastes time.
**Impact:** Missing easy questions later in the paper.
**Solution:** Scan all questions first. Answer easy ones regardless of position.

### Mistake 7: Spending > 90 Seconds on One Question
**Problem:** Getting emotionally attached to solving one difficult question.
**Impact:** Losing time for 5-10 other solvable questions.
**Solution:** Set a mental timer. 90 seconds max. Mark and move.

### Mistake 8: Not Attempting All Part B Questions
**Problem:** Leaving Part B questions unattempted due to time pressure.
**Impact:** Part B has NO negative marking. Every unattempted question is a free mark lost.
**Solution:** Reserve 30 minutes for Part B. Attempt ALL 15 questions.

### Mistake 9: Ignoring Negative Marking
**Problem:** Random guessing on all unclear questions.
**Impact:** -0.33 per wrong answer. 10 wrong guesses = -3.33 marks.
**Solution:** Only guess if you can eliminate at least 2 options.

### Mistake 10: Not Reading Questions Completely
**Problem:** Missing keywords like "NOT", "EXCEPT", "FALSE", "INCORRECT".
**Impact:** Answering opposite of what is asked.
**Solution:** Underline/mentally note the key qualifier word.

### Mistake 11: Changing Answers Unnecessarily
**Problem:** Second-guessing and changing correct answers to wrong ones.
**Impact:** Losing marks on questions you initially got right.
**Solution:** Change only if you find a clear error in your first answer.

### Mistake 12: Panic When Questions Look Unfamiliar
**Problem:** Seeing unknown questions causes anxiety and affects subsequent performance.
**Impact:** Even easy questions seem hard when panicking.
**Solution:** Skip unknown questions. Come back after completing others. Confidence restores.

## Conceptual Mistakes (High-Frequency Errors)

### Mistake 13: Confusing Active vs Passive Sign Convention
**Problem:** Using wrong sign convention in op-amp or transistor problems.
**Impact:** Wrong gain signs, incorrect current directions.
**Solution:** Active: current enters positive terminal. Passive: current enters positive terminal. Always be consistent.

### Mistake 14: Mixing Up Laplace vs Z-transform Properties
**Problem:** Using time-domain properties interchangeably.
**Impact:** Wrong ROC, incorrect inverse transforms.
**Solution:** Create a side-by-side comparison table. Review before exam.

### Mistake 15: Forgetting Negative Marking in Calculation
**Problem:** Not factoring -0.33 into expected value analysis.
**Impact:** Attempting questions with < 30% confidence (negative EV).
**Solution:** Only attempt if you can eliminate 2+ options.

### Mistake 16: Wrong Unit Conversions
**Problem:** dB to linear, MHz to Hz, mV to V conversions.
**Impact:** All calculations wrong by orders of magnitude.
**Solution:** Write units at every step. Double-check conversions.

### Mistake 17: Confusing Series vs Parallel Resonance
**Problem:** Using series resonance formulas for parallel circuits.
**Impact:** Wrong Q-factor, incorrect bandwidth calculations.
**Solution:** Series: Z_min at resonance. Parallel: Z_max at resonance. Remember this key difference.

### Mistake 18: VHDL Signal vs Variable Assignment
**Problem:** Using <= in process (meant for variables) or := outside process.
**Impact:** Wrong VHDL code analysis answers.
**Solution:** Signal: <= (concurrent and in process, delayed). Variable: := (only inside process, immediate).

### Mistake 19: Confusing Buck and Boost Converter Formulas
**Problem:** Using Vo = D*Vin for boost or Vo = Vin/(1-D) for buck.
**Impact:** Completely wrong answer.
**Solution:** Buck steps DOWN: Vo < Vin, so Vo = D*Vin. Boost steps UP: Vo > Vin, so Vo = Vin/(1-D).

### Mistake 20: Not Checking Eigenvalue Properties
**Problem:** Assuming all matrices have unique eigenvalues.
**Impact:** Wrong answers for singular matrix, similar matrix problems.
**Solution:** Singular matrix => at least one eigenvalue = 0. Sum of eigenvalues = trace. Product = determinant.

## Quick Self-Check Before Submitting

- [ ] All Part B questions attempted (no negative marking!)
- [ ] No question left unattempted that you could solve
- [ ] Units match in numerical answers
- [ ] No calculation errors from sign mistakes
- [ ] Read "NOT" and "EXCEPT" questions carefully
- [ ] Time remaining used for review, not new questions
