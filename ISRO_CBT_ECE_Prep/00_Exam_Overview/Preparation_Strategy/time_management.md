# ISRO CBT ECE Exam — During-Exam Time Management Strategy

## Exam Structure Recap

| Parameter | Details |
|-----------|---------|
| Total Questions | 80 |
| Total Duration | 90 minutes |
| Time per Question | 67.5 seconds (theoretical) |
| Effective Time per Question | **75 seconds** (after accounting for review time) |
| Marks per Question | 1 mark or 2 marks |
| Negative Marking | **⅓ of marks** for wrong answer (1/3 for 1-mark, 2/3 for 2-mark) |
| Question Type | Multiple Choice (4 options) |

---

## Time Allocation Strategy

### The 75-Second Rule

With 80 questions in 90 minutes, you have exactly **67.5 seconds per question**. However, you must factor in:

| Activity | Time Budget |
|----------|-------------|
| Reading + Understanding Question | 20–25 seconds |
| Solving / Calculating | 30–35 seconds |
| Marking Answer | 5 seconds |
| Buffer per question | ~7 seconds |
| **Total per question** | **~67 seconds** |

### Time Block Distribution

Divide the 90 minutes into **three 30-minute blocks**:

#### Block 1 (0–30 minutes): High-Confidence Zone

| Activity | Details |
|----------|---------|
| **Goal** | Attempt 25–30 questions |
| **Focus** | Easy and medium questions you are confident about |
| **Speed** | ~60 seconds per question |
| **Marking** | Answer and move on immediately |

#### Block 2 (30–60 minutes): Working Zone

| Activity | Details |
|----------|---------|
| **Goal** | Attempt 25–30 more questions |
| **Focus** | Medium difficulty questions requiring calculation |
| **Speed** | ~75 seconds per question |
| **Marking** | Answer, mark for review if unsure |

#### Block 3 (60–90 minutes): Review & Cleanup Zone

| Activity | Details |
|----------|---------|
| **Goal** | Attempt remaining questions + review marked ones |
| **Focus** | Hard questions, revisit flagged questions |
| **Speed** | ~90 seconds per question |
| **Marking** | Attempt only if you can eliminate 2+ options |

## Question Navigation Strategy

### The Traffic Light System

Color-code every question mentally as you read it:

| Signal | Meaning | Action |
|--------|---------|--------|
| **GREEN** | You know the answer immediately | Answer in < 30 seconds, move on |
| **YELLOW** | You can solve but it takes time | Attempt, budget 90 seconds max |
| **RED** | You have no idea / very lengthy | Mark for review, move on immediately |

### Time Decision Matrix

| If you recognize the topic in... | Then... |
|----------------------------------|---------|
| First 5 seconds | Answer immediately (GREEN) |
| First 10 seconds | Solve if confident (YELLOW) |
| After 15 seconds with no idea | Skip for now (RED) |

## Skip Strategy Rules

### When to Skip (MUST Skip)

1. **Question takes > 2 minutes** — Skip immediately
2. **You're down to 2 options and guessing** — Skip if negative marking applies
3. **Lengthy calculation required** — Skip, come back later
4. **Topic you haven't studied** — Skip, don't waste time
5. **Question seems ambiguous** — Skip, it might be a bonus if many skip it

### When NOT to Skip

1. **You know the answer in < 30 seconds** — Answer immediately
2. **You're 90% sure after calculation** — Answer, accept the risk
3. **Elimination gives you 1 option left** — Answer it
4. **The topic is your strongest area** — Attempt even if it takes 90 seconds

### Skip Budget

| Total Questions | Target Attempted | Skipped | Skip Budget |
|-----------------|------------------|---------|-------------|
| 80 | 65–70 | 10–15 | ~15% |

## Negative Marking Strategy

### ISRO Negative Marking Rules

| Question Type | Marks | Penalty for Wrong Answer |
|---------------|-------|--------------------------|
| 1-mark question | +1 | −0.33 (−⅓) |
| 2-mark question | +2 | −0.67 (−⅔) |

### Expected Value Analysis

| Your Confidence | 1-Mark Question | 2-Mark Question |
|-----------------|-----------------|-----------------|
| 100% sure | +1.00 | +2.00 |
| 75% sure (3 options eliminated) | +0.58 (EV) | +1.17 (EV) |
| 50% sure (2 options eliminated) | +0.17 (EV) | +0.33 (EV) |
| 33% sure (random guess) | −0.08 (EV) | −0.17 (EV) |

**Decision Rules:**

- **Always answer** if you're 75%+ confident
- **Answer 2-mark questions** if you can eliminate 2 options (50%+ chance)
- **Skip 1-mark questions** if you're only 50/50
- **NEVER randomly guess** — negative marking makes it a losing game

### Safe Guessing Threshold

| Situation | Action |
|-----------|--------|
| Can eliminate 1 option | Skip (expected value near zero) |
| Can eliminate 2 options | Answer (positive expected value) |
| Can eliminate 3 options | Always answer (guaranteed correct) |

## Question Paper Reading Strategy

### First Pass (5 minutes)

1. **Don't solve anything** — just scan
2. Mark GREEN questions across all subjects
3. Identify the easiest 15–20 questions
4. Note subjects with more questions than expected

### Targeted Solving (75 minutes)

1. Solve all GREEN questions first
2. Move to YELLOW questions subject by subject
3. Return to RED questions only if time permits

### Final Review (10 minutes)

1. Review all marked-for-review questions
2. Check if any questions were left unanswered by mistake
3. Ensure no question is left unattempted (if time permits, make an educated guess on easy ones)

## Common Time Traps to Avoid

### Trap 1: The Time Sink Question
- A question you don't know but keep trying for 5+ minutes
- **Solution:** Set a mental timer — 90 seconds max per question

### Trap 2: The Overtime Calculator
- A calculation that requires multiple steps and keeps giving different answers
- **Solution:** Do it once, trust your calculation, move on

### Trap 3: The Doubt Spiral
- Re-answering questions you already answered confidently
- **Solution:** Never change an answer unless you find a clear error

### Trap 4: The Perfectionist
- Trying to solve every single question
- **Solution:** 80% attempt rate is excellent; focus on accuracy

### Trap 5: The Speed Demon
- Rushing through easy questions and making silly mistakes
- **Solution:** Read each question carefully; speed comes from practice

## CBT-Specific Tips

### Interface Navigation
- Use the **question palette** on the right to jump between questions
- **Mark for review** button is your best friend — use it liberally
- Colors in palette: Answered (Green), Not Answered (Red), Marked (Purple), Both (Purple+Green)

### Calculator Strategy
- ISRO CBT provides an **on-screen calculator**
- Practice using it during mock tests — it's slower than physical calculator
- For simple arithmetic, calculate mentally to save time
- Use calculator only for complex operations

### Keyboard Shortcuts
- Learn any available keyboard shortcuts for the CBT interface
- Practice navigating with keyboard during mock tests

## Emergency Time Management

### If 30 Minutes Left and 30+ Questions Remaining

1. Stop solving — scan only
2. Answer questions where you know the answer in < 10 seconds
3. Skip all calculation-based questions
4. For 2-mark questions with partial knowledge, attempt if you can eliminate 2 options
5. For 1-mark questions, attempt only if you're confident

### If 15 Minutes Left and 15+ Questions Remaining

1. Rapid-fire mode: answer only GREEN questions
2. For remaining RED questions, make educated guesses if negative marking allows
3. Review marked-for-review questions only if they're quick

### If 5 Minutes Left

1. Answer any remaining unanswered questions
2. For MCQs, eliminate and guess (if you can eliminate at least 1 option)
3. Don't leave any question blank — there's no penalty for NOT attempting, but you lose potential marks

---

## Post-Attempt Review Strategy

### During the Last 5 Minutes

1. Scan through all 80 questions using the palette
2. Look for questions marked for review — quickly decide to answer or skip
3. Ensure no question is accidentally left blank
4. Don't change answers unless you spot a clear mistake
5. Take a deep breath — you've done your best

### Mental Checklist

- [ ] All 80 questions visited
- [ ] No question left unattempted (educated guess if needed)
- [ ] Marked-for-review questions resolved
- [ ] No answer changed without strong reason
- [ ] Time utilized fully until the last second

## Summary: Golden Rules

1. **75 seconds per question** — this is your mantra
2. **GREEN first, RED last** — always attempt easy questions first
3. **Skip aggressively** — don't let one question eat your time
4. **Never guess randomly** — negative marking is real
5. **Use the review system** — mark and come back later
6. **Track your progress** — check time checkpoints regularly
7. **Practice under exam conditions** — build exam temperament
8. **Stay calm** — panic wastes more time than difficult questions
9. **Trust your preparation** — you've prepared for this
10. **Finish strong** — use every second until time is up
