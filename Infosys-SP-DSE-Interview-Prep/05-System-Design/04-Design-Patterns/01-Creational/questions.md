# Design Patterns — Creational Interview Questions and Answers

## Q1: What are creational design patterns?
**A:** Patterns controlling object creation — decoupling instantiation from the code that uses objects: Singleton, Factory, Abstract Factory, Builder, Prototype.

## Q2: What is a Singleton?
**A:** Ensures one instance of a class globally (via __new__ in Python or a module-level object) — the config/cache connection pattern, but thread-safety and testability are its cost.

## Q3: What is a Factory method?
**A:** A method or class creating objects of a family without exposing construction logic — callers get an interface, internals choose the concrete class.

## Q4: What is the difference between Factory and Abstract Factory?
**A:** Factory: one product family via a method. Abstract Factory: a family of related factories creating related products — one level more abstraction.

## Q5: What is a Builder pattern?
**A:** Step-wise construction of complex objects (chained .with_xxx() in Python) — separating assembly from representation; useful for complex config objects.

## Q6: What is a Prototype pattern?
**A:** Creating new objects by cloning a template (copy.deepcopy) instead of rebuilding — expensive init avoided; the copying idiom in Python.

## Q7: What is the trade-off of returning Singletons in web apps?
**A:** Shared state across requests is a bug source — use dependency-injected modules instead; the design conversation is about lifecycle.

## Q8: How do creational patterns show up in FastAPI?
**A:** Dependency injection and Depends() factories are construction decoupling by the framework — your endpoints receive built collaborators instead of creating them.

## Q9: What is the trade-off between patterns and simplicity today?
**A:** Python idioms (module singletons, dataclasses as builders) often replace explicit GoF scaffolding — know the intent, not just the UML.

## Q10: What is lazy instantiation?
**A:** Creating the object on first use rather than at startup — saving cost when it's rarely used (a classic singleton variant).
