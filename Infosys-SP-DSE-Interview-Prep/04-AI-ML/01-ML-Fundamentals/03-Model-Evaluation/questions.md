# Ml Fundamentals — Model Evaluation Interview Questions and Answers

## Q1: What is accuracy and its limitation?
**A:** Accuracy = correct/total; misleading on imbalanced data (99:1 always-predict-majority gives 99%). Precision/recall/F1 matter more there.

## Q2: What is precision, recall, and F1?
**A:** Precision = TP/(TP+FP) (how many predicted positives are right); Recall = TP/(TP+FN) (how many real positives were found); F1 = harmonic mean balancing both.

## Q3: What is a confusion matrix?
**A:** TP/FP/FN/TN laid out per class — the table precision/recall derive from; multi-class extends it to row/column per label.

## Q4: What is ROC-AUC?
**A:** ROC plots TPR vs FPR across thresholds; AUC is the probability a random positive ranks above a random negative — threshold-independent quality; AUC 0.5 is random.

## Q5: What is precision-recall curve and when prefer it over ROC?
**A:** PR focuses on the positive class — best for highly imbalanced tasks (fraud, disease) where ROC looks too optimistic.

## Q6: What is a regression evaluation metric?
**A:** MSE (big-error averse), RMSE (same units as target), MAE (robust, linear penalty), R^2 (variance explained) — pick per business cost of errors.

## Q7: What is bias in evaluation — data leakage?
**A:** Informing the model of test data (fit scaler on full data, oversampling before split) inflates metrics; leak detection is an interview favourite.

## Q8: What is the difference between training accuracy and validation accuracy drift?
**A:** Train high + val low = overfitting; both low = underfit; both high and close = healthy generalisation — the diagnostic readout.

## Q9: What is a learning curve?
**A:** Plotting train/val error vs training size clues capacity: converging curves mean well-behaved; persistent gaps mean high variance.

## Q10: What is cross-entropy loss used as a metric?
**A:** Measures disagreement between predicted probability distribution and true labels; lower = better calibration — standard for classification training.

## Q11: What is a business-metric evaluation?
**A:** Map ML errors to money (false positives cost X, false negatives cost Y) — choosing the threshold that minimises expected cost, not just AUC.
