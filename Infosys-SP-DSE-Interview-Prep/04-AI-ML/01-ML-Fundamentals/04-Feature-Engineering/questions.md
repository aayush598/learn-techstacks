# Ml Fundamentals — Feature Engineering Interview Questions and Answers

## Q1: What is feature engineering?
**A:** Transforming raw data into predictive inputs: encoding, scaling, binning, interactions, and derived quantities — often worth more than model choice.

## Q2: What is one-hot encoding vs label encoding?
**A:** One-hot: k columns for k categories (no ordinality, works for trees/linear). Label encoding: integers — only for ordinal data or targets; avoid imposing false order.

## Q3: What is standardisation vs normalisation?
**A:** Standardisation: zero-mean/unit-var (z-scores) for Gaussian-ish and distance models; min-max normalisation: scale to [0,1]. Choose per algorithm.

## Q4: What is handling of missing values in features?
**A:** Drop (if random/tiny), mean/median/mode impute, model-based imputation, or flag the missingness as a feature — the safer approaches than silently dropping rows.

## Q5: What are the datetime/date features you'd extract?
**A:** Day-of-week, month, hour, is_weekend, season, elapsed time — turning timestamps into pattern-capturing columns for forecasting/ranking.

## Q6: What is feature scaling's effect on gradient descent?
**A:** Unscaled features make the loss surface elongated, slowing convergence; scaling features speeds up optimisation and improves distance metrics.

## Q7: What is an interaction feature?
**A:** A synthetic column combining two variables (product/sum) — capturing effects a linear model can't express, e.g., price × quantity = revenue.

## Q8: What is a text-to-feature pipeline?
**A:** TF-IDF/bag-of-words, word embeddings, or LLM encodings followed by dimensionality reduction — depending on the downstream model.

## Q9: How do you remove redundant features?
**A:** Correlation/VIff inspection, mutual-information scoring, tree-importances, and backward elimination — reducing multicollinearity and overfitting.

## Q10: What is the curse of dimensionality?
**A:** As feature count grows, data becomes sparse so distances lose meaning — models overfit and clusters dissolve; dimensionality reduction counters it.

## Q13: What are the advantages and disadvantages of 04 feature engineering?
**A:** Advantages: predictability of behaviour, standardised semantics, widely understood patterns. Disadvantages: each design brings overhead or constraints, so it must be balanced against simplicity and project context whenever an alternative exists.
