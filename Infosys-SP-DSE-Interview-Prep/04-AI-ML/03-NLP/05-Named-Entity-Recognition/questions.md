1. **What is NER?**
   - Named Entity Recognition labels spans in text as PERSON, ORG, LOCATION, DATE, etc. — the information-extraction workhorse for search, compliance, and knowledge graphs.

2. **What is the BIO/IOB tagging scheme?**
   - B-(egin), I-(nside), O(utside) per token: 'Barack B-PERSON Obama I-PERSON' — the sequence-labelling framing of NER.

3. **What are the classical NER approaches?**
   - Rule/dictionary-based, CRF + hand-crafted features, BiLSTM-CRF neural tagging, now fine-tuned BERT — each escalation improves coverage at compute cost.

4. **What is a CRF and why did it pair with BiLSTM?**
   - Conditional Random Field models label transitions — enforcing valid tag sequences (I-PER must follow B-PER); the BiLSTM produced features, CRF decoded them.

5. **How does transformer-based NER work?**
   - Fine-tuned token classifiers predict a tag per token; subword tokens need alignment back to word spans — the modern highest-accuracy approach.

6. **What are the evaluation metrics for NER?**
   - Micro/macro F1 over entity spans (exact-match of boundaries) — partial overlaps count as errors; strict vs relaxed scoring variants.

7. **What is the challenge of entity boundaries?**
   - Long/nested entities and adjacent entities share boundaries; the model must decide exact span endpoints — boundary detection is harder than the type.

8. **What is a knowledge-graph extraction pipeline using NER?**
   - NER -> entity linking (map to ontology IDs) -> relation extraction -> triples loaded into a graph — the GenAI RAG/knowledge-base interplay.

9. **What are domain-specific entity types?**
   - Custom labels like product codes, chemical compounds, or device SKUs — needing annotated data and custom tag sets beyond the generic 4-5.

10. **What is annotation and how do you build training data?**
   - Human/progmatic labelling tools (Prodigy, label-studio); weak supervision from lexicons/distant patterns reduces cost — data-quality feedback loop.
