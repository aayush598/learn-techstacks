# Llm And Genai — Embeddings And Vector Db Interview Questions and Answers

## Q1: What is an embedding model and how do embeddings work?
**A:** A neural encoder mapping text/images to dense vectors where semantically similar items are close — cosine/Euclidean distance become semantic similarity.

## Q2: What makes embeddings useful?
**A:** They make meaning computable: search, clustering, dedup, recommendation via geometric proximity, unprepared labelled labels.

## Q3: What is cosine vs Euclidean distance?
**A:** cosine ignores magnitude (direction only), best for text embeddings; Euclidean considers length — DNS/AR/Cos differs per embedding model.

## Q4: What is a vector database (Pinecone, Chroma, Milvus, Qdrant, Weaviate)?
**A:** A purpose-built store with ANN indexes, metadata filters, and CRUD over embedding vectors — the retrieval layer of RAG.

## Q5: What is ANN (approximate nearest neighbour)?
**A:** Indexes trading a tiny recall loss for huge speedups (HNSW, IVF-PQ) — brute-force similarity is too slow at scale.

## Q6: What is HNSW?
**A:** Hierarchical Navigable Small World graph index — a graph of overlapping layers with greedy greedy search; state-of-the-art for recall/latency balance.

## Q7: What is the difference between semantic search and keyword search?
**A:** Semantic catches paraphrase/intent (vector); keyword is exact-term deterministic (BM25) — hybridisation covers both.

## Q8: What is metadata filtering in a vector store?
**A:** Pre-filtering/narrowing the index by fields (date, author, tenant) before similarity — scoping retrieval for correctness and speed.

## Q9: What is embedding dimension and how do you pick a model?
**A:** Model output size (e.g., 768/1536); higher is more expressive but costs memory — choose by corpus size, latency, and quality needs.

## Q10: How do embeddings relate to your ScriptVector-style project?
**A:** Input snippets -> chunk -> embed -> vector index -> semantic lookup for code/docs — the exact RAG embedding pipeline you've built; describe it with these components.

## Q11: What is a reranker and why add one?
**A:** A cross-encoder scoring query-passage pairs precisely, re-ordering candidates — small effort, large precision gains at the top of the prompt.
