1. **What is an LLM?**
   - A large transformer-based language model (billions+ of parameters) pre-trained on massive text corpora to predict the next token — fine-tuned/RL-aligned for helpful assistants.

2. **How does an LLM generate text?**
   - Autoregressively: each output token conditions on all prior tokens; decoding strategies sample or greedily pick from the next-token distribution.

3. **What is temperature sampling?**
   - Scaling logits before softmax: low temperature sharpens (deterministic), high temperature flattens (creative) — the creativity knob.

4. **What is top-k / top-p (nucleus) sampling?**
   - Restricting the next-token choice to the top-k candidates or the smallest set with cumulative probability p — pruning low-probability tails for coherence.

5. **What is the difference between pre-training and fine-tuning an LLM?**
   - Pre-training learns general language from raw text (huge compute); fine-tuning adapts it to tasks/instruction/domain with smaller curated data.

6. **What is an instruction-tuned model?**
   - Fine-tuned on (instruction, response) pairs so the model follows directions instead of predicting text — the IFT ⇢ RLHF → assistant stack.

7. **What is RLHF?**
   - Reinforcement learning from human feedback: a reward model trained on human preferences steers the policy to align with preference — ChatGPT-era alignment.

8. **What is the context window?**
   - The maximum token input an LLM accepts; beyond it, context is truncated/extended by RoPE/scaling — the memory ceiling of conversation.

9. **What are hallucinations?**
   - Fluent but fabricated outputs — the model has no epistemic grounding; mitigated by RAG, prompting confidence, and fact-checking layers.

10. **What are the scaling laws?**
   - Empirical power-laws linking model size, data, compute to loss — predicting that predictable improvements justify big training runs.

11. **What is a checkpoint vs a deployed model?**
   - A checkpoint is the weights snapshot; deployment wraps it with a serving/tokeniser/API — the ops difference between training and production.

12. **What is the difference between a base model and a chat model?**
   - Base: raw next-token prediction, streaming and unpredictable; chat: instruction/RLHF-aligned with roles, refusals, and formatting.
