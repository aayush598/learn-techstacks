# Llm And Genai — Llm Fundamentals Interview Questions and Answers

## Q1: What is an LLM?
**A:** A large transformer-based language model (billions+ of parameters) pre-trained on massive text corpora to predict the next token — fine-tuned/RL-aligned for helpful assistants.

## Q2: How does an LLM generate text?
**A:** Autoregressively: each output token conditions on all prior tokens; decoding strategies sample or greedily pick from the next-token distribution.

## Q3: What is temperature sampling?
**A:** Scaling logits before softmax: low temperature sharpens (deterministic), high temperature flattens (creative) — the creativity knob.

## Q4: What is top-k / top-p (nucleus) sampling?
**A:** Restricting the next-token choice to the top-k candidates or the smallest set with cumulative probability p — pruning low-probability tails for coherence.

## Q5: What is the difference between pre-training and fine-tuning an LLM?
**A:** Pre-training learns general language from raw text (huge compute); fine-tuning adapts it to tasks/instruction/domain with smaller curated data.

## Q6: What is an instruction-tuned model?
**A:** Fine-tuned on (instruction, response) pairs so the model follows directions instead of predicting text — the IFT ⇢ RLHF → assistant stack.

## Q7: What is RLHF?
**A:** Reinforcement learning from human feedback: a reward model trained on human preferences steers the policy to align with preference — ChatGPT-era alignment.

## Q8: What is the context window?
**A:** The maximum token input an LLM accepts; beyond it, context is truncated/extended by RoPE/scaling — the memory ceiling of conversation.

## Q9: What are hallucinations?
**A:** Fluent but fabricated outputs — the model has no epistemic grounding; mitigated by RAG, prompting confidence, and fact-checking layers.

## Q10: What are the scaling laws?
**A:** Empirical power-laws linking model size, data, compute to loss — predicting that predictable improvements justify big training runs.

## Q11: What is a checkpoint vs a deployed model?
**A:** A checkpoint is the weights snapshot; deployment wraps it with a serving/tokeniser/API — the ops difference between training and production.

## Q12: What is the difference between a base model and a chat model?
**A:** Base: raw next-token prediction, streaming and unpredictable; chat: instruction/RLHF-aligned with roles, refusals, and formatting.
