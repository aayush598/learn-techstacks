# Llm And Genai — Prompt Engineering Interview Questions and Answers

## Q1: What is prompt engineering?
**A:** Designing inputs to steer model outputs reliably: role instructions, context, few-shot examples, and output constraints — the transferable skill for any LLM app.

## Q2: What is the zero-shot vs few-shot prompting?
**A:** Zero-shot: instructions only. Few-shot: few input/output exemplars establish the pattern. Choose few-shot when format/edge cases are tricky; trim to save tokens.

## Q3: What is chain-of-thought (CoT) prompting?
**A:** Prompting for step-by-step reasoning ('think step by step') — noticeably improves complex reasoning (math, logic) though it costs tokens and latency.

## Q4: What is a system prompt vs user prompt?
**A:** System: persistent instructions/behavioural constraints (roles, tone, rules). User: the actual request. Structuring this split is the core of production apps.

## Q5: What is output formatting control?
**A:** Requesting JSON/markdown fixtures, enums, and length caps in the prompt plus asking the model to validate — robust structured outputs from prompts alone.

## Q6: What is prompt injection and how do you defend it?
**A:** Malicious user content overrides your instructions (ignore previous, reveal key). Defenses: treat input as data, delimit with classifiers, sanitise tool calls, least-privilege.

## Q7: What is metadata/context packing in RAG prompts?
**A:** Fitting retrieved chunks into the instruction template with the user question — the prompt design that decides answer quality in RAG.

## Q8: What is few-shot selection and examples quality?
**A:** Choosing representative, correctly-formatted examples beats random sampling — mislabelled few-shots poison every shot after them.

## Q9: What is temperature/verbosity control?
**A:** Low temperature + concise instructions for deterministic APIs; high temperature for creative writing — calibrating per use case.

## Q10: What is a constrained/guarded prompt?
**A:** Explicit 'Do not X' plus output schema plus post-hoc validation — layered guardrails rather than a single hopeful line.

## Q11: What is chain-of-density / summarisation prompting?
**A:** Iteratively prompting for increasingly dense summaries — retaining detail while compressing; a trick for long-context distillation.
