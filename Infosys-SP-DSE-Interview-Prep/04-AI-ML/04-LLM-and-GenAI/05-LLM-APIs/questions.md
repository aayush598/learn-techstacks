# Llm And Genai — Llm Apis Interview Questions and Answers

## Q1: What are the main LLM API families?
**A:** OpenAI (GPT-4o-series, embeddings), Google (Gemini on Vertex/AI Studio), Anthropic (Claude), OpenRouter for unified access — chat/completions + embeddings endpoints.

## Q2: What is the chat completions structure?
**A:** POST with messages=[{role: system/user/assistant, content}], model, temperature; returns choices with content — the omnipresent API shape.

## Q3: What is function/tool calling in LLM APIs?
**A:** The model emits a structured function-call (name + args) instead of plain text; your app runs it and feeds the result back — the foundation of agentic apps.

## Q4: What is structured output / response format?
**A:** JSON-schema-validation (or JSON mode) forcing the model's output into a schema — reliable programmatic consumption without parsing gymnastics.

## Q5: What is embeddings API usage?
**A:** POST to the embeddings endpoint returning vector lists per input — powering the retrieval stores and similarity logic of RAG.

## Q6: What is streaming and why use it?
**A:** Incremental tokens over SSE — low time-to-first-token perceived latency and progressive UI rendering for chat apps.

## Q7: How do you manage API keys, rate limits, and retries?
**A:** Env/secret injection, exponential backoff on 429, token-budget accounting — the production-hardening practices interviewers ask about.

## Q8: What is the cost/time profile of a call?
**A:** Bill by prompt+completion tokens; latency scales with output length; batching/caching reduce spend — calculate per-request economics for products.

## Q9: What is model caching or prompt caching?
**A:** Providers cache repeated prefixes (system prompts, few-shots) at a discount — big savings for stable RAG/agent system prompts.

## Q10: What is the difference between a provider-agnostic layer and direct SDKs?
**A:** wrappers (OpenRouter, LiteLLM) normalise APIs across providers — resume-visible engineering of swapping models without code rewrites.
