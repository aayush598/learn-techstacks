1. **What is transfer learning?**
   - Borrowing representations from a model trained on a big task and adapting them to a smaller related task — faster, less data, better small-dataset performance.

2. **What is fine-tuning?**
   - Continuing training a pre-trained model (with a small learning rate) on the target data, unfreezing some/all layers — the standard way to adapt large models.

3. **What is feature extraction vs fine-tuning?**
   - Feature extraction freezes the backbone and trains only the new head; fine-tuning updates pre-trained weights too — feature extraction first, unfreeze gradually.

4. **Why does transfer learning work?**
   - Early layers learn generic features (edges, syntax, patterns) transferable across tasks; only the top layers are task-specific — reusing the generic base saves data/compute.

5. **What is catastrophic forgetting?**
   - Fine-tuning on new data can overwrite old knowledge — mitigated with lower LR, replay/buffers, LoRA-style low-rank adaptation.

6. **What are LoRA and parameter-efficient fine-tuning (PEFT)?**
   - LoRA adds small trainable low-rank matrices while freezing the base — near full fine-tune quality with a fraction of the memory, enabling multi-adapter serving.

7. **What is a pre-trained checkpoint and how do you choose one?**
   - A snapshot of weights trained on a corpus (GPT, Llama, BERT); choose by modality, task type, license, and size-vs-resource trade-offs.

8. **How do you avoid overfitting when fine-tuning small data?**
   - Tiny learning rate, few epochs, early stopping, heavier regularisation, and warmup — protecting the rich pre-trained features.

9. **What is the difference between zero-shot and few-shot?**
   - Zero-shot uses the model as-is with just a prompt; few-shot supplies example demos — both avoid additional training; fine-tuning is when demos aren't enough.

10. **What is domain adaptation?**
   - Shifting a model from a source domain (clean news text) to a target domain (tweets with slang) — a specialised transfer-learning case.
