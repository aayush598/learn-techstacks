# Deep Learning — Transfer Learning Interview Questions and Answers

## Q1: What is transfer learning?
**A:** Borrowing representations from a model trained on a big task and adapting them to a smaller related task — faster, less data, better small-dataset performance.

## Q2: What is fine-tuning?
**A:** Continuing training a pre-trained model (with a small learning rate) on the target data, unfreezing some/all layers — the standard way to adapt large models.

## Q3: What is feature extraction vs fine-tuning?
**A:** Feature extraction freezes the backbone and trains only the new head; fine-tuning updates pre-trained weights too — feature extraction first, unfreeze gradually.

## Q4: Why does transfer learning work?
**A:** Early layers learn generic features (edges, syntax, patterns) transferable across tasks; only the top layers are task-specific — reusing the generic base saves data/compute.

## Q5: What is catastrophic forgetting?
**A:** Fine-tuning on new data can overwrite old knowledge — mitigated with lower LR, replay/buffers, LoRA-style low-rank adaptation.

## Q6: What are LoRA and parameter-efficient fine-tuning (PEFT)?
**A:** LoRA adds small trainable low-rank matrices while freezing the base — near full fine-tune quality with a fraction of the memory, enabling multi-adapter serving.

## Q7: What is a pre-trained checkpoint and how do you choose one?
**A:** A snapshot of weights trained on a corpus (GPT, Llama, BERT); choose by modality, task type, license, and size-vs-resource trade-offs.

## Q8: How do you avoid overfitting when fine-tuning small data?
**A:** Tiny learning rate, few epochs, early stopping, heavier regularisation, and warmup — protecting the rich pre-trained features.

## Q9: What is the difference between zero-shot and few-shot?
**A:** Zero-shot uses the model as-is with just a prompt; few-shot supplies example demos — both avoid additional training; fine-tuning is when demos aren't enough.

## Q10: What is domain adaptation?
**A:** Shifting a model from a source domain (clean news text) to a target domain (tweets with slang) — a specialised transfer-learning case.
