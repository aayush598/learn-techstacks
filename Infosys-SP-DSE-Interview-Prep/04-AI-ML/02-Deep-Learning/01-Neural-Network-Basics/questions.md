# Deep Learning — Neural Network Basics Interview Questions and Answers

## Q1: What is a neuron/perceptron?
**A:** A weighted sum of inputs passed through a non-linear activation: y = activation(w·x + b). Stacked and chained, these form deep networks.

## Q2: What are activation functions and common choices?
**A:** ReLU (fast, sparse, default hidden), sigmoid (0-1 output), tanh (-1..1), softmax (probabilities); each has gradient regimes — ReLU dominates hidden layers.

## Q3: What is a loss function in DL?
**A:** A scalar quantifying prediction error minimised by training — cross-entropy for classification, MSE/MAE for regression; choice shapes the gradients.

## Q4: What is backpropagation?
**A:** The chain rule applied backward through the graph computing gradients of the loss w.r.t. every weight — the training engine behind all DL.

## Q5: What is a gradient descent and its variants?
**A:** SGD (one sample), mini-batch SGD (batch), Momentum/Adam (adaptive) — the optimiser family; Adam is the pragmatic default in modern training.

## Q6: What is overfitting in a neural net?
**A:** High capacity memorises training noise; diagnosed by train/val divergence; fixed with regularisation, augmentation, dropout, early stopping, more data.

## Q7: What is the vanishing/exploding gradient problem?
**A:** Gradients multiply across layers tending to 0 or infinity; mitigated by ReLU/leaky-ReLU, normalised initialisation, batchnorm, skip connections, and residual blocks.

## Q8: What is an epoch, batch, and iteration?
**A:** Epoch: one full pass over data. Batch: a chunk per update. Iteration: one batch step per epoch = samples/batch_size — the training-loop vocabulary.

## Q9: What is a learning rate and how is it chosen?
**A:** Step size of weight updates; too high diverges, too low stalls — schedule/decay and Adam's adaptive rates handle much of the tuning.

## Q10: What is the difference between hyperparameters and parameters?
**A:** Parameters are learned weights; hyperparameters (layers, lr, batch size) are set by the engineer and tuned by validation.

## Q11: What is GPU acceleration in training?
**A:** Massively parallel matrix ops the CUDA/cuDNN stack accelerates; batching utilises the GPU, memory (VRAM) caps batch size — the practical training bottleneck discussion.

## Q12: What is weight initialisation?
**A:** Setting starting weights to avoid symmetry and vanishing gradients (He/Xavier); wrong init stalls training regardless of later optimisation.
