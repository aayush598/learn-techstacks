# Deep Learning — Transformers Interview Questions and Answers

## Q1: What is a transformer?
**A:** A sequence model using self-attention instead of recurrence; parallel over positions, stackable layers, and the backbone of modern AI (BERT, GPT, T5).

## Q2: What is self-attention?
**A:** Each token computes Q, K, V projections; attention weights = softmax(QK^T / sqrt(d)) applied to V — allowing every token to aggregate relevant context.

## Q3: What is the multi-head attention?
**A:** Several attention heads in parallel, each learning a different relationship subspace — concatenated and re-projected into the model width.

## Q4: What is the role of positional encoding?
**A:** Because attention is permutation-invariant, explicit position vectors (sinusoidal or learned) inject order information.

## Q5: What is the transformer block composition?
**A:** Input: (sub)layer-norm + multi-head self-attention, then a feed-forward MLP with a residual and norm — stacked N times in both encoder and decoder.

## Q6: What is the difference between encoder-only, decoder-only, and encoder-decoder?
**A:** Encoder-only (BERT): understanding/embedding. Decoder-only (GPT): generation. Encoder-decoder (T5/BART): seq2seq with full context. The architecture taxonomy.

## Q7: What is masked/autoregressive attention?
**A:** Causal masking prevents decoder tokens from attending to future tokens — preserving left-to-right generation order.

## Q8: What are KV-cache and inference efficiency?
**A:** Recomputing nothing: cached-K/V per token enable O(1)-per-token generation — the mechanism behind LLM serving and its memory ceiling.

## Q9: Why did transformers scale so well?
**A:** Parallel token processing (GPU-friendly), long-range dependencies span the input, and scaling laws — compute/data/model scale simply and predictably improve.

## Q10: What are transformer limitations?
**A:** Quadratic attention cost O(n^2) in sequence length, context-window memory, and hallucination — the motivation for FlashAttention, sparse attention, and RAG.

## Q11: What is FlashAttention?
**A:** An I/O-aware attention kernel tiling attention onto SRAM — near-linear speedups and big memory savings without changing the math.

## Q12: What is the difference between attention and convolution?
**A:** Attention is content-dependent, global, and parallel-safe; convolution is fixed-window, translation-equivariant — transformers learned them; hybrids (Conformer, Mamba) blend both.
