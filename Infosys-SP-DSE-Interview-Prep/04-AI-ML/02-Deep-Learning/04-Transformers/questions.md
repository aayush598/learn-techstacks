1. **What is a transformer?**
   - A sequence model using self-attention instead of recurrence; parallel over positions, stackable layers, and the backbone of modern AI (BERT, GPT, T5).

2. **What is self-attention?**
   - Each token computes Q, K, V projections; attention weights = softmax(QK^T / sqrt(d)) applied to V — allowing every token to aggregate relevant context.

3. **What is the multi-head attention?**
   - Several attention heads in parallel, each learning a different relationship subspace — concatenated and re-projected into the model width.

4. **What is the role of positional encoding?**
   - Because attention is permutation-invariant, explicit position vectors (sinusoidal or learned) inject order information.

5. **What is the transformer block composition?**
   - Input: (sub)layer-norm + multi-head self-attention, then a feed-forward MLP with a residual and norm — stacked N times in both encoder and decoder.

6. **What is the difference between encoder-only, decoder-only, and encoder-decoder?**
   - Encoder-only (BERT): understanding/embedding. Decoder-only (GPT): generation. Encoder-decoder (T5/BART): seq2seq with full context. The architecture taxonomy.

7. **What is masked/autoregressive attention?**
   - Causal masking prevents decoder tokens from attending to future tokens — preserving left-to-right generation order.

8. **What are KV-cache and inference efficiency?**
   - Recomputing nothing: cached-K/V per token enable O(1)-per-token generation — the mechanism behind LLM serving and its memory ceiling.

9. **Why did transformers scale so well?**
   - Parallel token processing (GPU-friendly), long-range dependencies span the input, and scaling laws — compute/data/model scale simply and predictably improve.

10. **What are transformer limitations?**
   - Quadratic attention cost O(n^2) in sequence length, context-window memory, and hallucination — the motivation for FlashAttention, sparse attention, and RAG.

11. **What is FlashAttention?**
   - An I/O-aware attention kernel tiling attention onto SRAM — near-linear speedups and big memory savings without changing the math.

12. **What is the difference between attention and convolution?**
   - Attention is content-dependent, global, and parallel-safe; convolution is fixed-window, translation-equivariant — transformers learned them; hybrids (Conformer, Mamba) blend both.
