# Python Basics — Lists And Tuples Interview Questions and Answers

## Q1: What is a list?
**A:** A mutable, ordered sequence of heterogenous objects — O(1) append/pop at end, O(n) insert/remove, supports slicing, indexing, and iteration.

## Q2: What is a tuple and when prefer it over a list?
**A:** Immutable ordered sequence — used as dict keys, to return multiple values, and to signal fixed data; slightly cheaper and hashable.

## Q3: What is the difference between list.append, extend, and insert?
**A:** append adds one element; extend merges an iterable's items; insert(index, x) places x at a position shifting the rest.

## Q4: How does list slicing work?
**A:** lst[start:stop:step] returns a new list (shallow copy of references); negative indices count from the end; lst[::-1] reverses.

## Q5: What is the time complexity of common list ops?
**A:** Index O(1), append/pop O(1) amortised, insert/delete middle O(n), membership `in` O(n), copy O(n), sort O(n log n).

## Q6: What is list comprehension vs map/filter?
**A:** Comprehensions are idiomatic and faster than map/filter with lambdas; `[str(x) for x in nums]` reads better than `map(str, nums)` for most developers.

## Q7: How do you flatten a nested list?
**A:** [x for sub in nested for x in sub]; generic recursion or itertools.chain.from_iterable for one level.

## Q8: What is a namedtuple?
**A:** A tuple subclass with named fields — tuple immutability plus attribute access; used for lightweight records (Point(x=1,y=2)).

## Q9: What are sorting keys?
**A:** sorted(lst, key=len) sorts by the key function without touching items; use reverse=True and operator.itemgetter for multi-field sorts.

## Q10: What is a deque and when use it over a list?
**A:** collections.deque gives O(1) appendleft/popleft — ideal for queues/undo stacks; lists are O(n) at the front.
