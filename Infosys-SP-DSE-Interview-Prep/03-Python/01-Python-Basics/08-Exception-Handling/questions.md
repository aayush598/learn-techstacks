# Python Basics — Exception Handling Interview Questions and Answers

## Q1: What is try/except/else/finally?
**A:** try runs risky code; except catches specified exceptions; else runs only if no exception; finally always runs (cleanup) — the full block layout.

## Q2: What is the difference between an exception and an error?
**A:** Exception: a recoverable runtime fault (ValueError, KeyError, custom). SystemExit/KeyboardInterrupt they are BaseExceptions, not errors — catch carefully.

## Q3: How do you catch multiple exception types?
**A:** except (TypeError, ValueError) as e: — one handler for several classes; catch specific types first, Exception last.

## Q4: What is raise and how do you propagate exceptions?
**A:** raise ValueError('msg') throws; bare `raise` re-raises the current exception preserving the traceback — idiomatic propagation.

## Q5: What is a custom exception and when define one?
**A:** class MyError(Exception): pass — gives callers a stable, semantic type to catch; always subclass Exception, never BaseException.

## Q6: What is the BaseException hierarchy?
**A:** BaseException -> Exception -> (ValueError, TypeError, ...); KeyboardInterrupt/SystemExit inherit BaseException directly — a bare except: captures even those (don't do it).

## Q7: What is an assertion?
**A:** assert cond, 'msg' raises AssertionError if false; typically disabled with -O — for invariants, not input validation in production.

## Q8: What is the difference between logging vs printing errors?
**A:** Logging (logging module) records structured, configurable, timestamped messages; print goes to stdout. In production use logging.exception in except blocks.

## Q9: What is the with-exception interplay?
**A:** Context managers' __exit__ can swallow or re-raise exceptions — allowing resource cleanup plus error suppression where intended.

## Q10: What is the try/finally purpose without except?
**A:** finally guarantees cleanup (close files, release locks) even on error, letting the exception propagate — the old pattern the with statement automates.
