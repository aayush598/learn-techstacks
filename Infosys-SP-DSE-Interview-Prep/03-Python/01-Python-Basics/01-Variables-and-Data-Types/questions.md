# Python Basics — Variables And Data Types Interview Questions and Answers

## Q1: What primitive/immutable vs mutable types exist in Python?
**A:** Immutable: int, float, bool, str, tuple, frozenset. Mutable: list, dict, set, bytearray. Immutables can be hashed (dict keys), mutables can be changed in place.

## Q2: What is the difference between == and is?
**A:** == compares values (equality); is compares object identity (same memory address). Common trap: small ints and interned strings may compare is True by CPython internment.

## Q3: What is dynamic typing vs static typing?
**A:** Python infers types at runtime and rebinds any name; C/Java fix types at compile time. Type hints (PEP 484) only aid tools/mypy, they are never enforced at runtime.

## Q4: What are None and how do you check it?
**A:** None is Python's null single object; check with `x is None` (never ==). Functions without return implicitly return None.

## Q5: What is type coercion / implicit conversion in Python?
**A:** Operators implicitly convert: int + float -> float, comparisons across int/str fail; use int(), float(), str(), bool() to convert explicitly.

## Q6: What is the scope: LEGB rule?
**A:** Name resolution order: Local -> Enclosing -> Global -> Built-in. A name is looked up in that order; assigning creates a local unless declared global/nonlocal.

## Q7: What is integer precision in Python?
**A:** Python ints are arbitrary precision (big ints) with no overflow — a common contrast to Java/C where ints wrap or overflow.

## Q8: What is a float and its precision caveat?
**A:** IEEE 754 double with ~15-17 significant digits; 0.1 + 0.2 != 0.3 due to binary representation — use Decimal for money, or round for display.

## Q9: What is a boolean in Python?
**A:** bool subclasses int; True==1, False==0. Truthiness: empty containers, 0, None, empty str are falsy; everything else truthy.

## Q10: What is the difference between type() and isinstance()?
**A:** type(x) gives the exact class; isinstance(x, cls) checks the whole MRO including subclasses — always prefer isinstance for hierarchy checks.
