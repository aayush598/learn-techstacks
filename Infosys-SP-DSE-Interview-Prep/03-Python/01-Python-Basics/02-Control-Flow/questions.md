# Python Basics — Control Flow Interview Questions and Answers

## Q1: What is the difference between if/elif/else and a switch statement?
**A:** Python has no switch/case (until match case); elif chains evaluate sequentially. match/case (3.10+) provides structural pattern matching.

## Q2: How do for and while loops work?
**A:** for iterates over any iterable (list, range, dict, generator); while repeats while a condition is truthy; else on a loop runs if no break occurred.

## Q3: What does break, continue, and pass do?
**A:** break exits the innermost loop, continue skips to the next iteration, pass is a no-op placeholder (also used in empty classes/functions).

## Q4: What is a list comprehension?
**A:** A concise constructor: [expr for x in iterable if cond]; equivalent to nested for + append. Prefer comprehensions for readability and speed.

## Q5: What is the ternary conditional expression?
**A:** value_if_true if condition else value_if_false — a compact branch; avoid nesting multiple ternaries for readability.

## Q6: What is zip() used for in loops?
**A:** Pairs iterables element-wise: for a,b in zip(xs,ys); stops at the shortest; zip_longest (itertools) pads instead.

## Q7: What is enumerate()?
**A:** Yields (index, element) pairs in a loop — better than manual range(len(x)) indexing for most cases.

## Q8: What is short-circuit evaluation?
**A:** and/or evaluate left to right and stop early: `None or value` returns value, `x and f(x)` never calls f when x falsy — guards avoid errors.

## Q9: What does a for/else or while/else clause mean?
**A:** The else block runs only when the loop completes without break — a concise 'didn't find it' flag for search loops.

## Q10: What is a walrus operator (:=)?
**A:** Assignment expression binding a value inline: while (line := f.readline()): — Python 3.8+, reduces duplicate calls in conditions.
