# Python Basics — File Handling Interview Questions and Answers

## Q1: How do you open and read a file?
**A:** with open('f.txt','r') as f: data = f.read() — the with block guarantees closing, even on exceptions; modes r/w/a and binary variants.

## Q2: What are the file modes?
**A:** r read, w write (truncates), a append, x exclusive create, + for read/write; b for binary ('rb'). Every mode question starts here.

## Q3: What is the difference between read, readline, readlines?
**A:** read(size) reads the whole/limited bytes; readline() reads one line with newline preserved; readlines() returns a list of lines — iterate the file object for lines lazily.

## Q4: What is the purpose of the with statement?
**A:** Context manager protocol: __enter__/__exit__ run before/after the block, closing the file even on exceptions — the correct resource idiom.

## Q5: How do you write to a file?
**A:** f.write(text) writes once; f.writelines(seq) writes many without adding newlines; open with 'w' truncates — use 'a' to append.

## Q6: What is a CSV/JSON read pattern?
**A:** csv.reader iterates rows; json.load(fp) parses whole documents; both are stdlib — the data-format handling interviewers ask about.

## Q7: What is seek and tell?
**A:** tell() returns the current offset; seek(offset, whence) moves it — used for random access and binary file parsing.

## Q8: What is the difference between buffered and unbuffered I/O?
**A:** Text files are line-buffered by default; binary can be buffered (default) or unbuffered (mode buffering=0); flush() forces writes. Performance trade-off.

## Q9: How do you append vs overwrite?
**A:** open(...,'a') appends to the end preserving content; open(...,'w') truncates — the classic distinction for log files.

## Q10: How do you iterate a large file efficiently?
**A:** for line in open(path): processes line by line streaming from disk — never read() a huge file into memory whole.
