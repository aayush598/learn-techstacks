# Python Basics — Dictionaries And Sets Interview Questions and Answers

## Q1: What is a dict and how is it implemented?
**A:** An ordered (since 3.7) key→value mapping implemented as a hash table with open addressing; O(1) average lookup/insert/delete.

## Q2: What makes an object usable as a dict key?
**A:** It must be hashable — immutable types by default; custom classes are hashable by identity unless __eq__ is defined (then __hash__ must be set to a new rule).

## Q3: What is the difference between a dict and a set?
**A:** dict maps keys to values; set is an unordered collection of unique hashable keys. Both are hash tables; sets support O(1) membership.

## Q4: What is dict.get and setdefault?
**A:** get(key, default) returns default instead of raising; setdefault(key, default) inserts only if missing — building counters/grouping without KeyError.

## Q5: What is a defaultdict?
**A:** collections.defaultdict(factory) auto-creates missing keys with the factory: defaultdict(list) for appends, defaultdict(int) for counters.

## Q6: What is an OrderedDict vs dict?
**A:** dict is insertion-ordered already (3.7+); OrderedDict additionally supports move_to_end/reorder operations used when order changes matter.

## Q7: What is a Counter?
**A:** collections.Counter is a dict subclass counting hashables; most_common(k) returns top-k — the canonical frequency tool in interviews.

## Q8: How do you merge two dicts?
**A:** d3 = {**d1, **d2} and d1 | d2 (3.9+) merge shallowly with later values winning; update() mutates in place.

## Q9: What is dictionary comprehension?
**A:** {k: v for ...} builds a dict in one expression — mapping/reversing dicts (e.g., {v:k for k,v in d.items()}).

## Q10: What is the difference between removing with pop vs del?
**A:** dict.pop(key, default) returns the value or default; del d[key] raises KeyError if missing. popitem removes the last inserted item.

## Q11: What is Counter.most_common and its complexity?
**A:** Returns sorted-by-count list; O(n log k) via heap if k given, O(n log n) otherwise. The standard answer for top-k frequent elements.
