1. **What is a dict and how is it implemented?**
   - An ordered (since 3.7) key→value mapping implemented as a hash table with open addressing; O(1) average lookup/insert/delete.

2. **What makes an object usable as a dict key?**
   - It must be hashable — immutable types by default; custom classes are hashable by identity unless __eq__ is defined (then __hash__ must be set to a new rule).

3. **What is the difference between a dict and a set?**
   - dict maps keys to values; set is an unordered collection of unique hashable keys. Both are hash tables; sets support O(1) membership.

4. **What is dict.get and setdefault?**
   - get(key, default) returns default instead of raising; setdefault(key, default) inserts only if missing — building counters/grouping without KeyError.

5. **What is a defaultdict?**
   - collections.defaultdict(factory) auto-creates missing keys with the factory: defaultdict(list) for appends, defaultdict(int) for counters.

6. **What is an OrderedDict vs dict?**
   - dict is insertion-ordered already (3.7+); OrderedDict additionally supports move_to_end/reorder operations used when order changes matter.

7. **What is a Counter?**
   - collections.Counter is a dict subclass counting hashables; most_common(k) returns top-k — the canonical frequency tool in interviews.

8. **How do you merge two dicts?**
   - d3 = {**d1, **d2} and d1 | d2 (3.9+) merge shallowly with later values winning; update() mutates in place.

9. **What is dictionary comprehension?**
   - {k: v for ...} builds a dict in one expression — mapping/reversing dicts (e.g., {v:k for k,v in d.items()}).

10. **What is the difference between removing with pop vs del?**
   - dict.pop(key, default) returns the value or default; del d[key] raises KeyError if missing. popitem removes the last inserted item.

11. **What is Counter.most_common and its complexity?**
   - Returns sorted-by-count list; O(n log k) via heap if k given, O(n log n) otherwise. The standard answer for top-k frequent elements.
