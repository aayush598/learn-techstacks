1. **What is NumPy and its core object?**
   - A library for fast numeric arrays; the ndarray — homogeneous typed data in contiguous memory enabling vectorised C-speed computation.

2. **What is the difference between a NumPy array and a Python list?**
   - ndarray: fixed-size, homogeneous, vectorised ops, broadcasting; list: heterogeneous, dynamic, Python objects, loops — arrays dominate numeric workloads.

3. **What is vectorisation and why does it matter?**
   - Operators run over whole arrays without Python-level loops: arr * 2, arr1 + arr2 — speed and cleaner code for element-wise math.

4. **What is broadcasting?**
   - NumPy implicitly stretches a smaller array across a larger one (shape rules) — arr + 5 or (3,1) + (1,4); knowing the rules avoids shape errors.

5. **How do you create arrays common ways?**
   - np.array(list), np.zeros, np.ones, np.arange, np.linspace, np.random.rand, np.eye — the instantiation roster for interviews and data work.

6. **What is the difference between reshape, resize, and flatten?**
   - reshape returns a new view (or copy) with the same data; resize mutates in place; flatten/flatten always copies; ravel may view — memory behaviour differences.

7. **What are boolean mask indexing?**
   - arr[arr > 5] returns the elements satisfying a condition — fast filtered selection powering pandas' masks underneath.

8. **What is the axis concept?**
   - axis=0 is down rows (columns aggregated), axis=1 is along columns (rows aggregated); np.sum(arr, axis=1) sums each row — the classic confusion point.

9. **What is the performance story of NumPy vs pure Python?**
   - C implementation, cache-friendly contiguous memory, no per-op Python overhead — 10-100x speedups on elementwise/linear-algebra workloads.

10. **What is np.where?**
   - np.where(cond, x, y) vectorised select; np.where(cond) returns indices — the array-level if-else function.

11. **How do you compute a mean/std in NumPy?**
   - arr.mean(), arr.std(), np.percentile(arr, 90), np.argmax(arr) — the aggregate statistics arsenal for ML feature pipelines.

12. **What is a dot product and its use?**
   - np.dot(a, b) / a @ b computes matrix products — the linchpin for linear algebra in ML/statistics (regressions, embeddings).
