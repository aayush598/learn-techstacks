# Python Libraries — Python Testing Interview Questions and Answers

## Q1: What is pytest and how does it differ from unittest?
**A:** pytest: function-based tests, plain asserts, fixtures, parametrise, plugins — less boilerplate and richer diagnostics than unittest's class-based style.

## Q2: How do you write a basic test?
**A:** def test_add(): assert add(2,3) == 5 — functions named test_* are discovered automatically; failing asserts show diff-friendly output.

## Q3: What is a fixture?
**A:** @pytest.fixture yields shared setup/teardown (DB, client, model) with scopes (function/module/session) — dependency injection for tests.

## Q4: What is parametrisation?
**A:** @pytest.mark.parametrize('x,y,expected', [(1,1,2),(2,2,4)]) runs the same test over cases — covering edge inputs without duplication.

## Q5: What is mocking and when do you use it?
**A:** unittest.mock.patch replaces external calls (HTTP, DB) with controlled fakes — testing logic without network/flakey dependencies.

## Q6: What is the difference between assert, and testing exceptions?
**A:** with pytest.raises(ValueError): validates that code raises — the negative-path test habit recruiters love.

## Q7: How do you test a FastAPI/Flask app?
**A:** FastAPI: TestClient (httpx) with monkeypatched dependencies; Flask: app.test_client() — both exercise the full request stack.

## Q8: What is the testing pyramid?
**A:** Many unit tests (fast, isolated) -> fewer integration tests (real DB/HTTP) -> few end-to-end tests — proportioning coverage cost/confidence.

## Q9: What is code coverage and how do you use it?
**A:** pytest --cov=app --cov-report=term-missing shows uncovered branches — a metric, not a goal; 100% isn't the point.

## Q10: How do tests integrate into CI?
**A:** GitHub Actions job runs pytest on each PR, failing merges on red — the quality gate wired into your CI/CD pipeline on the resume.

## Q11: What is a golden/snapshot test?
**A:** Storing expected output and comparing — great for serialisation/AI outputs where you freeze known-good behaviour.
