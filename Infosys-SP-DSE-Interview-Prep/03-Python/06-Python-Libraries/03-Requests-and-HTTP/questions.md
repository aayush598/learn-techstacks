# Python Libraries — Requests And Http Interview Questions and Answers

## Q1: What is the requests library?
**A:** The de-facto HTTP client for Python — params, headers, JSON bodies, sessions, and timeouts wrapped in a clean API.

## Q2: How do you make a GET request with parameters?
**A:** requests.get(url, params={'q': 'x'}) — params auto-encodes into the query string; headers= sets auth/accept.

## Q3: How do you handle a POST with JSON?
**A:** requests.post(url, json={'key': 'value'}) — json= serialises, sets Content-Type: application/json; data= sends form-encoded.

## Q4: What is the difference between response.text, .json(), and .content?
**A:** .text decodes str; .json() parses JSON (raises on invalid); .content is raw bytes — choose based on the payload format.

## Q5: What is check_for_status?
**A:** resp.raise_for_status() raises HTTPError for 4xx/5xx — forcing explicit error handling instead of silent partial data.

## Q6: What is a requests.Session and why reuse it?
**A:** Session persists cookies and TCP connections across calls — performance and state (login tokens) for multi-request flows.

## Q7: How do you set timeouts and what are their layers?
**A:** timeout=(connect_timeout, read_timeout) — without it, requests can hang forever; the interview answer for 'why did my script stall'.

## Q8: How do you send a file or multipart upload?
**A:** requests.post(url, files={'file': ('x.csv', open('x.csv','rb'))}) — multipart/form-data for typical upload APIs.

## Q9: What is a Basic-auth and Bearer-token header?
**A:** requests.get(url, auth=('user','pass')) builds Basic; headers={'Authorization': f'Bearer {token}'} for JWT — the API protocol companions.

## Q10: How do you retry requests robustly?
**A:** urllib3 Retry with backoff_factor and status_forcelist — the resilient-client pattern (used under LangChain/Agno HTTP tools too).

## Q11: How do you handle JSON errors in a response?
**A:** Checks status then resp.json(); wrap in try/except for spec drift — graceful degradation whenever a third-party API changes shape.
