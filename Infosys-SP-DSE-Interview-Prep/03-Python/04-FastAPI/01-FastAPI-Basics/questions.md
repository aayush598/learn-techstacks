# Fastapi — Fastapi Basics Interview Questions and Answers

## Q1: What is FastAPI and why is it popular?
**A:** A modern Python web framework built on Starlette + Pydantic; async support, automatic OpenAPI docs, type-driven validation, high performance, and minimal boilerplate.

## Q2: How does FastAPI handle request validation?
**A:** Pydantic models (type-annotated) validate the request body; Query/Path/Header/Body parameters type-validate inputs — 400s returned automatically on mismatch.

## Q3: What is the difference between a query and a path parameter?
**A:** Path parameters are part of the URL (/users/{id}); query params follow ?key=value. FastAPI maps both via the function signature.

## Q4: How do you define a GET vs POST endpoint?
**A:** @app.get('/items') vs @app.post('/items') with a Pydantic body model; method decorators map HTTP verbs to handlers cleanly.

## Q5: What is the automatic OpenAPI/swagger documentation?
**A:** FastAPI generates /docs (Swagger UI) and /redoc from type annotations — interactive API docs without configuration.

## Q6: What is the difference between sync and async endpoints?
**A:** def endpoints run in a threadpool; async def run on the event loop — use async for I/O-bound work, sync for CPU-bound/blocking libs.

## Q7: What is the FastAPI dependency injection system?
**A:** Depends() resolves function dependencies per request — shared DB sessions, auth checks, and pagination params with automatic cleanup.

## Q8: What is the app factory / lifespan pattern?
**A:** lifespan context manager (FastAPI 0.93+) wires startup/shutdown — opening DB pools or model caches once at app boot.

## Q9: How do you run FastAPI?
**A:** uvicorn app.main:app --reload — the ASGI server; options --host 0.0.0.0 --port 8000; gunicorn with uvicorn workers in production.

## Q10: How does FastAPI compare to Flask?
**A:** FastAPI: async, auto-docs, Pydantic validation, performance. Flask: synchronous, minimal, WSGI, mature ecosystem. Choose FastAPI for new APIs, Flask for simplicity/legacy.
