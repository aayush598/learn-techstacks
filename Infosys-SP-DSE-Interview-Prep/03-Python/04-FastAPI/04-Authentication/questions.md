1. **What are the common auth flows for a FastAPI API?**
   - OAuth2 + JWT bearer tokens; session cookies for browser apps; API keys for machine clients — choose by client type and revocation needs.

2. **How do you implement JWT auth in FastAPI?**
   - python-jose/pyjwt to sign {sub, exp, scopes}; an OAuth2PasswordBearer dependency decodes and validates the token for protected routes.

3. **What is the AuthUser dependency pattern?**
   - def get_current_user(creds=Depends(oauth2_scheme)): validate JWT then load the user — injected into every protected endpoint.

4. **How do you store passwords safely?**
   - bcrypt/passlib hash + salt; never plaintext. Compare with bcrypt.checkpw; cost factor tuned for security vs latency.

5. **What is OAuth2 and the password flow?**
   - Client trades credentials for a token via the /token endpoint; scopes limit what the token may do — the standard for third-party access.

6. **What is the difference between an access token and a refresh token?**
   - Access: short-lived JWT on each request. Refresh: long-lived secret exchanged for new access tokens when they expire — enhancing revocation.

7. **What are scopes and role-based access?**
   - JWT 'scope' claims map to permissions; dependencies check scopes/roles before serving — RBAC at the endpoint level.

8. **How do you protect against token theft?**
   - HTTPS only, short access-token lifetimes, secure HttpOnly cookies, refresh-token rotation, and rate limiting on /token.

9. **What is the difference between Basic, Bearer, and API-key auth?**
   - Basic: username:password base64 (TLS-required). Bearer: a token in Authorization header — JWT flows. API key: static per-client — simple machine access.

10. **What is CORS and CSRF interplay with auth?**
   - CORS limits which origins may call the API; cookie-based auth needs CSRF tokens; bearer tokens are origin-agnostic — trade-offs per auth style.
