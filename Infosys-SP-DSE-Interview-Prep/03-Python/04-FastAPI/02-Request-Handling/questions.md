# Fastapi — Request Handling Interview Questions and Answers

## Q1: How do you read query parameters in FastAPI?
**A:** Annotate plain args: def search(q: str, limit: int = 10) — validated and auto-documented; Query(...) adds constraints (min_length, regex).

## Q2: How do you read path parameters?
**A:** def get_item(item_id: int) — path matching with type coercion; a bad int returns 422 automatically.

## Q3: How do you read a JSON request body?
**A:** A Pydantic model param: def create(item: Item) — FastAPI parses and validates into the model; nest models for complex payloads.

## Q4: How do you send a file upload?
**A:** UploadFile or bytes param with Python-multipart installed; Python's file object streams to disk without loading everything in memory.

## Q5: How do you return custom status codes and headers?
**A:** Return Response(status_code=201) or use the response_model and status_code decorator args; JSONResponse/PlainTextResponse give low-level control.

## Q6: What is response_model and why does it matter?
**A:** It filters/validates the OUTGOING payload — hiding sensitive fields and guaranteeing the API contract; also documents OpenAPI responses.

## Q7: How do you handle errors/404s?
**A:** HTTPException(status_code=404, detail='...') raises the response; custom exception handlers via @app.exception_handler(MyError).

## Q8: How do you handle CORS?
**A:** CORSMiddleware with allow_origins/allow_methods/allow_headers — configure per environment; critical for web frontends calling the API.

## Q9: What is a middleware and how do you add one?
**A:** Code running before routing for every request (logging, auth, timing); use @app.middleware('http') or BaseHTTPMiddleware class.

## Q10: How do you do request logging?
**A:** A middleware logs method, path, status, and duration with the logging module — observability without touching each endpoint.
