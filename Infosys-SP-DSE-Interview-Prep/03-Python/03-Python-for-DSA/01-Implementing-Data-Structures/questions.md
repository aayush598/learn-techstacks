# Python For Dsa — Implementing Data Structures Interview Questions and Answers

## Q1: Which built-in containers map to classic data structures?
**A:** list = dynamic array; tuple = persistent array; dict/set = hash table; deque = queue/deque; heapq = binary heap; str = char sequence — all ready in stdlib.

## Q2: How do you implement a stack in Python?
**A:** A list with append()/pop() gives O(1) LIFO; or collections.deque for thread-safety. The stack interview primitive.

## Q3: How do you implement a queue in Python?
**A:** collections.deque with append()/popleft() (O(1) both ends); queue.Queue is a thread-safe blocking wrapper. A single list head is O(n) — avoid.

## Q4: How do you implement a min-heap?
**A:** import heapq; heapq.heappush(h, x); heapq.heappop(h) — Python's heapq IS a min-heap binary tree in a list; use -values for max-heap behaviour.

## Q5: How do you implement a binary-search tree (BST)?
**A:** A Node class with left/right and insert/search/delete traversals; Python's recursion rebuilds nodes (3.12) or iterative pointer walking avoids recursion limits.

## Q6: How do you implement a linked list in Python?
**A:** class Node: __init__(self, val, next=None); maintain head reference with iterative loops and dummy-node sentinel for edge cases.

## Q7: How do you implement a hash table from scratch?
**A:** Array of buckets + hash() of keys + separate chaining or open addressing; Python's dict does this natively but interviews test the theory.

## Q8: How do you implement a graph adjacency list?
**A:** dict: node -> list/set of neighbours (or dict of weights); 30 lines take you through BFS/DFS/Dijkstra — the foundational interview representation.

## Q9: What is a Trie and how to implement it?
**A:** A tree of characters; children dict per node with an end-of-word flag — prefix queries in O(len) using sum/any/all and set of `words` termination.

## Q10: How do you implement LRU cache in Python?
**A:** collections.OrderedDict move_to_end/popitem(last=False), or linked list + dict manually — the classic system-design-on-whiteboard pair.

## Q11: How do you implement a disjoint-set (Union-Find)?
**A:** parent array + rank/size, find with path compression, union by size — near O(alpha(n)) inverse Ackermann for connectivity problems.

## Q12: How do you implement a segment tree?
**A:** A 4n array tree of range aggregates; build, point update, range query — O(log n); iterative version avoids recursion.
