## Q1: What is the fast input/output idiom in competitive Python?
**A:** import sys; data = sys.stdin.buffer.read().split(); iterate tokens — dramatically faster than input() for large competitive datasets.

## Q2: How do you do a 2 sum with a dictionary?
**A:** seen = {}; for i,x in enumerate(nums): if target-x in seen: return [seen[target-x], i]; seen[x] = i — O(n) one-pass.

## Q3: What is the Counter-based group count for anagram grouping?
**A:** sorted(item) or tuple(sorted(item)) as the group key groups anagrams in O(n * k log k); Counter keys enable O(nk).

## Q4: How do you reverse a list/string/subarray?
**A:** nums.reverse() or nums[::-1]; two-pointer swap for in-place subarray reversal — the O(n)/O(1) idiom.

## Q5: How do you zip and transpose a matrix?
**A:** list(zip(*matrix)) transposes a rectangular grid; for (r,c) loops still matter for in-place matrix problems.

## Q6: What is the heap-based top-k idiom?
**A:** heapq.nlargest(k, iterable) / nsmallest; or push k then replace for streaming — the one-liner for Top-K questions.

## Q7: How do you handle big integers in Python DSA?
**A:** Python ints are arbitrary precision so no overflow — but that means you can be tempted into constant-time-complexity cheating; clarify time bounds with the interviewer.

## Q8: What is the bitwise fast exponentiation?
**A:** pow(base, exp, mod) is O(log exp); or manual loops shifting the exponent — modular arithmetic for count-ways problems.

## Q9: What is the trick for sorting by a complex key?
**A:** sorted(items, key=lambda x: (-x[1], x[0])) sorts by frequency desc then name asc — two-field orderings in one key tuple.

## Q10: How do you avoid O(n^2) string concatenation in loops?
**A:** Collect parts in a list then ''.join(parts) — concatenating in a loop is quadratic; join is a single linear pass.

## Q11: What is the in-place swapping trick?
**A:** arr[i], arr[j] = arr[j], arr[i] — Python's tuple-assignment swap; the bread-and-butter for partition/pointer algorithms.

## Q12: How do you convert between int and string bases?
**A:** int(s, 16), hex(255), format(n, 'b') for binary — quick numeral-system conversions for interview problems.
