1. **What is template inheritance?**
   - A base.html with {% block content %} regions; child templates {% extends 'base.html' %} and override blocks — DRY page layout.

2. **What is the Jinja2 variable escaping?**
   - {{ user.name }} auto-escapes HTML by default to prevent XSS; use |safe only for trusted content — the security-critical detail.

3. **How do you loop and branch in templates?**
   - {% for item in items %} ... {% endfor %} and {% if cond %}: template control flow mirroring Python minus the colons.

4. **How do you pass context to templates?**
   - render_template('x.html', name=name) exposes variables; global template utils (config, url_for) are always available.

5. **What are template filters?**
   - |lower, |date('%Y-%m-%d'), |default('n/a') post-process values in the template — keep formatting in the view layer.

6. **What is a macro in Jinja2?**
   - {% macro input(name) %} reusable template fragments with parameters — rendering components without a JS framework.

7. **How do you avoid duplicate HTML with partials?**
   - {% include '_item.html' %} reuses a snippet; macros parametrise it further — componentising server-rendered pages.

8. **What is the difference between {{ }} and {% %}?**
   - {{ expression }} prints a value; {% statement %} executes logic (if/for/extends/block) — the two Jinja syntactic classes.

9. **How does template rendering relate to XSS?**
   - Auto-escaping neutralises injected <script>; the |safe escape hatch reopens it — never mark user input safe.

10. **How do you internationalise templates?**
   - Jinja2 i18n extensions with gettext-style translations and locale selection — not every app needs it, but the pattern exists.
