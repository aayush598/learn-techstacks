# Python Advanced — Memory Management Interview Questions and Answers

## Q1: How does Python manage memory?
**A:** Reference counting for immediate deallocation plus a generational garbage collector for reference cycles; CPython uses per-size-class arenas (pymalloc).

## Q2: What is reference counting?
**A:** Each object tracks how many references point to it; at zero the object is freed immediately — the primary CPython reclamation mechanism.

## Q3: What is the cyclic reference problem?
**A:** Two objects referencing each other never hit zero refcount; the generational GC detects such cycles and collects them — IDs/frames are notable cycle sources.

## Q4: What is the generational GC?
**A:** Objects are tracked in 0/1/2 generation buckets; young objects are scanned more often — tuning thresholds trades pause time vs reclaimed garbage.

## Q5: What is the difference between del and the GC?
**A:** del just removes a name (decrementing refcount); the GC only matters for cycles — resource classes often need __del__ to complement.

## Q6: What is weakref and when use it?
**A:** weakref.ref(obj) observes an object without keeping it alive, turning None once collected — for caches/observers that shouldn't leak.

## Q7: What is memory profiling?
**A:** tracemalloc and objgraph quantify per-line allocations and object growth — used to find leaks and large temporaries.

## Q8: What does sys.getrefcount(x) show?
**A:** The current reference count (including the temporary from the argument pass) — a debugging peek at an object's popularity.

## Q9: What is the id() and the difference between object identity and equality?
**A:** id(obj) is the CPython address (unique while alive); two equal values ('a' and 'a') may share one interned object — but that's implementation detail, not guaranteed.

## Q10: How do you reduce memory for large datasets?
**A:** __slots__, generators, array module, NumPy for typed arrays, avoiding list-of-dicts, and streaming processing — the pragmatic performance playbook.
