# Python Advanced — Asyncio Interview Questions and Answers

## Q1: What is asyncio and the event loop?
**A:** A library for concurrent I/O via coroutines: an event loop schedules awaitables, multiplexing blocking waits with selectors — one thread, many tasks.

## Q2: What is a coroutine?
**A:** An async def function that runs until an await, suspending the task; awaited via await or scheduled with asyncio.create_task.

## Q3: What is the difference between async def and a normal function?
**A:** Calling an async def returns a coroutine object (nothing runs) until awaited; a normal function executes immediately — the fundamental async distinction.

## Q4: What is await and blocking calls inside coroutines?
**A:** await yields control to the loop; blocking (time.sleep, requests.get) inside a coroutine stalls all tasks — always use async.sleep/async HTTP clients (httpx/aiohttp).

## Q5: What is asyncio.gather?
**A:** Runs multiple awaitables concurrently awaiting all results: asyncio.gather(*tasks, return_exceptions=True) — the default parallel fan-out pattern.

## Q6: What is asyncio.create_task vs awaiting directly?
**A:** create_task schedules in the background for parallel progress; direct await runs sequentially — create_tasks to fire-and-wait multiple I/Os at once.

## Q7: What is an async generator (async for)?
**A:** async def __aiter__ using await and yield per item — streaming from a database cursor or websocket without blocking the loop.

## Q8: What is asyncio.run?
**A:** asyncio.run(main()) creates a new loop, runs the coroutine, and closes it — the entry point replacing manual loop handling in scripts.

## Q9: What is to_thread?
**A:** asyncio.to_thread(fn, ...) runs the blocking function in a worker thread freeing the loop — bridging sync libraries into async code simply.

## Q10: How does async compare with threading in Python?
**A:** async: cooperative, one thread, huge fan-out for I/O; threading: preemptive, GIL-bound; async avoids thread-safety and overhead but requires async libraries throughout.
