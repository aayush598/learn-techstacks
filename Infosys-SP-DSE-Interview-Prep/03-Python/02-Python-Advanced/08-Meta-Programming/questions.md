# Python Advanced — Meta Programming Interview Questions and Answers

## Q1: What is meta-programming in Python?
**A:** Code that generates/manipulates code at runtime: decorators, descriptors, __getattr__, metaclasses, __new__/__init_subclass__, inspect, eval/exec.

## Q2: What is a metaclass?
**A:** The class of a class — type by default; a metaclass controls class creation/extraction (before __init__ of the class object). Used for registering subclasses, enforcing interfaces.

## Q3: How does type() create a class dynamically?
**A:** Klass = type('Klass', (Base,), {'attr': 1, 'method': fn}) — building classes at runtime without class statements.

## Q4: What is __getattr__ vs __getattribute__?
**A:** __getattr__ is called only when normal lookup fails (missing attrs); __getattribute__ intercepts ALL attribute access — implement proxies/Mock-style objects.

## Q5: What is a descriptor?
**A:** An object with __get__/__set__/__delete__ controlling attribute access; property/classmethod/staticmethod are descriptors — the mechanism behind properties.

## Q6: What is class-level registration pattern?
**A:** A metaclass or __init_subclass__ auto-registers every subclass in a registry — used in plugin frameworks and DB ORMs (declarative models).

## Q7: What is inspect module used for?
**A:** Introspecting signatures, source code, class hierarchies, and stack frames — powering debuggins, frameworks, and CLI tools.

## Q8: What is __new__ used for in classes beyond allocation?
**A:** In metaclasses/immutables, __new__ runs before __init__, enabling cache-keyed singletons, singleton enforcing, and subclass filtering.

## Q9: What is the difference between class methods and metaprogramming by decorators?
**A:** Decorators manipulate callables; metaclasses manipulate classes themselves — choose decorators for functions, metaclasses when you control class construction.

## Q10: What is dataclasses and how is it meta-programmed?
**A:** @dataclass auto-generates __init__, __repr__, __eq__ from annotations — a pragmatic everyday example of code generation without metaclass verbosity.
