# Operating Systems — Process Management Interview Questions and Answers

## Q1: What is a process?
**A:** A program in execution: code, data, heap, stack, registers, and state. Each process gets its own isolated address space; the OS schedules it, allocates resources, and switches between them.

## Q2: What is the difference between a process and a thread?
**A:** Process: independent memory space, heavier to create/switch, isolated. Thread: lightweight unit within a process, shares the process's memory, cheaper context switch, prone to races.

## Q3: What are the process states?
**A:** new → ready → running ↔ waiting/blocked → terminated (plus suspended/stopped variants). The diagram question — state transitions and what causes them.

## Q4: What is a process control block (PCB)?
**A:** The kernel's record per process: PID, state, program counter, registers, memory info, open files, scheduler priority — everything needed to suspend and resume a process.

## Q5: What is context switching?
**A:** Saving one process's state (into its PCB) and loading another's — the overhead of multitasking; frequent switches hurt throughput and cache locality.

## Q6: What is the difference between preemptive and non-preemptive scheduling?
**A:** Preemptive: the scheduler can interrupt a running process (time quantum). Non-preemptive: the process runs until it blocks or finishes. Real-time systems care deeply.

## Q7: What is a zombie process?
**A:** A child that has exited but whose parent hasn't yet called wait() — its PCB lingers to let the parent read the exit status. Parent must reap or the OS eventually orphans/reaps.

## Q8: What is an orphan process?
**A:** A running process whose parent has exited first; it gets reparented to init (PID 1) in Unix, which reaps it when it finishes.

## Q9: What is fork()?
**A:** The Unix system call that clones the current process (COW memory); children get a copy of memory, PID differs, and fork() returns 0 to the child and the child's PID to the parent.

## Q10: What are the components of a process address space in memory?
**A:** Text (code), data (initialised/static), heap (grows upward via malloc), stack (grows downward for calls). Layout questions define memory-management depth.
