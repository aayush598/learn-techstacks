# Computer Networks — Security Interview Questions and Answers

## Q1: What are the CIA triad properties?
**A:** Confidentiality (no unauth access), Integrity (no unauth modification), Availability (stays up) — the foundational security objectives every design must weigh.

## Q2: What are the common types of attacks?
**A:** DDoS, SQL injection, XSS, CSRF, MITM, phishing, brute force, and social engineering — know the mechanism and the mitigation for each.

## Q3: What is a firewall and its types?
**A:** A device filtering traffic by rules; packet-filter (layer 3/4) and stateful (tracks connections). Next-gen adds app-layer inspection.

## Q4: How do you protect an API?
**A:** Authentication (OAuth2/JWT), rate limiting, input validation, least-privilege scopes, TLS, CORS lockdown, and logging/monitoring — the exact controls you built into FastAPI.

## Q5: What is symmetric vs asymmetric encryption?
**A:** Symmetric: one shared key (AES) — fast. Asymmetric: key pairs (RSA/ECC), slower — used for key exchange/digital signatures; TLS uses both in a hybrid.

## Q6: What is a hash vs encryption?
**A:** Hash: one-way, fixed-length, deterministic (SHA-256) for integrity/storing passwords. Encryption: reversible with a key for confidentiality. They are not interchangeable.

## Q7: What is a Man-in-the-Middle (MITM) attack and its mitigation?
**A:** Attacker impersonates both ends, intercepting/modifying messages. Mitigations: TLS with certificate validation, pinned certs, mutual TLS.

## Q8: What is SQL injection and how do you prevent it?
**A:** Attacker injects SQL via input to manipulate queries. Prevention: parameterised queries/bind placeholders, ORMs, input validation, least-privilege DB users.

## Q9: What is XSS and its types?
**A:** Injecting client-side scripts to steal data; stored/persistent, reflected, DOM-based. Prevention: escaping output, CSP headers, sanitising input.

## Q10: What is a CSRF attack and its mitigation?
**A:** Forcing a logged-in user to perform unintended requests; mitigation: CSRF tokens, SameSite cookies, double-submit cookies.

## Q11: What is a DDoS attack?
**A:** Overwhelming a service with traffic (volumetric/application-layer) to make it unavailable (breaks availability). Mitigation: load balancing, rate limiting, CDN/WAF, mitigation services.

## Q12: What is defence in depth?
**A:** Layering independent controls (network, app, data, monitoring) so failure of one doesn't expose the system — the overall security architecture principle.
