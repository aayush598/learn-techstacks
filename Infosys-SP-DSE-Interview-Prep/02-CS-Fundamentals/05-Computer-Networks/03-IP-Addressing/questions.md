# Computer Networks — Ip Addressing Interview Questions and Answers

## Q1: What is an IP address and its classes?
**A:** IPv4 is 32-bit dotted decimal (192.168.1.1); classes A (1-126), B (128-191), C (192-223) with fixed /8,/16,/24 defaults — though CIDR superseded classes in practice.

## Q2: What is a subnet mask?
**A:** A 32-bit mask separating network bits (1s) from host bits (0s) — e.g., /24 = 255.255.255.0; it defines how large a network is and which hosts share a broadcast domain.

## Q3: What is CIDR notation?
**A:** Classless Inter-Domain Routing (e.g., 10.0.0.0/24) — prefix length replacing classful routing for efficient address allocation.

## Q4: What is the difference between a public and private IP?
**A:** Public: globally routable. Private ranges (10.x, 172.16-31.x, 192.168.x) are for internal LANs, mapped to public via NAT.

## Q5: What is NAT?
**A:** Network Address Translation maps private IPs to one public IP for internet access — also applies port-mapping for inbound services. IPv4 exhaustion's main mitigator.

## Q6: What is localhost / 127.0.0.1 and 0.0.0.0?
**A:** 127.0.0.1 is the loopback to the local machine; 0.0.0.0 means 'bind on all interfaces' — the uvicorn --host choices in FastAPI.

## Q7: What is IPv6 and why do we need it?
**A:** 128-bit addressing (fe80::/10 link-local etc.) solving IPv4 exhaustion, with auto-configured addresses; adoption driven by growth of connected devices.

## Q8: How does a DNS query work?
**A:** Browser → resolver → root → TLD → authoritative server chain returning the A/AAAA record; cached at each level. The mapping of names to IPs underpins everything.

## Q9: What is DNS caching and TTL?
**A:** Queries cached locally/resolver-side for the record's TTL (time-to-live) — reducing latency and load; mis-set TTLs cause propagation delays.

## Q10: What are the common record types?
**A:** A (IPv4), AAAA (IPv6), CNAME (alias), MX (mail server), TXT (verification/SPF), NS (authoritative nameservers) — the DNS record roster.
