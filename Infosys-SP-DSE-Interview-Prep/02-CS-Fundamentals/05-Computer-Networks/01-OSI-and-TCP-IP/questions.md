# Computer Networks — Osi And Tcp Ip Interview Questions and Answers

## Q1: List the 7 OSI layers and their function.
**A:** Physical (bits/wiring), Data Link (frames/MAC), Network (IP routing), Transport (TCP/UDP ports/segments), Session (dialog orchestration), Presentation (encoding), Application (HTTP/SMTP) — memorise top-to-bottom for the roster question.

## Q2: How do the layers compare to the TCP/IP model?
**A:** TCP/IP merges: Application (7-5), Transport (4), Internet (3), Network Access (1-2). The 4-layer model is the practical derangement most interviews use.

## Q3: What is encapsulation in networking?
**A:** Each layer wraps the upper payload with its own header: data → TCP header → IP header → Ethernet frame — the onion model; empty middle term is where your packet lives.

## Q4: What is a MAC address and how does it differ from an IP address?
**A:** MAC: 48-bit hardware address on the NIC, layer-2, usually burned in. IP: 32/128-bit logical address, layer-3, assigned — the router uses IP, the switch uses MAC.

## Q5: What is the difference between a hub, switch, and router?
**A:** Hub: broadcasts at layer 1. Switch: forwards frames by MAC at layer 2, isolates collisions. Router: forwards packets by IP across networks at layer 3.

## Q6: What is ARP?
**A:** Address Resolution Protocol maps an IP to a MAC on a LAN — the cache stores IP↔MAC mappings; ARP poisoning is a known attack.

## Q7: What is the purpose of the Transport layer?
**A:** End-to-end delivery: segmentation, port numbers, reliability (TCP) or best-effort (UDP), flow/congestion control — layer 4 is TCP/UDP territory.

## Q8: What is the Network layer responsible for?
**A:** Logical addressing and routing: IP packets, subnetting, routing protocols (OSPF/BGP), and fragmentation between MTUs.

## Q9: What happens when you type a URL and hit Enter?
**A:** DNS resolution → TCP handshake → TLS handshake → HTTP request → server processing → HTTP response → rendering. The full-stack answer spanning every layer.

## Q10: Why do we model networks in layers at all?
**A:** Modularity: each layer has a defined interface, can change independently, and is testable in isolation — the engineering argument interviewers probe.
