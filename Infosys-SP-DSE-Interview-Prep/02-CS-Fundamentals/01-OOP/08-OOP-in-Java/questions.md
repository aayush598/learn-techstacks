# Oop — Oop In Java Interview Questions and Answers

## Q1: What are the four pillars of OOP and how does Java enforce each?
**A:** Encapsulation (private + getters), Inheritance (extends/implements), Polymorphism (overriding/interfaces), Abstraction (abstract classes/interfaces) — Java enforces via keywords and type system.

## Q2: What is the difference between an interface and an abstract class in Java?
**A:** Abstract class: may hold state, constructors, some implemented methods, single inheritance. Interface: contract of abstract methods (default/static allowed), multiple can be implemented. Java 8+ allows default methods in interfaces.

## Q3: What is a HashMap vs a TreeMap in Java?
**A:** HashMap: O(1) average get/put, unordered, allows one null key. TreeMap: O(log n) navigation, sorted by key via Comparable/Comparator — the exact Infosys Hashmap vs Treemap question.

## Q4: What is a ConcurrentHashMap?
**A:** Thread-safe hash map with finer-grained locking (CAS + segments) — safe for concurrent reads/writes without external synchronisation; never allows null keys/values.

## Q5: Explain ArrayList vs LinkedList vs Vector.
**A:** ArrayList: dynamic array, O(1) index access, O(n) middle insertion. LinkedList: doubly-linked, O(1) ends. Vector: array like ArrayList but synchronized (legacy, slow).

## Q6: What are access modifiers in Java?
**A:** private (same class), default/package-private, protected (package + subclasses), public (anywhere) — the toolkit for Java encapsulation enforcement.

## Q7: What is the `final` keyword?
**A:** final class (no subclass), final method (no override), final variable (cannot be reassigned) — Java's immutability/constancy marker.

## Q8: What is runtime polymorphism in Java?
**A:** When the actual object type (not the static reference type) selects the method at runtime; classic: Animal a = new Dog(); a.makeSound() runs Dog's version — late binding.

## Q9: What are Java generics and their use?
**A:** Type parameters at compile time (List<String>) providing type safety without runtime cost; erased at runtime (type erasure) to Object.

## Q10: What is a Java exception hierarchy?
**A:** Throwable → Exception (checked/unchecked) and Error. Checked exceptions must be handled or declared; unchecked (RuntimeException) thread logic bugs — understanding helps designing robust services.
