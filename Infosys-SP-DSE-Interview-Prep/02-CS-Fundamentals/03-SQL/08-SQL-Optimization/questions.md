1. **List the common causes of slow queries.**
   - Missing/inefficient indexes, table scans on large tables, SELECT *, heavy joins without stats, functions on indexed columns, the N+1 pattern, and lock contention.

2. **How do you improve a slow SELECT?**
   - Add covering/sargable indexes, rewrite predicates to use them, avoid functions on columns (WHERE sal*2 vs WHERE sal), reduce columns returned, and check the query plan.

3. **What is sargability?**
   - A predicate is sargable when the indexed column stands alone (col = ?, col >= ?); wrapping it (YEAR(col) = 2024 or col+1 = x) disables the index — a favourite optimisation answer.

4. **What is an index's role in ORDER BY?**
   - An index matching the ORDER BY columns lets the planner return rows already sorted — avoiding a sort phase; covering indexes make it even cheaper.

5. **What is a query cache as opposed to an index?**
   - Database/main tools caching result sets or query plans, bypassing reprocessing — differs from indexes (storage structures speeding reads). Only prudent when staleness is acceptable.

6. **How does SELECT * hurt performance?**
   - Brings unneeded columns → wider scans, more I/O, breaks covering indexes, and hard-codes schema — always select only needed columns.

7. **How do you reduce JOIN cost?**
   - Index the join keys (FKs), filter early with WHERE, keep the join order from small to large, and use exists that prevents oversized intermediate results.

8. **What is the effect of a high page miss on prepares?**
   - Repeated identical queries benefit from prepared statements/plan caching — the DB skips planning; for dynamic predicates re-plans keep stats current.

9. **When is a full table scan acceptable?**
   - Small tables, or predicates matching most rows (a full scan beats an index whose selectivity is low) — the planner decides; forcing with hints is an anti-pattern.

10. **How do you test the improvement?**
   - EXPLAIN ANALYZE before/after with the same parameters and dataset — compare actual time and rows; verify the index is used and not just created.
