# Sql — Advanced Sql Interview Questions and Answers

## Q1: What is a recursive CTE?
**A:** WITH RECURSIVE cte AS (base UNION ALL recursive-step) — builds trees, hierarchies, and series in SQL. The classic example: employees up the reporting chain.

## Q2: Write a recursive CTE for a number series.
**A:** WITH RECURSIVE t(n) AS (VALUES (1) UNION ALL SELECT n+1 FROM t WHERE n < 10) SELECT n FROM t; — materialises 1..10.

## Q3: What is a PIVOT/unpivot?
**A:** Rotating rows into columns (PIVOT) or columns into rows (UNPIVOT); PostgreSQL uses FILTER/conditional aggregation — SELECT ... SUM(CASE WHEN ...) for pivot-in-SQL.

## Q4: What is the difference between GROUPING SETS, CUBE, ROLLUP?
**A:** ROLLUP produces hierarchical subtotals, CUBE all combinations, GROUPING SETS explicit subsets — SQL analytics for totals and subtotals.

## Q5: What is a LATERAL join?
**A:** A correlated FROM-subquery that can reference the join's left side row-by-row: FROM orders o, LATERAL (SELECT ... WHERE ... o.id) x — powerful for per-row computations.

## Q6: What is the MERGE (UPSERT) statement?
**A:** MERGE INTO/INSERT ... ON CONFLICT (col) DO UPDATE inserts or updates deterministically — PostgreSQL's UPSERT pattern avoids race-prone check-then-write.

## Q7: How do you select rows with the latest timestamp per group?
**A:** DISTINCT ON (group) ... ORDER BY group, timestamp DESC (PostgreSQL) or ROW_NUMBER() OVER (PARTITION BY ...): the window version is standard SQL.

## Q8: What is the difference in reading JSONB operators?
**A:** ->> extracts text, -> extracts JSON, @> containment, ? exists — PostgreSQL's JSON operations for semi-structured queries.

## Q9: Write a query to remove duplicate rows keeping one.
**A:** DELETE FROM emp WHERE id NOT IN (SELECT MIN(id) FROM emp GROUP BY name, dept); — keep one per group: the classic dedupe cleanup.

## Q10: What is EXPLAIN ANALYZE and what does it tell you?
**A:** Shows the chosen execution plan with actual rows/time — a sequence scan vs index scan, join method, and filter estimates — the first step to optimisation.
