# Linux — Linux Basics Interview Questions and Answers

## Q1: What is Linux and its architecture?
**A:** An open-source OS with a kernel managing hardware, scheduling, and system calls; user-space tools (GNU coreutils) sit on top — the server OS of choice.

## Q2: What are the most common Linux commands?
**A:** ls, cd, pwd, cp, mv, rm, mkdir, grep, find, chmod, ps, top, ssh — the everyday toolbox everyone must rattle off.

## Q3: What is the difference between absolute and relative paths?
**A:** Absolute: /home/user/file, from root. Relative: ../file, from cwd — the path semantics of navigation.

## Q4: What is the directory structure (/bin, /etc, /var)?
**A:** /bin binaries, /etc config, /var variable logs/data, /home users, /tmp temp, /proc virtual-kernel files — the FHS layout maps.

## Q5: What are file permissions and how do you change them?
**A:** r/w/x per owner/group/other as octal (755); chmod sets them, chown changes ownership — the access-control basics.

## Q6: What is the difference between a hard link and symlink in Linux?
**A:** Hard link: additional name for the same inode. Symlink: a shortcut path (may break). ln file hard, ln -s target sym — reuses the OS concepts.

## Q7: What is stdout, stdin, stderr?
**A:** Standard streams: input (0), output (1), error (2); redirect with >, >>, 2>, and pipe with | — the shell plumbing.

## Q8: What does grep find?
**A:** Text search in files/streams: grep pattern file, -i ignore case, -r recursive — the pattern-matching reviewer.

## Q9: What is the difference between find and grep?
**A:** find locates files by name/type/time; grep searches content of files — two different axes of the filesystem.

## Q10: How do you check disk space, memory, CPU?
**A:** df -h (disks), free -h (RAM), top/htop (live processes), uptime (load) — the health-check command quartet.

## Q11: What is a package manager?
**A:** apt/yum/dnf install, update, and remove software from repos — the dependency management of the OS itself.

## Q12: How do you edit/search history in the shell?
**A:** history, !! (last), ctrl-r reverse search — shell productivity, the fastest editing shortcuts.
