# Git — Merging And Rebasing Interview Questions and Answers

## Q1: What is merging in Git?
**A:** Combining branches by creating a merge commit (or fast-forward) that reconciles the histories — history shows the branch topology.

## Q2: What is a merge conflict and how do you resolve it?
**A:** Both branches changed the same lines — Git marks <<<<<<< / ======= / >>>>>>> blocks; you edit, decide, git add + commit the resolution.

## Q3: What is fast-forward merging?
**A:** When the target branch hasn't moved, merging just moves its pointer forward — linear history without a merge commit; --no-ff forces a record instead.

## Q4: What is rebasing?
**A:** Re-applying one branch's commits on top of another's tip — a clean linear history at the cost of rewritten commit IDs (never rebase shared history).

## Q5: What is the difference between merge and rebase?
**A:** Merge preserves topology with a merge commit (safe for shared branches); rebase flattens into a linear story (clean, but rewrites order/IDs).

## Q6: What is cherry-picking?
**A:** Applying a single commit from elsewhere onto the current branch without bringing the whole history — targeted hotfix transfer.

## Q7: What is git revert vs reset?
**A:** revert creates an inverse commit (safe, keeps history, good for public branches); reset moves HEAD backwards discarding commits (rewrites — private/feature only).

## Q8: What is the golden rule of rebasing?
**A:** Never rebase commits you've pushed/shared — rewriting public history breaks collaborators; revert instead on shared branches.

## Q9: How do you resolve a conflict during a rebase?
**A:** Stop, edit conflicted files, git add, then git rebase --continue — or --abort to bail out; each step re-applies the next commit.

## Q10: What is an interactive rebase used for?
**A:** git rebase -i lets you reorder, squash, fixup, or reword local commits — cleaning a messy feature branch before merge.

## Q11: What is squash merging?
**A:** --squash collapses all feature commits into one on merge — concise history at the cost of loss of the detailed journey.
