# 02 Bfs And Dfs — Graphs

**100 Interview Q&A — Infosys Specialist Programmer (SP) / Digital Specialist Engineer (DSE)**

1. **Explain BFS and its data structure.**
   - Breadth-first search visits level by level using a queue. Starting from a node, it discovers all neighbours, then their neighbours, guaranteeing shortest-path (fewest edges) in unweighted graphs.

2. **What is the time and space complexity of BFS?**
   - O(V+E) time with adjacency lists; O(V) space for the visited set and queue (frontier can be O(V) at one level).

3. **Explain DFS with recursion and stack.**
   - DFS follows one branch as far as possible before backtracking; recursive implementation uses the call stack, or an explicit stack, marking visited on entry. O(V+E).

4. **Distinguish BFS vs DFS use-cases.**
   - BFS: shortest path in unweighted graphs, level-order, connectivity between two nodes at min hops. DFS: cycle detection, topological sort, connected components, path existence, backtracking.

5. **How do you detect a cycle in an undirected graph with DFS?**
   - While DFS from u, if a neighbour v is visited and v != parent[u], a cycle exists. Parent distinction prevents treating the back-edge to origin as a cycle. O(V+E).

6. **How do you detect a cycle in a directed graph?**
   - Use three-colour marking (unvisited/on-stack/done); encountering a grey (currently on recursion stack) node indicates a back-edge → cycle. O(V+E).

7. **How do you count connected components?**
   - Outer loop over vertices; each unvisited start increments the count and its BFS/DFS marks that component. O(V+E).

8. **How do you find the shortest path in an unweighted graph?**
   - BFS from source tracking parent array; distance = level. Reconstruct path by backtracking parents. This is the canonical Infosys 'shortest path BFS' answer.

9. **How do you check if a path exists between two vertices?**
   - Run BFS/DFS from source; true iff the target is visited. If both in same component this is decided by component membership.

10. **What is a bipartite check and how is it done?**
   - A graph is bipartite if its vertices can be coloured 2-colour so that edges always join different colours. BFS colouring: neighbours must be the opposite colour or the answer is False. O(V+E).

11. **What is 0-1 BFS and when is it used?**
   - Edge weights in {0,1}; use a deque pushing 0-weights to the front and 1-weights to the back, achieving O(V+E) shortest paths instead of Dijkstra's O(E log V).

12. **What is topological ordering?**
   - A linear ordering of a DAG where every edge u→v has u before v. Kahn's algorithm (indegree-0 queue) or DFS finishing-time reversal produce it in O(V+E).

13. **How does Kahn's algorithm detect a DAG?**
   - Process indegree-0 nodes; decrement neighbours; if processed < V nodes, a cycle exists (remainder have nonzero indegree). O(V+E).

14. **How do you find the number of islands (grid BFS/DFS)?**
   - Scan cells; on encountering an unvisited '1', increment count and flood-fill (BFS/DFS) over adjacent land marking visited. O(rows×cols). This was literally asked in SP/DSE.

15. **What are flood-fill variations used for?**
   - Image fill, islands, largest island, regions bounded by water, and matrix-connectivity problems — all apply BFS/DFS over 4-direction neighbours.

16. **How do you get all paths from source to target?**
   - DFS tracking current path and visited; when target reached, copy path. Reuse of vertices is forbidden inside a single path unless revisits allowed. Exponential worst case.

17. **What is multi-source BFS?**
   - Seed the queue with all sources at distance 0 (e.g., all rotten oranges); the first BFS wave assigns minimal distance from ANY source — classic 'rotting oranges'.

18. **How do you find the shortest transformation (word ladder)?**
   - BFS over word states; neighbours are words differing by one letter. Precompute wildcard patterns or neighbours to keep transitions cheap. BFS gives hops.

19. **What is the 'min steps to eat all cheese / nearest 0' style?**
   - Multi-source BFS computes distance from all targets simultaneously; the cellular-automaton trick gives distances to nearest target in O(V+E).

20. **How do you detect if BFS results are level order for trees vs graphs?**
   - In graphs, BFS level = shortest edge-hops only if unweighted; in weighted graphs you must use Dijkstra or 0-1 BFS — not plain BFS.

21. **What is the intuition behind the 02 bfs and dfs technique used in coding interviews?**
   - The core idea is to avoid brute force by exploiting structure: leftover wasted compares are removed, and each element is processed a small constant number of times, driving complexity down to an optimal bound that interviewers expect you to justify.

22. **Write the brute-force approach for a typical 02 bfs and dfs problem and analyse it.**
   - Brute force enumerates every candidate configuration, e.g., every subarray/combination/permutation, giving O(n^2), O(n^3) or O(2^n). It is correct but only useful for small inputs; the interview follow-up is to optimise it to linear or O(n log n).

23. **State the time and space complexity of the optimal solution for most 02 bfs and dfs problems.**
   - The optimal solution is usually O(n) time with O(n) space, or O(n) time with O(1) space when a monotonic/pointer trick applies. Always state constants and best/worst cases explicitly.

24. **What common edge cases must be handled in 02 bfs and dfs implementations?**
   - Empty input, single-element input, all-equal values, negative numbers, duplicates, off-by-one at the last index, and large values where intermediate sums/products can overflow — every one must be tested.

25. **How would you dry-run your 02 bfs and dfs code on a small example in an interview?**
   - Pick a tiny input, walk index by index while updating each variable, and show the invariants hold at every step. This proves both correctness and that you truly understand the algorithm, which Infosys interviewers probe by asking you to trace code by hand.

26. **Give a real-world analogy for 02 bfs and dfs.**
   - Analogy: 02 bfs and dfs is like scanning a line of people for a specific property while remembering a few key facts — each person is visited once and relevant state is carried forward, exactly how the optimal solution behaves.

27. **How do you decide between a hash map, sorting, or two pointers as tools for 02 bfs and dfs?**
   - Hash map when you need membership/paired lookup in O(1) and space is affordable; sorting when order gives a monotonic advantage (two pointers, binary search); pointers directly when the input is already sorted. Trade space for speed only when constraints allow.

28. **What is the role of a prefix/suffix precomputation in 02 bfs and dfs?**
   - Precomputation turns repeated subcomputations into O(1) lookups, converting an O(n^2) nested loop into O(n). Common wherever the value at index i depends on an aggregate over a range around i.

29. **Explain the optimisation step you would mention after writing the naive version for 02 bfs and dfs.**
   - First remove redundant recomputation via memoisation or prefix arrays; next, exploit monotonicity with two pointers/sliding window; finally, reduce space by keeping running variables instead of full tables — always closing with the improved complexity.
