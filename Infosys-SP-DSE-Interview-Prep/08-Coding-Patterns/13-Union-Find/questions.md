1. **What is Union-Find (disjoint set)?**
   - A data structure tracking partition membership with near-O(1) amortised find/union — the workhorse for connectivity and dynamic-grouping problems.

2. **What are the core operations?**
   - find(x) returns the root/representative; union(a,b) merges two sets; often also connected(a,b) = find(a) == find(b) — maintained in O(alpha(n)) amortised.

3. **What are path compression and union by rank/size?**
   - Path compression flattens nodes to their root during find; union by size/rank attaches the smaller tree to the larger — together they give the inverse-Ackermann bound.

4. **Why is the union-find so fast?**
   - Both heuristics make trees nearly flat—so find is essentially O(1)—and the amortised bound is O(alpha(n)), effectively constant for all practical inputs.

5. **What are the classic applications?**
   - Graph connectivity (is there a path?), number of connected components, detecting cycles in Kruskal's MST, and dynamic equivalence queries — the standard roster.

6. **How does union-find detect cycles in undirected graphs (Kruskal)?**
   - Before adding an edge, if find(u) == find(v) the edge creates a cycle — skip it; otherwise union. That single check powers Kruskal's MST algorithm.

7. **What is the difference between union-find and BFS/DFS for connectivity?**
   - Union-find supports dynamic connections and incremental queries without re-traversal; BFS/DFS gives an O(V+E) one-shot answer when the graph is static.

8. **What is the number-of-provinces problem?**
   - Union-find over nodes; after processing all connections the number of components = distinct roots — a direct application with a child/rank implementation.

9. **What is the implementation shape in Python?**
   - parent = list(range(n)); rank = [0]*n; find with while-parent-loop + path compression; union compares ranks then attaches — about 15 lines, tested on classic inputs.

10. **What are the edge cases?**
   - n == 0 or 1, disconnected nodes, self-loops, duplicate edges, and nodes added after unions — the boundary set that finds off-by-ones in init/tracking.

11. **When is union-find NOT the right choice?**
   - When you need path details (the actual route), shortest distances, or weighted ordering — BFS/Dijkstra/MST handle those; union-find only answers membership queries.
