1. **What is the sliding window pattern?**
   - Expanding/shrinking a contiguous subarray with two pointers, incrementally updating the aggregate — converting many O(n^2) subarray problems to O(n).

2. **When does sliding window apply?**
   - Problems over contiguous subarrays/substrings with a constraint on the window (max sum size-k, longest substring with at most k distinct, min window containing all) — fixed or variable size.

3. **What is the difference between fixed and dynamic windows?**
   - Fixed: window size constant, slide one element at a time. Dynamic: size varies, right pointer expands and left shrinks while a condition holds.

4. **Give the framework for a variable-size window.**
   - while r < n: add a[r]; while (condition violated): remove a[l], l++; update answer with (r-l+1); r++ — the canonical loop skeleton.

5. **Why is the sliding window O(n) instead of O(n^2)?**
   - Each element enters once via the right pointer and leaves at most once via the left — total work is O(n) even though it looks like nested loops.

6. **What is the classic maximum-sum-subarray-of-size-k problem?**
   - Compute the first window's sum, then slide subtracting a[l] and adding a[r+1], tracking the max — O(n) instead of recomputing each window.

7. **How does the window maintain 'at most k distinct characters'?**
   - Right extends the window while distinct-count increases; when it exceeds k, shrink from the left until the constraint holds — each character tracked by a frequency counter.

8. **What is the difference between this and the two-pointer pattern?**
   - Two pointers usually work on sorted arrays with a monotonic comparison; sliding window maintains a contiguous range under a constraint. Overlap: every sliding window is two pointers.

9. **What edge cases do sliding-window implementations need?**
   - Empty input, window size > array length, all-equal characters, and the window never satisfying the constraint (return sentinel) — test all four.

10. **How do you find the minimum window substring?**
   - Expand r until all required chars are inside; shrink l while still containing them, tracking the min length — the flagship 'sliding window with a need/count map' problem.

11. **What is a monotonic deque's role in some window problems?**
   - For min/max over each window, a deque of candidates with windowed indices gives O(1) per element — sliding window with a deque (e.g., sliding window maximum).
