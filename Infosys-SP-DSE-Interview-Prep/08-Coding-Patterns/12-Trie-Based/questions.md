# Coding Patterns — Trie Based Interview Questions and Answers

## Q1: What is a trie (prefix tree)?
**A:** A tree where each node stores a character edge, with end-of-word flags — enabling prefix operations in O(word length), independent of corpus size.

## Q2: What is the basic trie interface?
**A:** insert(word): walk/create nodes and mark end; search(word): walk confirming end flag; startsWith(prefix): walk without needing the end flag — the three canonical methods.

## Q3: What are the complexities?
**A:** Insert/search/startsWith each cost O(L) where L is the word/prefix length; space is O(total characters over all words), trading memory for prefix speed.

## Q4: What is a trie vs a hash set for word lookup?
**A:** Hash set finds exact words in O(L) with O(1) hashing but cannot answer prefix queries; the trie answers startsWith in O(L) regardless of how many words share the prefix.

## Q5: What is the autocomplete pattern?
**A:** Traverse the prefix, then DFS from the node collecting all words with the accumulated char sequences (bounded by k results) — a direct product of search in the trie.

## Q6: What is a compressed trie / radix tree?
**A:** Nodes with single children collapse into one edge — reducing size and nodes while keeping prefix semantics; used in IP routing tables and string dictionaries.

## Q7: What is a ternary search tree?
**A:** A 3-way branching trie variant (less/greater/equal) with BST-like balance — comparable prefix search with different memory/balance trade-offs.

## Q8: What applications use tries?
**A:** Autocomplete/search suggestions, spell checkers, IP/route longest-prefix matching, word-break with dictionary, and text-pattern indexing — mention any you've applied.

## Q9: How does a trie help the 'word break' problem?
**A:** Checking dictionary membership for all substrings near the gap index — a trie accelerates the many-words-starts-with queries vs repeatedly scanning a set.

## Q10: What is the edge case set for tries?
**A:** Empty word (root's end flag), a word that is a prefix of another ('the' vs 'them'), and searching to a node that never existed — each decides between search/startsWith semantics.
