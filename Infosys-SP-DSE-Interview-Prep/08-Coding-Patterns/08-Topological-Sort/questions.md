1. **What is topological sort?**
   - A linear ordering of a DAG such that every edge (u,v) puts u before v — existence requires a DAG; used for dependency/graph ordering problems.

2. **What is the Kahn (BFS in-degree) algorithm?**
   - Count in-degrees, put zero-in-degree nodes in a queue, repeatedly remove one and decrement its neighbours; if output length < node count a cycle exists — O(V+E).

3. **What is the DFS-based topological sort?**
   - A post-order DFS push: after visiting all neighbours, push the node; reverse the pushes (or push while unwinding forward) to get a valid order — O(V+E) with a visited/recursion stack.

4. **How do you detect a cycle with either algorithm?**
   - Kahn: leftover nodes with non-zero in-degree. DFS: encountering a node already grey (on the current path). Cycle presence invalidates any topological order.

5. **What are the classic applications?**
   - Course scheduling/prerequisites, build systems (make), task dependency graphs, and package resolution — any 'what must complete before what' problem.

6. **What is the course-schedule problem as topo sort?**
   - If the prerequisite graph is a DAG you can finish all courses — schedule = topological order; asking 'can you finish' becomes 'is there a cycle'.

7. **What is the difference between BFS and DFS approaches?**
   - Kahn gives a natural order from linear dependencies and trivial cycle detection via count; DFS gives a recursive order — Kahn is often simpler to reason about and to code.

8. **What is the space complexity?**
   - O(V+E) for the adjacency list plus O(V) for in-degrees/queue or recursion depth — the memory profile of the representation, which interviews may probe.

9. **Why must the graph be a DAG?**
   - A cycle means each node depends on another in the cycle — no valid order exists; that's why cycle detection is embedded in both algorithms.

10. **How would you schedule tasks with durations?**
   - Add weighted 'finish times' along dependency edges — longest-path/topological DP over the order — the natural extension beyond bare ordering.
