1. **What is the merge-intervals pattern?**
   - Sort intervals by start, then greedily merge overlapping ones by extending end — converting many interval problems into one sorted linear pass.

2. **What is the standard merge-intervals algorithm?**
   - Sort by start; iterate keeping current; if next.start <= current.end merge (end = max), else push current and start a new one — O(n log n) overall.

3. **How do you define two intervals as overlapping?**
   - a and b overlap iff max(a.start,b.start) <= min(a.end,b.end); merging produces (min(a.start,b.start), max(a.end,b.end)).

4. **How do you handle intervals that touch exactly?**
   - Overlap when end == next.start (depending on the definition): inclusive intervals merge ([1,2],[2,3]) -> [1,3]; state your assumption explicitly.

5. **What is 'insert interval' and how is it different from merge?**
   - Insert keeps sorting justified (already sorted): find the position, merge the overlapped block, and append the rest — O(n) instead of a re-sort.

6. **What is the interval-overlap-count problem (meeting rooms)?**
   - Maximum active overlaps = the peak overlap; solved by scanning start+1/end-1 difference events, or a min-heap of active meetings — O(n log n).

7. **What are the three classic interval variants?**
   - Merge all overlaps; find free gaps between merged intervals; compute maximum concurrent overlaps (min platforms) — master the merge then diff variants.

8. **Why must intervals be sorted first?**
   - Greedy merging is only safe when you visit intervals by start — sorting turns an arbitrary set into a monotone scan where later intervals cannot start before earlier ones.

9. **What edge cases are common?**
   - Empty input, single interval, intervals fully contained ([1,10],[2,3]), adjacent endpoints, and an interval that touches nothing — each must merge for the right direction.

10. **How does interval logic map to calendar/scheduler systems?**
   - A calendar is a set of intervals; 'merge' finds free blocks, 'overlap count' builds the meeting-load curve, and 'insert' places a meeting — the same pattern, real product.
