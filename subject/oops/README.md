## Study protocol

1. **Foundations first** — `01_oops_core_foundations/` in order. Read every answer aloud; do not skim.
2. **Principles** — `02_solid_and_design_principles/` for SOLID + general engineering principles + object techniques.
3. **Language depth** — pick your target language(s) in `03_language_specific_deep_dives/` (Java, C++, Python, C#, Go) and study deeply.
4. **Patterns** — `04_design_patterns_mastery/` creational → structural → behavioral → architectural.
5. **Final drills** — `05_oops_interview_rounds/` brutal rapid-fire and interview-simulation rounds the week before interviews.

Each file progresses intuitively: Q1–25 fundamentals → Q26–50 intermediate → Q51–75 advanced → Q76–100 senior/architect level. To get full value, do not skip the last quarter of any file — that is where top-company filtering happens.
