# Data Sufficiency — Topic Guide

> Section 1 · Aptitude · Data Sufficiency · _Estimated reading time: 30 min for the full topic_

## What the pre-test asks in this topic

The DSE pre-test's 10-question aptitude section regularly includes **1–2 data-sufficiency questions**
in the classic five-option format:

```
Q. <stem asking for a quantity>

Statement I: ...
Statement II: ...

A. Both statements together are sufficient, but neither alone is.
B. Statement I alone is sufficient, but Statement II alone is not.
C. Statement II alone is sufficient, but Statement I alone is not.
D. Either statement alone is sufficient.
E. Even both statements together are not sufficient.
```

There is **no number to compute**. The answer is a letter that judges the information. It is the
cheapest 1–2 marks in the section if you own the decision tree, and the easiest to throw away if you
start trying to solve the arithmetic.

## Learning objectives

After this topic you should be able to:

- List all five option claims **word for word** and know what each one asserts.
- Apply the four-step procedure: **I alone → II alone → together → compare**.
- Judge sufficiency by *uniqueness*, using a counterexample probe instead of full algebra.
- Recognise the two official routes to **E**: contradictory statements, and statements that never
  connect to the quantity asked.
- Recognise the "percentage/ratio without a base" trick and explain why it makes a statement
  insufficient **alone**.
- Explain why **D** requires that the two statements *agree*, and why two statements that give
  different values lead to E.
- Finish a data-sufficiency question in **under 60 seconds** using the phase budget.

## Quick 3-step solving procedure

1. **Read the stem first** (10 s). Say out loud what single quantity must be determined — "the value
   of x", "the number of litres of milk".
2. **Test each statement alone** (10 s each). Use the counterexample probe: try to name a *second*
   value that also fits. Two values = insufficient. One value = sufficient.
3. **Resolve the branch** (30 s). Both alone insufficient → test together → A if unique, E if not.
   Both alone sufficient → compare values → D if they agree, E if they differ. Mark the letter and
   move on.

## Key takeaways

- ✅ **Sufficiency = uniqueness.** One surviving value, not "I did some algebra".
- ✅ **A statement alone is insufficient does not mean E.** It means you must still test the pair.
- ✅ **D requires agreement.** Two statements giving two different numbers = E, not D.
- ✅ **Percentage and ratio statements need their base** in the same statement to work alone.
- ✅ **A missing link is also E** — distance without time, cost without selling price.
- ✅ **The answer is a letter.** If you are comparing numbers in the option list, you have misread
  the question.
- ✅ **Budget 60 seconds.** A DS question that takes 3 minutes has already cost you two other marks.
- ⚠️ **Meera's warning:** she reads the statements, starts solving, and runs out of the 90-second
  rule before she has picked a letter. Decide first, calculate never.
