## Core concept

### Master formula table

| Quantity | Formula |
|---|---|
| x% of N | `N × x / 100` |
| Percentage of x in N | `x / N × 100` |
| Percentage change | `(new − old) / old × 100` |
| Percentage change, forward | `old × (1 ± p/100)` |
| Successive change (a then b) | `a + b + ab/100` |
| Symmetric up-then-down | net loss = `x²/100 %` |
| x% of y% of N | `N × x × y / 10000` |
| Selling price with p% profit | `CP × (1 + p/100)` |
| Selling price with l% loss | `CP × (1 − l/100)` |
| Profit % | `(SP − CP) / CP × 100` |
| Discount | `SP = MP × (1 − d/100)` |
| Two successive discounts | `d1 + d2 − d1·d2/100` |
| Markup + discount | `SP = CP × (1 + m/100) × (1 − d/100)` |
| Simple interest | `SI = P · r · n / 100` |
| Compound interest | `CI = P[(1 + r/100)ⁿ − 1]` |
| 2-year CI amount | `P × (1 + r/100)²` |
| 2-year CI − SI | `P × (r/100)²` |
| Reverse percentage | x% more ⇒ `x/(100+x)` % less |
| Weighted average % | `Σ (share × value) / 100` |

## Worked example

**Q. The cost price of a bag is ₹2,500. The shopkeeper marks it 40% above cost and gives a 10%
discount. What is the selling price and the profit percent?**

```
MP = 2500 × 1.4 = ₹3,500
SP = 3500 × 0.9 = ₹3,150
Profit % = (3150 − 2500) / 2500 × 100 = 26%
```

**Answer: SP = ₹3,150, profit = 26%.**

## Quick rules

- Base first, then rate, then multiply.
- Two changes multiply: use the multiplier table.
- Profit/loss % is always on CP.
- Discounts chain by multiplication.
- `x% of y% of N = N × x × y / 10000`.
- Two-year CI − SI = `P(r/100)²`.
- Reverse percentage: `x/(100+x)`.
- Never average percentages without weights.

## Common traps

| Trap | Correct |
|---|---|
| `+10%` then `+10%` = 20% | 21% |
| `+20%` then `−20%` = 0% | −4% |
| Two discounts added | Multiply them |
| Profit % on SP | On CP |
| 20% of 30% = 50% | 6% of the base |
| Markup − discount | Multiply multipliers |
