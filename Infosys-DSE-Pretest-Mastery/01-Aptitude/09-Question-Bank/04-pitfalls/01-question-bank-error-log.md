# Question Bank Error Log

> Section 1 · Aptitude · Question Bank · _Estimated reading time: 5 min_
> **Prerequisite:** [Answer key and scorecard](../05-reference/01-answer-key-index-and-scorecard.md)

## In one sentence

A structured log of your mistakes, so the same error is charged to you once rather than on every
attempt.

## Why the pre-test tests this

- A candidate with 60% accuracy who repeats the same mistake scores 60% again. The log is what turns
  60% into 85%.
- The error **signatures** below cover most of what goes wrong in this section, and each one is
  linked to the exact page that fixes it.
- Write the log **immediately after** a wrong answer, not the night before the next attempt. Later,
  you forget which reading produced the error.

## Core concept

### The log format — one row per error

| Column | What to write | Example |
|---|---|---|
| Question | Number and short label | Q45 — average speed |
| My answer | The letter you picked | B (6 km/h) |
| Correct answer | From the key | B (6 km/h) — wait, if correct, no error |
| My reasoning | One line, in your own words | "Added 12 + 4 and halved" |
| Actual error | The named mistake, not "careless" | Used the arithmetic mean for equal distances |
| Fix | The page to re-read | Speed traps §Trap 1 |
| Recurrence | Times you have made it | 2nd time |

**The rule:** "careless" is not an error type. If you cannot name the mistake, you cannot fix it.

### The recurrence counter

Beside each signature, keep a count. The rule that makes the log useful:

| Times you have made this error | Action |
|---|---|
| 1st | Note it, move on |
| 2nd | Re-read the fix page the same day |
| 3rd | Do the matching [90-second drill](../02-techniques/01-ninety-second-drills.md) for that archetype |
| 4th | The error is an **old habit**, not a slip — change your procedure, not your speed |

### Procedure changes for habit-level errors

| Error signature | Procedure change |
|---|---|
| Arithmetic mean of speeds | Write "equal distances?" before computing any average speed |
| Pole vs platform | Underline "pole" or "platform" in the stem |
| Alligation reversed | Write "cheap first" next to the ratio before you compute it |
| Times added instead of rates | Convert both times to rates before touching the calculator |
| DS together-test skipped | Never write a letter before the together-test is done |
| Position arithmetic | Write `total − position + 1` as a unit, every time |

### The 48-hour rule

1. Attempt a block.
2. Log every wrong answer **immediately**.
3. Re-read the fix page for each error.
4. Re-attempt the same block **48 hours later**, untimed.
5. If you still miss it, the error is habit-level — change your procedure (see the table above).

## Worked example

**Q45.** Average speed for a round trip at 40 and 60 km/h. You answered **C (50 km/h)**. Correct is
**B (48 km/h)**.

| Column | Entry |
|---|---|
| My reasoning | "Average of the two speeds" |
| Error signature | #1 — arithmetic mean of speeds |
| Actual error | Applied the equal-**times** formula to an equal-**distances** question |
| Fix | Speed traps §Trap 1 — read the stem for what is equal |
| Recurrence | 1st time |
| Procedure change | Write "equal distances?" on the question before computing |
| Re-attempt | 48 hours later — Q45 and Q68 (both average-speed questions) |

**Note what is *not* in the log:** "I was careless." That entry cannot be acted on. The log exists to
convert a feeling into a procedure change.

## Quick rules

- Log every wrong answer immediately, in one line.
- Name the error from the signature list; "careless" is not a name.
- Recurrence 2 → re-read the fix page. 3 → drill. 4 → change the procedure.
- Re-attempt after 48 hours, untimed.
- A right answer with the wrong reasoning is also a log entry.

## Common traps

| Trap | Why it hurts | Fix |
|---|---|---|
| Logging "careless" | Nothing to act on | Use the signature numbers |
| Logging a day later | You forget the reading | Log immediately |
| Only logging wrong answers | Right answers with shaky reasoning repeat | Log shaky ones too |
| Never re-attempting | The error stays | 48-hour rule |
| Fixing the same error 4 times without a procedure change | It persists | Change the procedure |

## Checklist

- [ ] I logged every wrong answer immediately, with a named signature.
- [ ] I re-read the fix page for each error.
- [ ] I re-attempted the block after 48 hours.
- [ ] I changed my procedure for any signature at 4 occurrences.
- [ ] My recurrence counters are increasing nowhere — or I know exactly which one is stuck.
