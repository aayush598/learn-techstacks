# Section 1 — Aptitude

> Infosys DSE Pre-Test · Section 1 · Aptitude · _Estimated reading time: 6 hours of topic work + 9 hours of practice_

## What this section is

The Infosys DSE pre-test opens with an **aptitude section**: 10 questions in roughly 15 minutes,
covering data sufficiency, percentages, data interpretation, ranking, inequalities, number series,
mixtures, and ratio–speed–distance work. The whole section is 10 marks, and it is the first thing
the recruiter sees.

This directory is the complete study resource for that section: **nine topics, 46 content files,
and a 72-question bank with a full answer key**.

## The one rule that matters

> **90 seconds per question.** 10 questions × 90 seconds = 15 minutes.
> A question you cannot crack in 90 seconds gets your best guess and a move.

Every technique file in this section is built around that budget. If a method takes longer than
90 seconds, there is a faster version of it somewhere in the same file.

## How each topic is organised

Every topic folder follows the same five-part structure, so you always know where to look:

| Folder | Answers | What lives there |
|---|---|---|
| `01-concepts` | "What is this actually asking?" | The rules, the formulas, the notation |
| `02-techniques` | "How do I do it in 90 seconds?" | The procedures, the shortcuts, the order of operations |
| `03-worked-examples` | "What does a finished one look like?" | Fully solved questions with distractor breakdowns |
| `04-pitfalls` | "What will go wrong?" | The named traps and the option each one produces |
| `05-reference` | "What do I revise on the morning of the exam?" | One-page sheets, tables, formula cards |

Each topic also has a `README.md` that acts as its table of contents, and every subfolder has a
short `README.md` listing its files.

## Learning path

| Stage | Duration | Work | You are ready when |
|---|---|---|---|
| 1. Concepts | 1 day per topic | Read `01-concepts` and `02-techniques` for all 8 topics | You can state the main rule of each topic from memory |
| 2. Traps | 2 hours | Read `04-pitfalls` for the four highest-frequency topics | You can name the wrong option each trap produces |
| 3. Practice | 3 days | Part A, then Part B, then Part C of the question bank — untimed | You score 70% per archetype, not just in total |
| 4. Timing | 1 week | One drill a day, then a full timed part | You finish 24 questions in 27 minutes |
| 5. Repair | Ongoing | Error log, re-attempt after 48 hours | Your recurrence counters stop rising |

## Honest rules for this resource

- Every question has real options, a definite correct answer and a breakdown of why each wrong
  option is wrong.
- Every number in every worked example has been computed and checked. If a figure appears in a
  worked example, it is reproducible.
- The 72-question bank has a complete answer key with a one-line reason per question.
- The style is deliberately terse. If a section reads like a textbook, it has failed: the point of
  this resource is that you can use it in the last two hours before the exam.
