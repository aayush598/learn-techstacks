# 00 - Exam Blueprint

> Section 00 · Exam Blueprint · _Estimated reading time: 9 min_
> **Prerequisite:** none

## In one sentence
The **pre-test blueprint is the source of truth for timing and thresholds** — you must plan to 90 seconds per question and 39/60 to unlock stream selection.

## Why the pre-test tests this
- **Time constraint:** 60 questions / 90 minutes = 90 seconds average. The test filters for speed + accuracy under pressure.
- **Threshold gating:** 65% (39/60) minimum to unlock stream selection; falling short blocks stream choice with no manual override.
- **Section asymmetry:** Aptitude 10, English & L&D 15, DBMS/SQL 10, Java problem-solving 25 — Java is the largest pool.
- **Batch variance:** counts/order/negative marking come from live instructions. You cannot rely on exact numbers.

## Worked example
**Scenario:** Ananya has 12 minutes left with 8 questions (mix of Java + Aptitude).  

**Step 1:** Compute remaining: 8 × 90s = 720s = 12 min. Tight but feasible if disciplined.  
**Step 2:** Sort: do questions she knows in first 45s, eliminate on others, flag at 70s.  
**Step 3:** Apply 90-second rule — never go over 90s per question. Bank saved time only if next is harder, not to overthink one.  

**Result:** If she forces a 95s stall on 1 question, she loses ~0.5 questions worth of time minimum. Discipline beats perfection.

## Quick rules
- **Time:** 90 seconds per question average. Treat as hard cap mentally.
- **Gate:** 39/60 (65%) unlocks stream selection.
- **Largest pool:** Java 25/60 — highest leverage if you fix output prediction.
- **Read live:** counts/order/negative marking can vary by batch.
- **Eliminate:** 2 options down often beats guessing blindly if unsure.
- **No date/fee guessing:** never assume exam dates, fees, or pass percentages beyond stated facts.

## Common traps
- **Memorising old counts:** batch differs; read instructions.
- **"I just need to pass":** 39/60 is tight if you lose easy marks to time.
- **Saving time to ruminate:** saved seconds do not earn points.
- **Ignoring Java:** 25 questions can make or break the 39.
- **Assuming negative marking:** treat as unknown until live — plan to avoid blind guesses if risky.

## Checklist
- [ ] You know 60/90 = 90s and 39/60 = 65%.
- [ ] You know the 4 sections and their topics.
- [ ] You know stream list (5 options).
- [ ] You accept batch variance and will read live instructions.
- [ ] You will use the 90-second rule on practice.
