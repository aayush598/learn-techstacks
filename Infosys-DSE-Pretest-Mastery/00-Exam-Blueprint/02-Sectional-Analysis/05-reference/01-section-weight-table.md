# Section Weight And Cheap-Marks Reference

> Section 00 · Exam Blueprint · Sectional Analysis · _Estimated reading time: 12 min_
> **Prerequisite:** [../01-concepts/05-score-model-building-39.md](../01-concepts/05-score-model-building-39.md)

## In one sentence
**One table gives you section weight, target correct counts, and the cheapest archetypes you can use to hit each target.**

## Why the pre-test tests this
- **Single-page revision:** allocation decisions in one glance.
- **Threshold tied to targets:** each section's target adds up to the gate.
- **Cheap-mark map:** tells you what to do first in each section.
- **Practice calibration:** check your mock against these targets.

## Core concept

### The master reference table
| Section | Q | Share | Target correct | Cheapest archetypes |
|---------|---|-------|----------------|---------------------|
| Aptitude | 10 | 16.7% | 6 | data sufficiency, ranking, inequalities |
| English & L&D | 15 | 25.0% | 11 | behavioural, etiquette |
| DBMS / SQL | 10 | 16.7% | 8 | ACID, normalization, basic joins |
| Java | 25 | 41.7% | 15 | definitions, compile ID, common output |
| **Total** | **60** | **100%** | **40** | — |

| Section | Expensive archetype |

### The 39 line
Target 40 so a single slip still clears 39.

## Worked example
**Using the table to set a plan.** Meera checks her mock against the targets:
- Aptitude actual 5 vs target 6 → −1.
- English actual 11 vs target 11 → on target.
- DBMS actual 9 vs target 8 → +1.
- Java actual 12 vs target 15 → −3.

Net vs model: `−1 + 0 + 1 − 3 = −3` → she is 3 marks behind the 40-model, landing at 37 (below the gate). The largest gap is Java (−3), so the next study hour goes to Java output tracing, not to Aptitude. The table turns a vague "I did badly" into a specific, ranked action list.

## Quick rules
- **Java is 41.7%** — protect it.
- **English is 25%** — bank it.
- **DBMS is 16.7%** — relearn the theory fast.
- **Aptitude is 16.7%** — do not over-invest.
- **Target 40, gate is 39.**
- **After each mock, compare actual vs target and fix the largest gap.**

## Common traps
- **Editing targets without recomputing the total.**
- **Assuming difficulty is uniform across sections.**
- **Forgetting the margin above 39.**
- **Chasing the smallest section instead of the largest gap.**

## Checklist
- [ ] You know each section's share of the paper.
- [ ] You know your target per section.
- [ ] Your targets sum to at least 40.
- [ ] You know the cheap archetypes per section.
- [ ] You recompute after each mock.
- [ ] You fix the largest gap first.
