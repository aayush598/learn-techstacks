# Minute-By-Minute Mock Run (Rahul's Test Day)

> Section 00 · Exam Blueprint · Test Day Strategy · _Estimated reading time: 22 min_
> **Prerequisite:** [../02-techniques/01-flagging-and-review-strategy.md](../02-techniques/01-flagging-and-review-strategy.md)

## In one sentence
**A minute-by-minute test-day log shows the strategy is not theory — every checkpoint forces a concrete action.**

## Why the pre-test tests this
- **Rehearsal:** it turns rules into an executable script.
- **Checkpoints:** it shows how to react when you are behind or ahead.
- **Flagging in action:** it demonstrates converting uncertain marks.
- **Rahul's profile:** strong Java, weak English — a genuine stress test of the strategy.

## Core concept

### The setup
Rahul attempts a full 60-question mock in 90 minutes. The reported order (illustrative) is Aptitude → English & L&D → DBMS/SQL → Java. No negative marking is stated.

### Rahul's profile
| Attribute | Detail |
|-----------|--------|
| Java | Strong — recognises output patterns quickly |
| English | Weak — judgment fine, grammar shaky |
| DBMS | Solid on theory and joins |
| Aptitude | Average |
| Weakness | Stalls when he feels "almost there" |

### The minute-by-minute log
| Time | Q done | Event | Action taken |
|------|--------|-------|--------------|
| 0:00-0:01 | 0 | Reads instructions | Notes: no negative marking → will fill everything |
| 0:01-0:14 | 8 | Aptitude: DS, %, ranking, inequalities | Marks 6 confident; flags 1 DI; guesses 1 series |
| 0:14-0:16 | 8 | Behind check: target 10 by min 15 | Slightly behind; continues, will recover in English |
| 0:16-0:36 | 23 | English & L&D | Fast behavioural/etiquette (9 sure); flags 3 error-correction |
| 0:36-0:38 | 23 | Checkpoint: 23 done vs target ~25 | On pace |
| 0:38-0:52 | 33 | DBMS / SQL | ACID, normalization, joins (8 sure); flags 2 query-writing |
| 0:52-0:54 | 33 | Checkpoint: 33 done | On pace |
| 0:54-0:56 | 33 | A hard inner-class Java question at 80s | Flags it; does NOT stall |
| 0:56-1:14 | 48 | Java output/collections/exceptions | 10 sure, 3 flagged |
| 1:14-1:16 | 48 | Checkpoint: 48 done, 16 min left | Slightly ahead after Java speed |
| 1:16-1:26 | 60 | Finishes remaining Java | Converts 2 flagged (known patterns) |
| 1:26-1:30 | 60 | Final review: 8 flags total | Converts 3 flags: 1 DI, 1 series, 1 error-correction |
| 1:30 | 60 | Stop | All questions answered; no blanks |

### Result reconstruction
| Section | Correct | Flags converted | Notes |
|---------|---------|-----------------|-------|
| Aptitude | 6 | +1 (DI) | Guessed series wrong |
| English & L&D | 11 | +1 (error corr) | 2 flags wrong |
| DBMS / SQL | 8 | 0 | 1 query flag wrong, 1 right (counted) |
| Java | 15 | +1 (pattern) | 2 flags wrong |
| **Total** | **40** | **+3** | ✅ clears by 1 |

### Key decision points
1. **0:54:** flagged instead of stalling 80+ seconds on inner-class scoping — saved roughly 40 seconds.
2. **1:16:** converted Java flags using recognised output patterns.
3. **1:26:** final review targeted only flags — converted three.
4. **Filled every question** because no negative marking was stated.

## Worked example
**The counterfactual that decided the pass.**

If Rahul had stalled 100 seconds on the inner-class question at 0:54, he would have finished Java two questions short and had about 6 minutes for review instead of 14. His flag conversions would drop from three to about one, and his total falls to roughly 38 → ❌.

**The single flag-and-move decision at 0:54 is worth the pass.**

| Scenario | Review time | Flags converted | Total | Result |
|----------|-------------|-----------------|-------|--------|
| Flag at 0:54 | 14 min | 3 | 40 | ✅ |
| Stall to 0:54+ | 6 min | 1 | 38 | ❌ |

## Quick rules
- **Check at 15 / 40 / 60 / 76 minutes.**
- **Flag instead of stalling.**
- **Convert flags in the last 15 minutes.**
- **Fill everything if there is no penalty.**
- **One decision can decide the pass.**
- **Never exceed 90 seconds on any question.**

## Common traps
- **Skipping checkpoints.**
- **Stalling at 80 seconds** because you feel close.
- **Leaving a blank when there is no penalty.**
- **Reviewing answered questions instead of flags.**

## Checklist
- [ ] You have drafted your own minute log.
- [ ] You check at four points.
- [ ] You flag at 70 seconds.
- [ ] You convert flags at the end.
- [ ] You fill all questions per the live policy.
- [ ] You never exceed 90 seconds on any question.
