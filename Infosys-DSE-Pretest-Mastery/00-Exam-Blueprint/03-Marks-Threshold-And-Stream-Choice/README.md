# 03 - Marks Threshold And Stream Choice

> Section 00 · Exam Blueprint · Marks Threshold And Stream Choice · _Estimated reading time: 11 min_
> **Prerequisite:** [../README.md](../README.md)

## In one sentence
**39/60 (65%) is a hard gate — clear it and stream selection unlocks; miss it and no stream is offered regardless of preference.**

## Why the pre-test tests this
- **Binary consequence:** the threshold is not advisory; it gates the next step.
- **Arithmetic matters:** knowing how 39 is built prevents panic.
- **Stream mapping:** your target score and strengths point to different streams.
- **Risk:** negative marking and guessing change whether you clear or fail.

## Core concept

### Threshold facts
| Item | Value |
|------|-------|
| Total questions | 60 |
| Pass mark | 65% |
| Minimum marks to unlock stream selection | 39 |
| Consequence of missing | No stream selection offered |
| Consequence of clearing | Stream choice form unlocks |

### Streams selectable after clearing
| Stream | Focus |
|--------|-------|
| Java + Angular | Backend + web frontend |
| Data Science & Agentic AI | Data, ML, AI agents |
| UI Stack | UI/frontend |
| Data Engineering | SQL, pipelines, ETL |
| Microsoft Azure + .NET | Cloud + .NET |

### Path to 39 (one viable split)
| Section | Q | Target correct |
|---------|---|----------------|
| Java | 25 | 15 |
| English & L&D | 15 | 11 |
| DBMS/SQL | 10 | 8 |
| Aptitude | 10 | 6 |
| **Total** | **60** | **40 (margin +1)** |

## Worked example
**Two candidates, same knowledge, different outcomes:**
- **Candidate A** leaves 6 blanks (no negative marking stated but didn't read) → loses ~1.5 expected marks → 37.5 → **fails**.
- **Candidate B** fills all with elimination → +2 marks → 40 → **clears.**
The threshold reward is as much about rule-following as knowledge.

## Quick rules
- **39/60 = 65% is the gate.**
- **5 streams unlock after clearing.**
- **Aim 40 for margin.**
- **Read the live negative-marking policy.**
- **Never leave blanks if there's no penalty.**

## Common traps
- **Assuming exact 39 is enough in a batch with stricter rules.**
- **Choosing a stream you can't sustain** (covered in later resource folders).
- **Ignoring batch variance in the threshold.**
- **Letting one section sink the total.**

## Checklist
- [ ] You know the gate is 39/60 (65%).
- [ ] You know the 5 streams.
- [ ] You aim to clear with margin.
- [ ] You read the live rules.
- [ ] You have a per-section path to 39.
