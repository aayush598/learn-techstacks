# 05 - Pretest History And Variants

> Section 00 · Exam Blueprint · Pretest History And Variants · _Estimated reading time: 11 min_
> **Prerequisite:** [../README.md](../README.md)

## In one sentence
**The pre-test has two commonly reported variants — the off-campus DSE assessment and the standard online assessment — and the safe move is to prepare the shared core and read live instructions.**

## Why the pre-test tests this
- **Batch variance is real:** counts, order, and negative marking differ by intake.
- **Two variants:** candidates report a DSE-specific format and a broader online-assessment format.
- **Shared core:** topics barely change; mechanics sometimes do.
- **Calm under variance:** knowing what's stable prevents panic when the live test differs.

### The two reported variants
| Aspect | Off-campus DSE pre-test | Standard online assessment |
|--------|-------------------------|----------------------------|
| Sections | Aptitude, English & L&D, DBMS/SQL, Java problem-solving | Can be a broader aptitude + coding screening |
| Java weight | Highest (25 reported) | May vary |
| Section counts | Reported 10/15/10/25 | Reported to vary |
| Gate | Cleared to unlock stream selection | Depends on the drive |
| Topics | Same recurring archetypes | Same recurring archetypes |

### What stays constant
| Constant | Detail |
|----------|--------|
| 90-second-per-question pressure | Applies to any 60×90 format |
| Core topics | Aptitude, English/L&D, DBMS/SQL, Java fundamentals |
| Stream selection gate | Clearing unlocks stream choice in the DSE track |
| Batch variance | Always read live instructions |

### Honest uncertainty
Exact counts, order, negative marking, and even section presence can vary. **This resource never invents dates, fees, or pass percentages beyond 39/60 and 65%.** Verify everything against live instructions.

## Worked example
**Karthik's retrospective:** "I prepared using a friend's older pattern that had a shorter Java section. The live test had 25 Java questions. Because I'd drilled the topics (not the counts), I adapted in the first minute. **Prepare topics, not counts.**"

## Quick rules
- **Two variants exist; prepare the shared core.**
- **Topics are stable, mechanics vary.**
- **Read live instructions in the first 2 minutes.**
- **Never assume counts from a previous batch.**
- **Adapt, don't panic, if the format differs.**

## Common traps
- **Memorising one variant's counts.**
- **Panicking when the live format differs.**
- **Assuming negative marking from hearsay.**
- **Trusting invented dates/fees from peers.**

## Checklist
- [ ] You know both reported variants.
- [ ] You know what stays constant.
- [ ] You'll read live instructions first.
- [ ] You prepare topics, not counts.
- [ ] You'll adapt if the format differs.
