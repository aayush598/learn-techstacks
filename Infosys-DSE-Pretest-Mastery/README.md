# Infosys DSE Pre-Test Mastery

> A complete, topic-by-topic preparation resource for the **Infosys Digital Sourcing & Engineering (DSE) pre-test** — the 60-question, 90-minute screening test you must clear to unlock stream selection.

---

## 1. The Exam at a Glance

| Item | Detail |
|------|--------|
| **Total questions** | 60 |
| **Total time** | 90 minutes → **90 seconds per question** average |
| **Pass mark** | **65%** → **39 / 60** minimum |
| **Why it matters** | Clearing it unlocks the **stream selection** form. No stream, no training track. |
| **Format** | Section-wise MCQ, mostly objective, negative marking varies by batch |
| **Sections** | 4 (see below) |

> Batch-to-batch variation is real. The *section weights* below are the pattern reported consistently
> by candidates across recent intakes; the *topics within each section* are far more stable than the
> exact count. **Assume the section split, but never memorise the count — always read the live instructions.**

### Section split

| # | Section | Questions | Time budget | Where to study |
|---|---------|-----------|-------------|----------------|
| 1 | **Aptitude** | 10 | ~15 min | [`01-Aptitude/`](01-Aptitude/) |
| 2 | **English & L&D** | 15 | ~22 min | [`02-English-And-LD/`](02-English-And-LD/) |
| 3 | **DBMS / SQL** | 10 | ~18 min | [`03-DBMS-SQL/`](03-DBMS-SQL/) |
| 4 | **Problem Solving (Java)** | 25 | ~35 min | [`04-Java/`](04-Java/) |

**Total: 60 questions / 90 minutes.**

## 2. The One-Page Game Plan

```
┌──────────────────────────────────────────────────────────────────────────┐
│  BEFORE THE TEST                                                       │
│  • Clear the topic notes, not the whole theory.                          │
│  • Drill question banks with a 90-second hard cap per question.          │
│  • Memorise ONE page per section (see 07-Cheat-Sheets/).                 │
│  • Do 2 full mocks in 90-minute blocks, no pauses.                       │
└──────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌──────────────────────────────────────────────────────────────────────────┐
│  IN THE TEST — THE 90-SECOND RULE                                       │
│  1. Read the question stem FIRST, before the options.                    │
│  2. If you know the answer in 45s → mark and move.                       │
│  3. If you don't → eliminate wrong options (usually 2 die instantly).   │
│  4. Still nothing at 70s → mark the least-wrong, flag, move. NO RUMINATE.│
│  5. Never spend >90s. The remaining time is worth more than one point.  │
└──────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌──────────────────────────────────────────────────────────────────────────┐
│  SECTION ATTACK ORDER                                                   │
│  • Aptitude: go for the 5 easy ones first, bank the time.                │
│  • English/L&D: mostly reading comprehension → FASTEST section to score. │
│  • DBMS/SQL: predictable. Learn the join rules → near-guaranteed 8–10. │
│  • Java: longest section. Do the output-prediction ones you know first. │
└──────────────────────────────────────────────────────────────────────────┘
```

## 6. Scoring Benchmarks

| Practice score | Verdict |
|----------------|---------|
| **54–60 (90%+)** | You are safe. Take one mock more, then stop studying. |
| **48–53 (80–90%)** | Comfortable. Do not study new topics; drill speed. |
| **42–47 (70–80%)** | Passable. Attack your weakest section — usually Java or Aptitude. |
| **39–41 (65–70%)** | Minimum viable. Sharpen error identification, not knowledge. |
| **30–38 (50–65%)** | Not yet. Go back to the topic notes; do not just take more mocks. |
| **< 30** | Start with `00-Exam-Blueprint` and `01-Aptitude`, then Java output patterns. |

## 7. Non-Negotiable Rules for Candidates

1. **Read the live instructions.** Counts, order, and negative marking are set by the live test. This
   resource describes the *pattern*; the live test decides the *rules*.
2. **Never leave a section empty.** A blank is a guaranteed zero; a guess is sometimes one point.
3. **The Java section is the biggest score pool (25 Q).** Even 13/25 there = 13 points ≈ 22% of the paper.
4. **L&D questions have one intended "professional" answer.** Pick the answer a new hire at Infosys
   would give in a real workplace. See [`02-English-And-LD/01-Behavioural-Scenario-Based/`](02-English-And-LD/01-Behavioural-Scenario-Based/README.md).
5. **Do not over-invest in Aptitude.** 10 questions ≈ 17% of the paper. Learn the 7 recurring archetypes
   (data sufficiency, percentages, DI, ranking, inequalities, series, mixtures) and move on.
6. **Rehearse the "compile or not" question.** A large slice of the Java section is
   *does this code compile / does it run / what does it print*. See
   [`04-Java/08-Output-Prediction-Patterns/`](04-Java/08-Output-Prediction-Patterns/README.md).
