## Quick rules

- "Handle it professionally", "take appropriate steps", "ensure things are sorted" = distractor, every time.
- The correct option breaks if you move it to a different scenario. Generic options do not break.

## Common traps

- Choosing the option with the fewest words.
- Sympathising with the passive option because it "sounds like a good teammate".
