## In one sentence
**These two files are the execution layer: a timed 6-step procedure that fits inside 90 seconds, and a 3-sentence template for when the question asks you to describe your own response.**

## Why the pre-test tests this

- A behavioural question is pattern recognition, not deliberation. A fixed procedure stops you from
  re-reading the stem four times.
- The written-answer template is needed if a batch uses a descriptive or interview-linked item.

## Quick rules

- Label options before evaluating them.
- Never spend the full 90 seconds on one item.
- Three sentences for a written answer: situation, action, reason.

## Common traps

- Writing five sentences when three will do.
- Reasoning with character ("I am responsible") instead of impact.

## Checklist

- [ ] I have run the 6-step procedure at least 10 times in the question bank.
- [ ] I can write a professional answer to an arbitrary scenario in 30 seconds.
