## In one sentence
**The four near-miss traps: correct-but-unfamiliar segments, errors hiding one word deep inside a good phrase, chunk-versus-clause judgement, and forcing an error that is not there.**

## Why the pre-test tests this

- Over-flagging is the most common way a weak-English candidate loses error-correction marks: three "wrong"
  chunks, one real answer, and a wrong pick.

## Quick rules

- Name the rule, not the feeling.
- Style, formality, and length are never errors.
- If nothing fires, look for a single mis-read word.

## Common traps

- Flagging "in accordance with", "prior to", "not only … but also".
- Missing its/it's, then/than, fewer/less.
