## Quick rules

- `for` + bare duration, `since` + starting point.
- `fewer` + countable, `less` + uncountable.
- `than` = comparison, `then` = sequence.
- `affect` = verb, `effect` = noun.
- `its` = possessive, `it's` = it is.

## Common traps

- Applying the British "the team are" rule.
- Flagging formal-but-correct constructions.
