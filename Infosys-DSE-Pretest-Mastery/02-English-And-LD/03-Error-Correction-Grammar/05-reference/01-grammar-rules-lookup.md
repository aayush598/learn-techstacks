## In one sentence
**One page of every rule you need for error correction, ordered the way the scan asks for them — so you can check a rule mid-question instead of recalling it.**

## Why the pre-test tests this

- You do not need a grammar textbook. You need **the 60 rules that actually appear**.
- Having them on one page turns "I think that's wrong" into "which rule is this?".
- Print it. Use it during drills with a pen in your hand.

## Core concept

### 1. Subject-verb agreement

| Rule | Example |
|------|---------|
| The verb agrees with the **head noun** of the subject | "The **list** of items **is**" ✅ |
| `of` phrases never control the verb | "The team **of** developers **has** agreed" ✅ |
| "each / every / everyone / somebody / either / neither" → **singular** | "**Each** of the trainees **was** given" ✅ |
| "the number of" → singular; "a number of" → plural | "The number of defects **is**" ✅ / "A number of defects **are**" ✅ |
| "one of the" → singular verb | "One of the modules **requires**" ✅ |
| A unified team, company, or organisation → singular (Indian English) | "The team **is**" ✅ |
| Compound subject joined by "and" → plural | "The team and the client **are**" ✅ |
| Compound subject joined by "or / nor" → the verb matches the **nearer** subject | "Neither the manager nor the team **was** informed" ✅ |

### 2. Articles

| Rule | Example |
|------|---------|
| Countable singular noun needs an article | "She is **an** engineer" ✅ |
| `a` = one of many, first mention; `the` = specific, already known | "**a** client" ✅ / "**the** client" ✅ |
| `a` vs `an` by **sound** | "**an** hour", "**a** university", "**an** MBA", "**a** one-rupee coin" |
| No article with uncountable nouns used generically | "**Information** is confidential" ✅ |
| No article before names, meals used generically, languages, subjects | "She speaks **French**" ✅ |
| `the` with unique things | "the sun", "the internet", "the manager I mentioned" ✅ |

### 3. Prepositions (high-frequency collocations)

| ✅ Correct | ❌ Wrong |
|-----------|---------|
| discuss, discuss **with** | discuss **about** |
| depend **on** | depend **of** |
| emphasize | emphasize **on** |
| married **to** | married **with** |
| reach, reach **for** | reach **at** |
| different **from** | different **than** (avoid) |
| according **to** | according **for** |
| reason **for** | reason **of** |
| responsible **for** | responsible **of** |
| consist **of** | consist **in** (only when it means "lie in") |
| prior **to** | prior **of** |
| deployed **to production** | deployed **to the production** |
| provide feedback (no article) | provide **a** feedback |

### 4. Tense

| Rule | Example |
|------|---------|
| One time frame per sentence unless justified | "Yesterday I **was** working" ✅ |
| Reported speech **back-shifts** | "He said he **was** tired" ✅ |
| Present perfect with `since` / `for` | "**has been** running **since** 2024" ✅ |
| Habitual actions take the simple present | "The build **runs** nightly" ✅ |
| A time clause uses the present for a future event | "If it **fails**, we **roll back**" ✅ |

### 5. Pronouns and reference

| Rule | Example |
|------|---------|
| A pronoun must have a clear antecedent | "The company said **they** would…" → "**it**" ✅ |
| `its` = possessive; `it's` = "it is" | "**its** own policy" ✅ / "**it's** important" ✅ |
| `their` = possessive/pronoun; `there` = place; `they're` = "they are" | "**they're** going to be late" ✅ |
| `your` = possessive; `you're` = "you are" | "**you're** late" ✅ |
| `whose` = possession; `who's` = "who is" | "**who's** the lead?" ✅ |

### 6. Relative pronouns

| Word | For | Note |
|------|-----|------|
| `who` | people | "the engineer **who** fixed it" ✅ |
| `which` | things | "the module **which** failed" ✅ |
| `that` | people or things | restrictive only — never after a comma |
| `whom` | people, after a preposition | "the person **to whom** I spoke" ✅ |
| `whose` | possession | "the person **whose** code failed" ✅ |

### 7. Modifiers

| Rule | Example |
|------|---------|
| A modifier attaches to the noun immediately before it | "the file **that I sent** to Rahul" ✅ |
| Long modifiers go after the noun; short ones before it | "a **difficult** decision" ✅ / "a decision **that took two weeks**" ✅ |
| A participle must modify the subject | "**Walking into the room, I saw** the projector fail" ✅ |
| No dangling participles | "Walking into the room, the projector failed" ❌ |
| Adverbials of time and place go at the end | "We reached the office **at 6 p.m.**" ✅ |

### 8. Connectors and punctuation

| Situation | Correct |
|-----------|---------|
| Two independent clauses, one comma | ❌ comma splice → use **;** / **, and** / **.** / **Because …** |
| Subordinate clause first + main clause | ✅ "**Although it rained**, the match continued." |
| Two independent clauses with a coordinator | ✅ "It failed**, and** we rolled back." |
| Items in a list | ✅ "A, B, and C" |
| Double negative | ❌ → "did not receive **any**" ✅ |
| Exception | ✅ "**not only** … **but also**" |

### 9. since / for

| Word | Takes | Example |
|------|-------|---------|
| `since` | a starting **point** | "since 2024", "since Monday", "since two hours ago" |
| `for` | a **duration** | "for two hours", "for three years", "for a long time" |

### 10. fewer / less · than / then · affect / effect

| Pair | Rule |
|-----|------|
| fewer / less | `fewer` + countable plural; `less` + uncountable |
| than / then | `than` = comparison; `then` = time or sequence |
| affect / effect | `affect` = verb; `effect` = noun (verb only in rare formal uses) |

### 11. Gerund vs infinitive

| Gerund only | Infinitive only |
|-------------|-----------------|
| enjoy, mind, avoid, finish, suggest, consider, imagine, risk, keep, miss, deny, admit, recommend, avoid | want, hope, decide, plan, intend, agree, offer, refuse, promise, learn, expect, manage, arrange, claim |

Also: `used to + infinitive`, `be used to + gerund`, `look forward to + gerund`.

### 12. Redundant modifiers

| ❌ | ✅ |
|---|------|
| absolutely essential | essential |
| completely finished | finished |
| free gift | gift |
| final conclusion | conclusion |
| past history | history |
| future plans | plans |
| end result | result |
| new innovation | innovation |
| each and every | each / every |
| first and foremost | foremost |
| unexpected surprise | surprise |
| repeat again | repeat |
| unite together | unite |
| close proximity | proximity |
| new brand-new | brand-new |
| personal opinion | opinion |
| advance planning | planning |

## Worked example

> **Q.** Identify the part of the sentence that contains an error.
>
> "**One of the** **follow-up actions was** **left pending for** **the last three weeks**, **and the** **client was informed** **about the** **delay in** **response**."
>
> A. One of the follow-up actions was
> B. left pending for the last three weeks
> C. and the client was informed
> D. about the delay in response

**Answer: B** — "left pending **for the last three weeks**" ❌. "For" takes a bare duration ("for three weeks"), not a
duration qualified by "the last". Either "for **three weeks**" or "since **the last three weeks**" (or "for the past
three weeks" — also acceptable) is required. The standard exam answer is "for **three weeks**".

**Why not the others:**
- A: "One of the follow-up actions **was** left" ✅ — "one" is the singular subject.
- C: ", and the client was informed" ✅ — a comma plus a coordinator correctly joins two independent clauses.
- D: "about the delay in response" ✅ — correct prepositional chain, "the delay" specific.

**The rule used:** `for` + a bare duration; `since` + a starting point.

## Quick rules

- Agreement → head noun, not the nearest noun.
- Articles → by sound.
- Prepositions → the standard collocation only.
- Tense → one frame per sentence; reported speech back-shifts.
- Pronouns → a clear antecedent; `its` vs `it's`.
- Modifiers → attach to the noun immediately before.
- Connectors → a comma cannot join two independent clauses.
- Redundancy → two words meaning the same thing.

## Common traps

- Using the British "the team are" rule in an Indian-English paper.
- Flagging "in accordance with" or "prior to".
- Flagging "not only … but also".
- Forgetting "the last three weeks" needs "the past" or a plain duration.
