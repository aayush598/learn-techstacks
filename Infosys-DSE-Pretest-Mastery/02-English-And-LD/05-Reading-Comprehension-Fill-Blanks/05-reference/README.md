## Quick rules

- Identify the type from the stem wording in 5 seconds.
- "NOT" items: the answer is the option the passage never mentions.
- Pick the less extreme tone option when two are plausible.

## Common traps

- Using the wrong evidence standard for the type.
- Choosing an extreme tone option.
