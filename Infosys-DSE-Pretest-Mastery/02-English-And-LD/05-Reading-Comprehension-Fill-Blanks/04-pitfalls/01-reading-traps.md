# Reading Traps

> Section 2 · English & L&D · Reading Comprehension & Fill Blanks ·  _Estimated reading time: 7 min_
> **Prerequisite:** [Solving a passage in 90 seconds](../02-techniques/01-solving-a-passage-in-90-seconds.md)

## In one sentence
**Eight ways these passages defeat you — each one has a signature in the wording of the wrong option, and a one-line counter.**

## Why the pre-test tests this

- The wrong options are **manufactured**, not accidental. Every distractor has a job: too strong, too narrow,
  topic-jump, outside knowledge, and so on.
- Once you can name the job, you stop being persuaded by it.

## Core concept

### The 8 traps and their counters

| # | Trap | What the wrong option looks like | Counter |
|---|------|----------------------------------|---------|
| 1 | **Too-strong inference** | "always", "never", "only", "no one", "proves", "impossible" | Ask: could a careful reader disagree? If yes, it is not supported. Reject the absolute. |
| 2 | **Outside knowledge** | True in the real world but not in the passage | Ask: is this *in* the passage? If it is only true in life, it is wrong here. |
| 3 | **Main idea vs detail** | An option that is true but only covers one paragraph | Test coverage: does the whole passage support it? |
| 4 | **Twist dropped** | An option matching P1 only, ignoring P2's contrast | Main idea = P1 topic **+** P2 twist. Always add the twist. |
| 5 | **Option echo** | The option repeats words from the passage but changes the relationship ("not because X but because Y") | Read the option against the passage's actual causal direction, not its vocabulary. |
| 6 | **Quantifier swap** | "many" becomes "most", "some" becomes "all", "often" becomes "usually" | Compare the quantifier word itself. "Many teams" ≠ "All teams". |
| 7 | **Vocabulary by dictionary** | The dictionary sense, not the sense used in that sentence | Read the sentence around the word; the sentence decides. |
| 8 | **Time spend** | A question that has consumed 3 minutes | Cap at 90 seconds. Flag it, move on, return in the final 2-minute review. |

### Trap 5 in detail — the option echo

This is the most sophisticated trap in the set, because the option uses the passage's own vocabulary and feels
familiar.

```
Passage: "the shift has not eliminated the need for human judgement"
Echo ❌: "the shift eliminated the need for human judgement"   ← uses every word, reverses the meaning
Echo ❌: "the shift may have reduced the need for human judgement" ← vague dilution
✅ Correct: "automation speeds up testing but does not remove the need for human judgement"
```

**Counter:** do not check whether the option's words appear in the passage. Check whether the option's
**relationships** match the passage's relationships.

### Trap 6 in detail — the quantifier swap

| Passage says | Option says | Verdict |
|--------------|-------------|---------|
| "Many organisations" | "Most organisations" | ❌ stronger |
| "some teams" | "all teams" | ❌ universal |
| "often" | "usually" | ❌ stronger |
| "can" | "will" | ❌ certainty |
| "may" | "must" | ❌ certainty |
| "rarely" | "never" | ❌ stronger |

If the passage hedges and the option does not, the option is wrong.

### Trap 3 vs Trap 4 — a decision you can make in 5 seconds

```
Is the question "mainly about / central idea / best title"?
   |- Yes → run the 3-test (coverage, neutrality, proportion)
   +- No  → it is a detail question; find the line and move on
```

A true statement that only covers P1 is a **detail**, never a main idea.

### Trap 8 — the time trap

The passages are designed to feel harder than they are. Symptoms of the time trap:

- You have read the same sentence four times.
- You are comparing two options on vibes.
- You have started checking whether the passage "seems" to support something else.

Action: mark the item, move to the next question, and come back in the final 2-minute review with the evidence
line found. If it still does not resolve in 30 seconds, pick the option with the weakest claim — under-claiming
beats over-claiming on inference items.

### The universal reject list

Any option containing these is suspect until the passage explicitly supports it:

| Word | Why it is suspect |
|------|-------------------|
| always, never, all, none, every | universals are rarely supported |
| only, solely, exclusively | exclusivity needs explicit support |
| proves, demonstrates conclusively | passages suggest; they rarely prove |
| obviously, clearly, always | no passage states what is "obvious" |
| because | claims a cause the passage may not claim |
| best, worst, most successful | requires a comparison the passage may not make |

## Worked example

> **Passage:** "Automation of routine testing has become standard practice in software delivery teams. Test
> scripts that once took engineers two days to write can now be generated and updated in under an hour, which
> allows teams to increase coverage rather than reduce it. The shift has not eliminated the need for human
> judgement."
>
> **Q.** It can be inferred that test automation:
>
> A. has completely replaced the need for experienced engineers
> B. frees up engineer time that can be redirected to higher-value work
> C. is adopted only by organisations with large test suites
> D. reduces the cost of maintaining software to zero

**Trap walkthrough:**

| Option | Trap | Verdict |
|--------|------|---------|
| A | Too-strong inference + option echo ("has not eliminated" → "has completely replaced") | ❌ |
| B | Legitimate one-step inference — faster script production (P2) implies time redirected (P2's "increase coverage") | ✅ |
| C | Outside knowledge + quantifier swap ("standard practice" → "only organisations with large test suites") | ❌ |
| D | Overreach: the passage never mentions cost, and "zero" is an absolute | ❌ |

**Counter applied to B:** could a careful reader of this passage disagree? Only if "increase coverage" did not
imply redirecting time — but the passage explicitly says the speed-up "allows teams to increase coverage rather
than reduce it", so the inference is one step, not two. ✅

## Quick rules

- Every wrong option has a job. Name it and the option loses its power.
- Reject universals and quantifier upgrades unless the passage is explicit.
- True-in-life but not-in-passage = wrong.
- Under-claim rather than over-claim on inference items.
- 90 seconds per question, then move.

## Common traps

- Assuming a fluent option is correct.
- Missing a quantifier swap.
- Answering a main-idea question with a P1 fact.
- Spending 3 minutes on a single item because you cannot decide.

## Checklist

- [ ] I named the trap type for the option I rejected.
- [ ] I checked every quantifier against the passage.
- [ ] I did not use outside knowledge.
- [ ] I left the item within 90 seconds.
