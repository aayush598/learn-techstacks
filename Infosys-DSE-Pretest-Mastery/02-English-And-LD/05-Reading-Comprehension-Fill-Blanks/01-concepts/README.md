## Quick rules

- Label paragraphs in 3 words, then read the questions.
- Delete the blank, then predict.
- Main idea = P1 topic + P2 twist.

## Common traps

- Reading the options before locating the evidence.
- Solving a lexical cloze on grammar alone.
