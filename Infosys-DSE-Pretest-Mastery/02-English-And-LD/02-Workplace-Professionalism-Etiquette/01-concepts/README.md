## Quick rules

- Professional = rule-compliant, timely, respectful, documented.
- Never a client request left unanswered, even on leave.
- Never a policy bent "for a good reason".

## Common traps

- Following the team's visible habit instead of the written policy.
- Treating politeness as a substitute for action.
