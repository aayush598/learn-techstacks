## Quick rules

- The professional option contains an action **and** a communication.
- Timing beats volume.
- Decline + explain + offer an alternative is the refusal formula.

## Common traps

- The polite-but-useless option.
- The efficient-but-non-compliant option.
- Assuming someone else will document the outcome.
