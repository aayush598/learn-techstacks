## In one sentence
**Six trap shapes: polite-but-empty, efficient-but-non-compliant, helpful-but-rule-breaking, right-for-you-wrong-for-the-role, over-communicating, and self-interested framing.**

## Why the pre-test tests this

- All four options in an etiquette item usually sound reasonable. Only the trap shapes separate them.

## Quick rules

- No change → trap.
- Breaks a rule → trap.
- Serves you at someone else's expense → trap.
- "Everyone does it" → red flag.

## Common traps

- Conformity mistaken for professionalism.
- Escalation used as a first move.
- Over-formality or under-formality relative to the role.
