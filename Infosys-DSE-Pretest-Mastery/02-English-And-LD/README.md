# Section 2 — English & L&D

> Section 2 · English & L&D · Section Overview ·  _Estimated reading time: 8 min_
> **Prerequisite:** [Master README](../README.md)

## In one sentence
**Section 2 is 15 questions in ~22 minutes and it is the cheapest 15 points in the paper** — nothing here needs outside knowledge, only the frameworks in this folder and a 90-second cap per question.

## Why the pre-test tests this

- Infosys uses Section 2 to screen for **communication maturity**, not for an English degree. There is no
  literature passage longer than six lines.
- The section is reported as the **fastest to score**: most candidates clear it in under 18 minutes.
- It carries roughly **25% of the paper** (15/60) but demands the least preparation time of any section.
- Five sub-types repeat across batches: **behavioural/scenario**, **workplace professionalism/etiquette**,
  **error correction** in the four-underlined-segment format, **vocabulary** (synonym/antonym/confused pairs),
  and **reading comprehension** (short passage or fill-in-the-blank).

## Core concept — the 22-minute budget

```
+----------------------------------------------------------------------+
|  15 questions · ~22 minutes                                         |
|                                                                      |
|  • Error correction   → 4–5 min  (fastest if you own the 8-step scan)|
|  • Vocabulary         → 2–3 min  (memory; zero reading)             |
|  • Reading comprehension → 4–5 min (one passage, one pass)         |
|  • Etiquette          → 3–4 min  (one decision rule)                |
|  • Behavioural        → 6–7 min  (slowest per question: 90s each)   |
|                                                                      |
|  Reserve 2 min at the end to re-check the 3 flagged questions.      |
+----------------------------------------------------------------------+
```

## Core concept — the section-wide rules

| Rule | Why it matters |
|------|----------------|
| Read the **stem** before the options | The stem often names the judgement ("best", "most appropriate", "least appropriate") — the same four behaviours can be scored opposite ways. |
| Behavioural questions have **one** professional answer | It is always the option with calm ownership + proportionate escalation. See the four-option scheme. |
| Error correction: **one segment is wrong, three are right** | If two segments look wrong, you have mis-read the option boundaries. Re-read the sentence. |
| Vocabulary questions are **recall, not reasoning** | If you don't know the word in 20 seconds, guess from word-shape and move on. |
| Reading comprehension: **answer only from the passage** | Outside knowledge is a liability, not a help. |
| Flag and move | At 70 seconds, mark the least-wrong option, flag it, continue. A blank is always zero. |

## Worked example — the shape of one scenario question

> **Q.** A week before a release deadline you discover a critical bug in a module you own.
> The delivery manager is in a client call and will be free in 40 minutes.
>
> A. Stay quiet, fix it silently, and mention it only if someone notices.
> B. Inform the delivery manager immediately, explain the impact, and propose a fix plan with two options.
> C. Send an email to the entire project distribution list and the client's IT head.
> D. Blame the developer who wrote the module and ask for a rewrite before the release.

**Answer: B.** It is the only option with early, proportionate communication **and** a proposed path forward.
A is the passive option (silence = hidden risk). C is the over-escalation option (skipping the line of reporting).
D is the aggressive option (blame, no fix). Full reasoning: [`01-Behavioural-Scenario-Based/03-worked-examples/01-solved-scenarios-part-1.md`](01-Behavioural-Scenario-Based/03-worked-examples/01-solved-scenarios-part-1.md).

## Quick rules

- 🔥 **90 seconds per question. Not 100.**
- Behavioural questions are about **process**, not about being "a good person". Look for the option that names a *process*.
- The correct behavioural option almost always contains a verb of **communication** + a verb of **ownership or action**.
- Never pick the option that criticises a named person in the scenario.
- In error correction, test the **verb first** — agreement and tense errors are the most frequent.
- Vocabulary: eliminate by **word class** (is the option a noun? a verb? an adjective?) before meaning.
- Reading comprehension: find the **sentence in the passage** that carries the same words as the option.
- Two minutes of review at the end beats three extra minutes on a single question.

## Common traps

- **The stem flips the answer.** "Least appropriate" is scored backwards. Circle the word.
- **Over-escalation looks responsible.** Escalating straight to the client's IT head is not "proactive" — it is a
  process violation dressed up as initiative.
- **The aggressive option is the most emotionally appealing.** It is never correct in a pre-test.
- **Perfect grammar traps in error correction.** The segment that "sounds bad" is often the *correct* one —
  error-correction questions deliberately include natural-sounding distractors.
- **Vocabulary options that are technically true but wrong in context** (e.g. a synonym of one meaning of a
  polysemous word). Always check the sense used in the sentence.

## Checklist

- [ ] I can name the four behavioural option archetypes (passive / aggressive / over-escalating / professional) in under 30 seconds.
- [ ] I can run the 8-step error scan on a sentence in under 45 seconds.
- [ ] I can state the section time budget (22 min for 15 questions) without looking.
- [ ] I have drilled at least 30 questions from [`06-Question-Bank/`](06-Question-Bank/README.md) under the 90-second cap.
- [ ] I read the stem's judgement word (best / least / most appropriate) every single time.
