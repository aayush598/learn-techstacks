# Support Tools for Solo Founders

## The Right Tool for Each Stage

The right support tools can save you hours per week. The wrong tools add complexity and cost. As a solo founder, choose tools that match your current stage and can grow with you.

### Stage-Based Tool Philosophy

- **Pre-revenue / < $2k MRR:** Free tools only. You don't have volume yet.
- **$2k-$10k MRR:** Start paying for one tool that saves the most time.
- **$10k-$50k MRR:** Invest in a proper support platform.
- **$50k+ MRR:** Full stack with automation, analytics, and possibly a first hire.

## Support Tool Categories

### 1. Help Desk / Ticketing System

The central inbox for all customer requests.

**Comparison:**

| Tool | Free Tier | Paid From | Best For |
|------|-----------|-----------|----------|
| Crisp | Yes (2 seats) | $25/mo | Solo founders, chat-first support |
| Help Scout | No | $25/mo | Email-first, simple, clean |
| Freshdesk | Yes | $15/mo | Full-featured, scales well |

**Recommendation by stage:**

- **Early (< $2k MRR):** Freshdesk free or HubSpot free
- **Growth ($2k-$10k MRR):** Help Scout or Crisp
- **Scale ($10k-$50k MRR):** Intercom
- **Enterprise ($50k+ MRR):** Intercom or Zendesk

### 2. Live Chat

Real-time chat on website and in-app.

**Comparison:**

| Tool | Free Tier | Key Feature |
|------|-----------|-------------|
| Crisp | Yes (2 seats, unlimited chats) | Chat + email + KB + bot |
| Intercom | No (starts at $74) | Best automation, expensive |
| Tidio | Yes (limited chats) | Simple, AI chatbot included |
| Drift | No (starts at $400) | Conversational marketing focus |

**Crisp is the best value for solo founders.** Free tier includes:
- Unlimited chats
- 2 team members (you + future hire)
- Knowledge base
- Basic chatbot
- Mobile app
- Email channel (support@ → Crisp)

| Tool | Free Tier | Paid From | Notes |

**Solo founder approach:** Use Crisp's basic bot to match keywords to KB articles. This handles 30-50% of common questions. Don't invest in complex AI until you have scale.

## The Solo Founder Support Stack

### Stack: Bootstrapped ($0-$2k MRR)

**Total cost: $0/month**

- **Crisp** (free): Live chat + email + basic bot
- **Notion** (free): Public knowledge base
- **Loom** (free): Personalized video responses
- **Freshdesk** (free) or just Gmail: Ticket management
- **Google Forms** (free): Customer feedback

### Stack: Growing ($2k-$10k MRR)

**Total cost: $25-$50/month**

- **Crisp** ($0-$25/mo): Live chat + email + bot
- **Gitbook** ($8/mo) or Notion (free): Knowledge base
- **Help Scout** ($25/mo): Ticket management
- **Loom** (free): Video responses
- **Better Uptime** (free): Status page + monitoring
- **HubSpot** (free): CRM

### Stack: Scaling ($10k-$50k MRR)

**Total cost: $100-$200/month**

- **Intercom** ($74/mo): Chat + email + bot + KB + automation
- **Intercom Articles** (included): Knowledge base
- **Better Uptime** ($20/mo): Status page + monitoring
- **HubSpot** (free or $45/mo): CRM
- **Delighted** ($25/mo): NPS/CSAT surveys
- **Loom** (free): Video responses

### Stack: Established ($50k+ MRR)

**Total cost: $300-$500/month**

- **Intercom** ($74-$200/mo): Full support platform
- **Zendesk Guide** ($55/mo) or Intercom Articles: Knowledge base
- **Better Uptime** ($20/mo): Status page
- **HubSpot** ($45/mo): CRM
- **Delighted** ($50/mo): Surveys
- **First hire** ($500-$2,000/mo part-time)

## Tool Selection Criteria

### For Solo Founders, Prioritize:

1. **Ease of setup** — Under 1 hour to start using
2. **Single inbox** — All channels (email, chat, social) in one place
3. **Mobile app** — You'll triage from your phone
4. **Integration** — Works with your existing stack
5. **Free tier** — Don't pay until you have revenue
6. **Simple UI** — No complex configuration

### Red Flags

- Requires a contract or annual commitment
- Setup takes more than 1 day
- No mobile app
- Can't handle all channels in one inbox
- Requires dedicated IT support to configure

## Setting Up Your Support Tools

### Step 1: Create Your Support Email

- support@yourdomain.com → forwards to your inbox
- Or better: support@ → Crisp/Help Scout inbox

**Pro tip:** Set up aliases:
- billing@ → same inbox, tagged differently
- security@ → same inbox, auto-tagged urgent

### Step 2: Configure Crisp (Recommended Starter)

1. Create Crisp account (free)
2. Connect support@yourdomain.com to Crisp inbox
3. Install Crisp widget on website (copy-paste script)
4. Install Crisp widget in-app (via SDK or iframe)
5. Set up basic chatbot with 5-10 KB articles
6. Configure auto-responder for after-hours
7. Set up email templates for common responses

**Time investment:** 2-3 hours total

### Step 3: Create Knowledge Base

1. Create Notion page (public access)
2. Write top 10 FAQ articles
3. Link articles to Crisp chatbot
4. Add search widget to website (if possible)

**Time investment:** 4-6 hours initial, 30 min/week maintenance

### Step 4: Set Up Status Page

1. Create Better Uptime account (free)
2. Add your product URL(s) as monitors
3. Configure status page with your branding
4. Add link to status page in app footer
5. Set up notification preferences (email+SMS for critical)

**Time investment:** 30 minutes

### Step 5: Set Up Feedback Loop

1. Add Crisp post-chat survey (CSAT)
2. Set up Delighted for NPS (send to customers quarterly)
3. Create feedback form for feature requests (Typeform or in-app)

**Time investment:** 1-2 hours

## Automating Your Support

### What to Automate First

1. **Ticket received acknowledgment** — Immediate auto-reply
2. **After-hours response** — Sets expectations
3. **Common question responses** — Keywords → KB articles
4. **Known issue updates** — During incidents
5. **CSAT survey** — After ticket resolution
6. **Ticket categorization** — Auto-tag by content

### Automation Workflow Examples

**New ticket from known user:**
```
Trigger: Email from existing customer
Action: Tag with their plan level
Action: Check for billing/payment issues
Action: If critical keywords flagged → send urgent notification
Response: Personalized acknowledgment with name and plan context
```

**Common question detection:**
```
Trigger: User types "how do I integrate with..."
Action: Bot responds with integration KB article
Action: Ask if resolved
If yes: Close with CSAT survey
If no: Escalate to inbox
```

### Automation Tools

- **Crisp workflows:** Built-in, simple
- **Intercom Series:** Powerful automation builder
- **Zapier/Make:** Connect anything to anything
- **Custom webhooks:** When you need full control

**Better (low cost):** Metabase connected to your ticket database

### Review Cadence

- **Daily:** Check ticket volume, respond to urgent
- **Weekly:** Review metrics, identify trends
- **Monthly:** Deep dive, plan improvements

## Evaluating New Tools

### Decision Framework

Before adding a new tool:

1. What problem does it solve?
2. How many hours per week will it save?
3. How much does it cost?
4. How long to set up?
5. Is this solving a current problem or a future one?

**Rule of thumb:** Only add a tool if it saves more time per week than the cost divided by your hourly rate. A $50/mo tool needs to save 30 minutes/month at $100/hr to break even.

### Avoid Tool Hoarding

Solo founders often accumulate too many tools. Each tool is:
- A monthly cost
- Learning curve
- Login to remember
- Integration to maintain

**Audit your tools quarterly.** If you haven't used a tool in 30 days, cancel it.

## Conclusion

The best support tool for a solo founder is the one that:
1. Consolidates all channels into one inbox
2. Automates the common so you can focus on the complex
3. Gives customers a self-service option
4. Costs less than the time it saves

Start with Crisp (free) + Notion KB (free) + Loom (free). Upgrade only when you have the volume to justify it.

Your support system should save you time, not create more work. Choose tools that reduce complexity, not add to it.
