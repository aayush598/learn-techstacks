# Landing Page Copy Templates for Different SaaS Types

## Executive Summary

Your landing page is your most important marketing asset. It must communicate value, build trust, and drive conversion in seconds. This guide provides complete landing page copy templates for different SaaS types — B2B, B2C, Developer Tools, Enterprise, and PLG — with fill-in-the-blank sections for each element.

---

## Section 1: Landing Page Structure (Universal)

### 1.1 The Standard SaaS Landing Page

```
ABOVE THE FOLD (What visitors see first)
1. Navigation (logo, links minimal)
2. Headline (one line, crystal clear value)
3. Subheadline (supporting benefit, 1-2 lines)
4. Primary CTA (button — "Start Free Trial" etc.)
5. Hero image/screenshot/demo video
6. Social proof bar (logos, user count, rating)

BELOW THE FOLD (Scroll down)
7. Problem/Agitation section
8. Solution/Features section (3-5 key features)
9. How it works (3 simple steps)
10. Benefits/Results (with numbers)
11. Social proof (testimonials, case studies)
12. Pricing (or link to pricing)
13. FAQ (overcome objections)
14. Final CTA (bottom of page)
15. Footer (links, privacy, terms)
```

### 1.2 Conversion-Heavy Elements

```
Primary CTA:
  Text: "Start Free Trial" / "Get Started" / "Try For Free"
  Subtext: "No credit card required" / "Free 14-day trial"
  Color: High contrast, brand color
  Position: Above fold, after each major section, sticky bar

Social proof bar:
  "Trusted by [X] companies"
  Customer logos (3-10 recognizable brands)
  "Join [X] users"
  Rating: "[X] stars on G2/Capterra"

Trust signals:
  Security badges (SOC 2, GDPR, encryption)
  Money-back guarantee
  "Free trial, no CC required"
  "Cancel anytime"
```

## Section 7: Landing Page Optimization Checklist

### 7.1 Above the Fold

```
[ ] Clear, specific headline (avoid vague/abstract language)
[ ] Subheadline adds crucial context
[ ] Primary CTA is the most prominent element
[ ] CTA subtext reduces friction ("no CC required")
[ ] Hero image/video shows the product in action
[ ] Navigation is minimal (don't distract from conversion)
[ ] Social proof is visible without scrolling
[ ] Page loads in < 2 seconds
[ ] Mobile responsive (60%+ of traffic)
```

### 7.2 Below the Fold

```
[ ] Features are benefit-focused, not technical specs
[ ] Each section has one clear message
[ ] Social proof is specific (names, numbers, logos)
[ ] Pricing is clear and easy to understand
[ ] FAQ addresses top 5-10 objections
[ ] Final CTA restates the primary offer
[ ] Trust signals throughout (badges, guarantees)
[ ] Testimonials include name, title, company, photo
```

### 7.3 Conversion Optimization

```
[ ] A/B test headline variations (always running)
[ ] A/B test CTA button text and color
[ ] A/B test hero image vs. video vs. illustration
[ ] A/B test social proof placement
[ ] A/B test pricing presentation
[ ] Heatmap tracking on key pages
[ ] Form analytics (where do people drop off?)
[ ] Session recording review (weekly)
[ ] Survey exit intent (why are people leaving?)
[ ] Load time optimization (sub-2 seconds)
```

## Landing Page Copy Checklist

```
BEFORE YOU WRITE
[ ] Define target customer (one specific persona)
[ ] Identify core value proposition (one sentence)
[ ] List top 3 objections to overcome
[ ] Gather social proof (testimonials, logos, numbers)
[ ] Review competitor landing pages

HEADLINE
[ ] Clear, specific, benefit-focused
[ ] Avoids jargon and buzzwords
[ ] Passes the "3-second test"
[ ] Includes target customer if applicable

SUBHEADLINE
[ ] Adds supporting detail to headline
[ ] Highlights key differentiator
[ ] Includes social proof element

CTA
[ ] Action-oriented text
[ ] Friction-reducing subtext
[ ] High contrast, prominent position
[ ] One primary goal per page

FEATURES
[ ] Benefit-focused, not feature-focused
[ ] Uses "you" and "your" language
[ ] Specific and concrete, not vague
[ ] Visual evidence (screenshots, GIFs)

SOCIAL PROOF
[ ] Customer logos (real, recognizable)
[ ] Testimonials with full attribution
[ ] Specific metrics and results
[ ] Trust badges (security, compliance)

TRUST SIGNALS
[ ] Privacy policy link
[ ] Terms of service link
[ ] Security/compliance badges
[ ] Money-back guarantee if applicable
[ ] "No credit card" for free trials

MOBILE
[ ] All text readable without zooming
[ ] CTAs tappable (minimum 44px)
[ ] Images scale properly
[ ] No horizontal scroll
```
