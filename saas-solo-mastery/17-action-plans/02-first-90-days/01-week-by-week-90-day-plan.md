# Week-by-Week Action Plan for the First 90 Days of Your SaaS

## Executive Summary

The first 90 days of your SaaS journey are critical. By week 12, you should have a validated product, paying customers, and a repeatable acquisition channel. This guide provides a week-by-week plan to get from zero to a sustainable, growing SaaS business in 90 days.

---

## Section 1: The 90-Day Roadmap

### 1.1 Phases Overview

```
Phase 1 (Days 1-30): LAUNCH
  Goal: Ship MVP and get first paying customers
  Outcome: $0-$1K MRR, 1-10 customers

Phase 2 (Days 31-60): VALIDATE
  Goal: Find repeatable acquisition channel
  Outcome: $1K-$3K MRR, 10-30 customers

Phase 3 (Days 61-90): SCALE
  Goal: Double down on what works
  Outcome: $3K-$10K MRR, 30-100 customers
```

### 1.2 The 90-Day Mindset

```
Speed over perfection. Every week matters.
If you're not embarrassed by what you shipped,
you waited too long.

Do things that don't scale initially.
Manual processes beat automated nothing.
Talk to every user. Learn from every interaction.

Revenue is validation. If you have paying customers,
you're on the right track. If you don't, nothing
else matters.
```

### 1.3 Key Milestones

```
Week 1: Problem validated, MVP planned
Week 2: MVP shipped
Week 3: First paying customer
Week 4: 1-5 paying customers, $0-$1K MRR
Week 6: Repeatable acquisition channel identified
Week 8: 10-30 customers, $1K-$3K MRR
Week 10: Unit economics understood
Week 12: 30-100 customers, $3K-$10K MRR
```

## Section 3: Weeks 5-8 — Validate Phase (Month 2)

### Week 5: Channel Exploration

```
GOAL: Find your top 3 acquisition channels

[ ] Identify 5-8 potential acquisition channels:
    - Content marketing (SEO)
    - Social media (Twitter, LinkedIn)
    - Paid ads (Google, LinkedIn)
    - Community (Reddit, IndieHackers, Slack)
    - Partnerships
    - Referral
    - Cold email
    - Product Hunt

[ ] Test 3 channels this week:
    - Channel 1: [Name] — invest 5 hours
    - Channel 2: [Name] — invest 5 hours
    - Channel 3: [Name] — invest 5 hours

[ ] Measure results for each:
    - Signups from channel
    - Cost per signup (time + money)
    - Conversion to active user
    - Conversion to paid

[ ] Rank channels by ROI:
    1. [Best channel] — [ROI]
    2. [Second channel] — [ROI]
    3. [Third channel] — [ROI]

Week 5 deliverables:
  - 3 channels tested
  - Channel ROI ranking
  - Top channel identified
```

### Week 6: Channel Intensification

```
GOAL: Double down on top 1-2 channels

[ ] Double time on top channel:
    - [Top channel]: invest 15+ hours

[ ] If content marketing is top:
    - Write 4+ articles (SEO-optimized)
    - Repurpose into social posts
    - Build 3-5 backlinks
    - Guest post on 1-2 industry blogs

[ ] If social media is top:
    - 3-5 posts per day
    - Engage with influencers
    - Join relevant conversations
    - DM warm leads

[ ] If cold outreach is top:
    - 20+ personalized outreaches per day
    - Follow up with non-responders
    - Track conversion rates

Week 6 deliverables:
  - 15+ hours on top channel
  - 10-20 new signups from top channel
  - Repeatable outreach process documented
```

### Week 7: Customer Success Deep Dive

```
GOAL: Understand your customers deeply

[ ] Conduct 10+ in-depth customer interviews:
    - Why did you sign up?
    - What almost stopped you?
    - What's the #1 value you get?
    - What would make you leave?
    - Would you refer us? To whom?

[ ] Create customer personas:
    - Persona 1: [Name] — [Demographics, behavior, needs]
    - Persona 2: [Name] — [Demographics, behavior, needs]

[ ] Map the customer journey:
    - Discovery -> Signup -> Activation -> Value -> Retention -> Referral

[ ] Identify drop-off points:
    - Where do users stop engaging?
    - What's the #1 reason for not converting?
    - What's the #1 reason for churning?

Week 7 deliverables:
  - 10+ customer interviews completed
  - Customer personas documented
  - Customer journey mapped
  - Top 3 churn risks identified
```

### Week 8: Conversion Rate Optimization

```
GOAL: Improve signup -> paid conversion

[ ] Analyze current funnel:
    Visitor -> Signup: ___% (benchmark: 2-5%)
    Signup -> Trial active: ___% (benchmark: 40-60%)
    Trial -> Paid: ___% (benchmark: 10-30%)

[ ] Run 3 A/B tests:
    Test 1: Headline variation
    Test 2: Pricing page layout
    Test 3: CTA button copy

[ ] Improve onboarding:
    - Reduce time to first value
    - Add milestone-based progress
    - Improve email sequence
    - Add in-app guidance

[ ] Improve trial to paid conversion:
    - Add more value prompts during trial
    - Address top objection in email sequence
    - Offer annual discount
    - Send personal outreach to warm leads

Week 8 deliverables:
  - 3 A/B tests completed
  - Onboarding improved
  - Conversion funnel documented
  - Conversion rate improved by 20%+
```

```

[ ] Analyze feature usage data:

    - Least-used features

    1. [Feature] — Expected impact on retention
    2. [Feature] — Expected impact on conversion

[ ] Remove or deprecate unused features:

    - Features causing support tickets

    - API response time improvement
    - Database query optimization

```

[ ] Analyze current pricing:

    - Churn by tier

[ ] Test pricing page changes:

    - Price anchoring
    - Annual discount presentation

[ ] Implement changes:

    - Announce changes with 30 days notice
    - Monitor churn impact

  - Pricing optimized
  - Price increase tested (if applicable)
  - Annual plan adoption increased
  - ARPU improved

### 5.3 Decision Framework

```
When facing a decision, ask:

1. Does this directly drive revenue?
   [Yes] -> Do it now
   [No] -> Ask question 2

2. Does this directly reduce churn?
   [Yes] -> Do it now
   [No] -> Ask question 3

3. Does this directly improve user experience?
   [Yes] -> Consider doing it
   [No] -> Skip it

4. Does this help me learn faster?
   [Yes] -> Consider doing it
   [No] -> Skip it

If you answered No to all 4, don't do it.
```

## Section 6: 90-Day Success Metrics

### 6.1 Target Metrics by End of Week 12

```
STRONG SUCCESS:
  MRR: $5K-$10K
  Customers: 50-100
  MoM growth: 20%+
  Churn: <3% monthly
  CAC payback: <6 months
  LTV:CAC: >3:1
  Top channel identified: [Yes]

MODERATE SUCCESS:
  MRR: $2K-$5K
  Customers: 20-50
  MoM growth: 10-20%
  Churn: 3-5% monthly
  CAC payback: <12 months
  LTV:CAC: >2:1
  Top channel identified: [Maybe]

SUSTAINABLE BUT SLOW:
  MRR: $500-$2K
  Customers: 10-20
  MoM growth: 5-10%
  Churn: 5-8% monthly
  CAC payback: <18 months
  LTV:CAC: <2:1
  Top channel identified: [Not yet]

RED FLAG (need to pivot or change approach):
  MRR: <$500
  Customers: <10
  MoM growth: <5%
  Churn: >8% monthly
  No clear acquisition channel
  Customers not willing to pay
```

### 6.2 What to Do If You're Behind

```
If you're below moderate success by week 12:

ANALYZE:
  Is the problem real? (Re-interview customers)
  Is the product good enough? (Fix core experience)
  Is the pricing right? (Adjust)
  Is the channel wrong? (Try different channels)

PIVOT OPTIONS:
  Narrow: Focus on a specific niche that works
  Reposition: Change messaging to different audience
  Rebuild: Major product changes (last resort)
  Kill: If nothing works, move to new idea

REALITY CHECK:
  90 days is enough to validate most ideas
  If you have 0 paying customers, something is fundamentally wrong
  Don't throw good time after bad ideas
```
