# Phase 2 — Intermediate TypeScript

> Modules 08–13. Combine types, narrow them safely, and write reusable abstractions.

## Modules

| # | Module | What you get |

| 08 | [Union and Intersection Types](./module-08-union-and-intersection-types/README.md) | Sum/product types, discriminated unions |

## Phase outcomes

- Model domains with discriminated unions and exhaustive checks.
- Write reliable user-defined type guards and assertion functions.
- Replace unsafe assertions with validation and `unknown`.
- Design generic functions, interfaces, classes, and repositories.
- Use classes safely and understand variance in inheritance.
- Choose literal unions / `as const` objects over enums when appropriate.
