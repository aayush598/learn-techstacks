## Phase outcomes

- Encode domain invariants in the type system (brands, refinements, state machines).
- Write and debug declaration files for untyped packages.
- Design package entry points and public type contracts.
- Use the Compiler API to build linters, codemods, and analyzers.
- Understand why the checker accepts or rejects a program.
