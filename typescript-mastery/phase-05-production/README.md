## Phase outcomes

- Turn on and understand all strict-family flags.
- Enforce consistent, reviewable type design across a team.
- Scale folder structure without circular dependencies or a `shared/` dumping ground.
- Prove type behavior with compile-time tests.
- Measure and fix expensive types.
- Upgrade TypeScript and evolve public types safely.
