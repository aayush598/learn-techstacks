# Basic Types

This module builds the core vocabulary of TypeScript: primitives, the special types (`null`, `undefined`, `void`, `never`, `any`, `unknown`, `object`), literals, arrays, tuples, and enums. You will learn how annotations and inference cooperate, and how types widen, narrow, and get assigned under `strict` mode.

## Key outcomes

- Annotate values, parameters, and returns precisely, and know when inference is enough.
- Use every primitive and special type (`never`, `unknown`, `void`, `null`, `undefined`) correctly.
- Model fixed-shape data with tuples and protect collections with `readonly`.
- Choose between enums and literal unions with a clear rationale.
- Reason about widening, narrowing, compatibility, and assignability under `strict` mode.
