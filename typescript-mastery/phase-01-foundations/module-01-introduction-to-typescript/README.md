# Module 01 — Introduction to TypeScript

> Phase 1 · Foundations

This module builds the mental model for everything that follows: TypeScript is JavaScript with a compile-time type system that is erased at runtime. You will learn what the compiler does, how files and projects are organized, and how to read diagnostics instead of fighting them.

## Key outcomes

- Explain compile-time types versus runtime values and describe type erasure.
- Outline the compiler pipeline and the role of the language service.
- Choose the correct extension for `.ts`, `.tsx`, `.d.ts`, `.mts`, and `.cts` files.
- Configure and run a basic compile, then interpret the resulting diagnostics.
- Navigate the Handbook, compiler reference, release notes, and Playground with intent.
