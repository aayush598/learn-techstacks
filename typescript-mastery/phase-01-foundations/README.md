## Phase outcomes

- Explain compile-time checking vs runtime behavior and type erasure.
- Initialize a strict TypeScript project and understand every important compiler flag.
- Model primitives, arrays, tuples, objects, and functions precisely.
- Know when inference is enough and when an annotation adds value.
- Use `as const` and `satisfies` correctly.
