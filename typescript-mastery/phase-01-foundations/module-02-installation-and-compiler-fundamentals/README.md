## Key outcomes

- Install a pinned, local TypeScript compiler and run it through npm scripts.
- Explain what `tsc` does, how it builds a program, and what it emits.
- Read and write a strict `tsconfig.json` with confidence.
- Select source files with `files`, `include`, and `exclude`.
- Control output layout with `rootDir`, `rootDirs`, `outDir`, and `declarationDir`.
- Use watch, no-emit, declaration-only, build, and incremental modes appropriately.
- Diagnose compiler errors and verify the effective configuration.
