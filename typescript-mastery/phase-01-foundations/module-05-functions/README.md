Learn how TypeScript types every part of a function: parameters, returns, `this`, overloads, generics, and the variance rules that govern assignability. Each topic is code-first and assumes `strict` mode, so the examples match how TypeScript behaves in real projects.

## Key outcomes

- Annotate parameters, returns, and function types confidently, and know when inference is enough.
- Model optional, default, rest, and tuple rest parameters precisely.
- Write reusable function types with aliases, interfaces, call signatures, and construct signatures.
- Design overloads and understand how resolution order affects the chosen signature.
- Type higher-order functions, callbacks, async functions, and promises correctly.
- Apply assertion and type-predicate functions to narrow types safely.
- Reason about `this` parameters, function assignability, and parameter/return variance under `strict`.
- Apply a consistent style for public function signatures.
