# Object Types and Object Properties

> Phase 1 · Module 06

This module covers how TypeScript describes objects: annotations, inference, optional and readonly members, nested shapes, index signatures, and composition. It ends with structural typing limits and strategies for modeling realistic object structures.

## Key outcomes

- Read and write object type annotations with required, optional, and readonly properties.
- Predict when TypeScript infers, widens, or preserves object literal types.
- Use structural compatibility and excess property checking without being surprised by them.
- Write string, number, and symbol index signatures and model optional keys correctly.
- Compose object types with intersections, unions, utility types, and generics.
- Structure complex real-world data models with clear boundaries and runtime validation.
