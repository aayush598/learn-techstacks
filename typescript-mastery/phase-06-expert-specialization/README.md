- Implement type-safe registries, event systems, builders, and state machines.
- Reason about variance, bivariance, and where TypeScript is unsound.
- Design and version a public type surface other teams can depend on.
- Build automated TypeScript checks and codemods.
- Write and enforce a project's TypeScript engineering standard.
