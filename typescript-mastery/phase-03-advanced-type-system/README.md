# Phase 3 — Advanced Type System

> Modules 14–20. Treat the type system as a programming language: query, transform, derive.

## Modules

| # | Module | What you get |
| --- | --- | --- |
| 14 | [Type Operators](./module-14-type-operators/README.md) | `keyof`, `typeof`, indexed access |
| 15 | [Mapped Types](./module-15-mapped-types/README.md) | Property transforms, key remapping |

## Phase outcomes

- Derive types from other types instead of duplicating them.
- Write and debug mapped, conditional, and template-literal types.
- Build variadic tuple APIs and typed argument lists.
- Reimplement every built-in utility type from scratch.
- Build a custom utility-type library with readable definitions.
- Recognize and avoid type-instantiation blowups.
