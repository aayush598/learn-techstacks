# Chapter 1: Deadlock Characterization

> **TL;DR**: A deadlock requires four conditions: mutual exclusion, hold-and-wait, no preemption, and circular wait. The resource allocation graph visualizes state; a cycle in the graph implies deadlock when all resources have a single instance.
