# 01 — The Complete Toolchain (Every Tool To Run This Business)

A master list of tools — mostly free — organized by function. Set these up once in Week 1 (Part 15).

## Core Business Setup

| Function | Tool (free first) | Purpose |
|----------|-------------------|---------|
| Business email | Gmail (branded via your domain later) | Professional contact |
| Business phone/UPI | WhatsApp Business app | Catalog + Status + support |
| Local search | Google Business Profile | "billing software near me" |
| Bookkeeping | Google Sheets tracker (Part 14) | Cash/income tracking |
| Invoicing | Google Docs template (Part 14) / free invoice app | Send professional invoices |

## Marketing & Content

| Function | Tool | Purpose |
|----------|------|---------|
| Logo/design | Canva (free) | Logo, flyer, marketing sheet |
| Short videos | Phone screen recorder / CapCut (free) | Demo clips |
| Social media | Instagram/Facebook/YouTube | Distribute content |
| Local directories | JustDial/IndiaMART/Sulekha | Free listings |
| Landing/page | Carrd / Google Site (free) | Simple one-page presence |

## Sales & CRM

| Function | Tool | Purpose |
|----------|------|---------|
| Lead tracker | Google Sheets (Part 14) | Pipeline |
| Customer/renewal tracker | Google Sheets | Asset list + renewal calendar |
| Video calls | Google Meet / Zoom (free) | Remote demos |
| Screen share | Meet/Zoom | Guided setup |

## Product & Delivery

| Function | Tool | Purpose |
|----------|------|---------|
| Platform build | The Pendrive Finance source (C++/Qt) | The product |
| Templates | The Visual Designer | Customize apps |
| Testing | Test on clean Windows PC | QA (Part 09) |
| Pendrives | Reliable USB 3.x (Sandisk/Kingston/etc.) | Deliverable |
| Backup | External drive + encrypted cloud (optional) | Data safety |

## Payments

| Function | Tool | Purpose |
|----------|------|---------|
| Domestic | UPI (business QR), cash, bank transfer | Collect money |
| International | PayPal / Stripe / Wise | Foreign payments |

## Admin & Compliance

| Function | Tool | Purpose |
|----------|------|---------|
| Registration | Your local govt portal (e.g., MSME/Udyam) | Formalize |
| Tax | Your local portal + CA | File returns |
| Files | Google Drive (encrypted for sensitive) | Store agreements, invoices, backups |
| Calendar | Google Calendar | Renewals, follow-ups, deadlines |

## Communication

| Function | Tool | Purpose |
|----------|------|---------|
| Support | WhatsApp Business | Primary channel |
| Team/partners | WhatsApp/Telegram + shared Sheets | Coordination |

## Setup Checklist (Week 1)

- [ ] Google account + Drive + Sheets + Calendar.
- [ ] Google Business Profile (Part 06).
- [ ] WhatsApp Business with catalog (Part 06/14).
- [ ] Create the 3 core trackers (Part 14).
- [ ] Create templates: agreement, invoice, marketing sheet (Part 14).
- [ ] Canva logo + marketing sheet (Part 14).
- [ ] Your 3-price offers set (Part 04).
