# 02 — DAYS 31–60: Build the Machine (Repeatable Delivery + Growing Pipeline)

**Goal:** Turn what worked into a repeatable system — more customers, faster delivery, first renewals, and a referral engine.

## Weeks 5–8: Systemize + Scale Delivery

### Week 5 — Solidify the System
- [ ] Refine your **niche template** with feedback from customer #1/2 (Part 09).
- [ ] Lock your **delivery checklist** (Part 09) — reuse every time.
- [ ] Set your **weekly rhythm** (outreach/delivery/support/content days) (Part 10).
- [ ] Update lead tracker; qualify new leads daily (Part 05).

### Week 6 — Grow Pipeline & Referrals
- [ ] **Daily outreach** (10–20 touches) + follow-ups (Part 05).
- [ ] Activate **referral asks** on every happy delivery (Part 10).
- [ ] Collaborate with **1–2 partners** (CA / IT shop) for referrals (Part 10).
- [ ] Post content weekly (Part 06) — tips, demos, testimonials.

### Week 7 — Get to 2–3 Customers
- [ ] Book + run more demos; close with deposit-first (Part 05).
- [ ] Deliver on time, collect balance, get testimonials (Part 09/10).
- [ ] Finish 1–2 more paid deliveries.

### Week 8 — First Renewal Prep
- [ ] Review renewal calendar (Part 04/10) — set up reminders for month 3+ renewals.
- [ ] Start collecting **annual licenses** / prepay discounts (Part 04).
- [ ] Raise prices for NEW customers by 10–20% if you have proof+testimonials (Part 04).

## Phase 2 Goals (clear by end of Day 60)

- [ ] **2–5 paying customers** total.
- [ ] Delivery time shrinking (template reuse working).
- [ ] **First testimonials + Google reviews** collected.
- [ ] **Referral engine** running (asks on every delivery).
- [ ] **Recurring renewals** structured (renewal calendar active).
- [ ] 1–2 partner referral relationships formed.

## Phase 2 Rhythm Reminder

Follow the weekly structure (Part 10 daily rhythm):
- Mon/Wed: outreach + demos.
- Tue/Thu: delivery/support.
- Fri: admin/cash/renewals.
- Sat: content/marketing.
- Sun: rest.

## Phase 2 Warning Signs

- ⚠️ Delivery quality dropping as volume grows → improve template + checklist (Part 09).
- ⚠️ Not enough leads → increase touches + referral focus (Part 05/10).
- ⚠️ Cash tight → quick-cash routes + renewals (Part 12/04).

## Phase 2 Wins

- Multiple paid customers + a system that reproduces delivery = real progress. Update your wins list.
