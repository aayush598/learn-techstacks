# 03 — The Project Delivery Workflow (Step-by-Step, Repeatable)

Follow the same steps for every customer. It makes delivery fast, consistent, and professional.

## The Delivery Pipeline

```
Requirements → Build/Customize → Test → Migrate Data → Backup → Train → Deliver → Collect Balance → Support/Warranty
```

## Step 1: Requirements (Part 02)
Scope sheet + signed agreement + deposit collected.

## Step 2: Build / Customize (in the Designer)
1. Copy your **niche template**.
2. Customize: business name, logo, theme, fields, forms, reports, invoice format.
3. Configure users/permissions.
4. Set up the modules from the scope.
5. Build any custom reports/workflows.

## Step 3: Test (Part 03) — never skip
- Entry forms end-to-end.
- Billing/invoice/printing.
- Stock updates, reports correct.
- Login/permissions.
- Runs offline from the pen drive on a clean Windows PC.

## Step 4: Migrate Data (if paid)
- Import customers/products from Excel/paper.
- **Verify** the import (counts match, no duplicates/garbage).
- Clean up test data.

## Step 5: Backup (always)
- Create a **verified backup** of the configured app + data.
- Store a secure copy (default drive + your offsite backup).
- Hand the customer a **spare backup** or explain the backup location.

## Step 6: Train (if paid / important for adoption)
- 1–3 sessions: how to bill, add stock, check profit, back up.
- Keep it simple, in their language, at their pace.
- Give a **short cheat-sheet** (Part 14) they can keep.

## Step 7: Deliver
- Hand over the pendrive (sealed/professional).
- Confirm data + backup + documentation.
- Collect the **balance** (before final handover).
- Get a **signed acknowledgment/acceptance** if valuable.

## Step 8: Post-Delivery (Part 10)
- Start the support/warranty window.
- Set a **follow-up check-in** in a few days.
- Ask for a **testimonial + referral**.
- Log the customer in your tracker (renewal clock starts).

## Handoff Documentation Checklist (Part 14)

- [ ] Pendrive with the app.
- [ ] Backup drive/location.
- [ ] Training cheat-sheet.
- [ ] Support contact + hours.
- [ ] Renewal date & amount.

|----------|-------|---------|----------|-------|---------|-------|

Update after every touchpoint. **Know where every project stands.**

## Time-Saving Rule

Build the **template once**, then each customer is "copy + customize + test." Resist rebuilding from scratch — that's how you stay fast and profitable.
