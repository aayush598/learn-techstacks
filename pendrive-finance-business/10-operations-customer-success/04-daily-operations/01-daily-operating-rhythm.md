# 01 — Daily Operating Rhythm (Run the Solo Business Sustainably)

A solo business runs well on **routine + systems**, not willpower. Structure your days so marketing, delivery, and support all get done.

## The Weekly Structure (recommended)

| Day | Focus |
|-----|-------|
| Mon | **Pipeline day** — outreach, leads, follow-ups, updates to tracker |
| Tue | **Delivery day** — build/customize, test, migrate |
| Wed | **Outreach + demos** — demos booked, prospecting |
| Thu | **Delivery/support day** — finish customizations, handle support batch |
| Fri | **Support batch + admin** — tickets, check-ins, invoices, renewals, bookkeeping |
| Sat | **Marketing/content** — batch-create content, post, prep next week |
| Sun | **Rest** — protect it (prevents burnout) |

> This is a template — adapt to your life. The key: **all roles get time** — seller, builder, supporter, marketer, administrator.

## Daily Blocks (protect your time)

- **Morning (deep work):** deliveries, builds, testing (highest-focus).
- **Midday:** outreach calls + demos (when owners are reachable).
- **Late:** support batch + admin + content (lighter).
- **Blocked support hours** (e.g., 6–8 pm) so you're not interrupted all day.

## Lead Pipeline Ritual (daily or 3x/week)

1. Update lead tracker with new leads + statuses.
2. Follow up on every engaged lead (multitouch — Part 05).
3. Book 1+ demo if leads allow.
4. Send 1+ proposal for qualified leads.

## Admin Ritual (weekly, 30–60 min)

- Update **cash flow** (money in/out).
- Update **project tracker** (status of every job).
- Send/reconfirm invoices.
- Backup customer data check.
- Renewal calendar review.

## Rest & Anti-Burnout

- Solo = all roles on you. **Burnout is the real threat.**
- Protect rest; take one full rest day.
- Batch tasks (don't context-switch all day).
- Automate what you can (Part 14).
- Defer/add help when overloaded (Part 13).

## The "No-Distraction Rule"

- Set **focused blocks** for deep work (build/test) with phone off.
- Do outreach in **dedicated blocks**, not spilling into everything.

## Daily Close-On (each evening, 5 min)

- [ ] What money came/went today? (updated)
- [ ] Any unresponded support? (handled)
- [ ] 3 leads touched today?
- [ ] One project advanced?
- [ ] What's #1 priority tomorrow?

> Rhythm creates momentum. Momentum + deposits = money. This is the machine.
